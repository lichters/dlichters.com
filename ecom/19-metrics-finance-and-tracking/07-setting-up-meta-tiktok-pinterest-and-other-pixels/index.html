Setting up Meta, TikTok, Pinterest and other pixels

Section 19.7 · 7 of 23 in this chapter · 14 min read

In short

  • A Meta pixel is tracking code on your website. It reports visits, carts and sales to Meta, so ads can learn who buys.
  • Turn on Maximum data sharing. This helps sales still get counted when ad blockers or Apple device limits block the normal pixel.
  • Check that the pixel is connected to Shopify before you trust ROAS or purchase numbers.
  • For TikTok, set the goal to Complete Payment, not Add to Cart.
  • Do not run Facebook and TikTok ads for the same product at the same time.

Pixel basics and how Meta uses them

2 min
  • A Facebook pixel is a small piece of tracking code on your website. It records events such as page views, add to carts and purchases. An event is any action a visitor takes.
  • The data goes back to Meta. Meta's algorithm (its automatic system for choosing who sees ads) uses it to optimise delivery and find similar buyers.
  • The same data also shows your sales in Ads Manager, Meta's ad dashboard.
  • Standard Meta conversion events for an online store are:
    • Add to Cart (ATC)
    • Initiate Checkout (IC)
    • Purchase
  • These events mark the steps a visitor takes toward buying.
  • Meta uses them to measure performance.
  • The pixel only records events that have already happened on the site.
  • At launch, the pixel contributes nothing. So early results depend on your creative (the ad images and videos) and your initial targeting (who the ads are shown to at the start).
  • After purchases, the pixel learns who bought and searches for similar users.
  • So early sales from a pocket improve later delivery.
  • A competitor (a rival store) with more pixel data can outperform an identical setup early on.
  • In Events Manager, Meta's tool for checking pixel events, check which events the pixel tracks:
    • website visits
    • add to cart
    • initiate checkout
    • purchases
  • The pixel appears as an audience source. An audience is the group of people your ads are shown to.
  • Select the pixel and confirm it shows green. Green means it is installed and active.
  • Purchase events sent from the store to Meta put buyers into the purchase audiences.
  • Facebook retargeting (showing ads again to people who already visited) runs on the Facebook pixel.
  • Once the pixel is installed in the store, the ad setup loads it automatically. No separate tracking setup is needed in the ad.
  • Before you judge results such as ROAS (return on ad spend: sales earned for every unit of money spent on ads), confirm the Meta pixel is connected to your Shopify store. Shopify is the online store software.
  • Make this connection through the Facebook and Instagram channel app.
  • Sales only reach Ads Manager through that connection.
  • Without it, the reported numbers are unreliable.

Pixel installation methods

1 min
  • A tracking pixel is a small script on every page. It records visitor activity and actions. Google calls the same thing a tag.
  • All major ad networks use this cookie-based system to fill retargeting lists. A cookie is a small file a website saves in the visitor's browser. A retargeting list is a list of people to show ads again.
  • A pixel can be installed in two ways:
    • by placing the code directly in the site
    • through Google Tag Manager, a Google tool that keeps tracking codes in one place
  • Google Tag Manager is not mandatory.
  • It suits extra tags such as Twitter or Taboola. Taboola is an ad network.

Shopify-Meta connection, data sharing and Conversions API

1 min
  • Since Apple's iOS 14.5 update (an iPhone software update), data sharing from third-party sites such as Shopify to Facebook is heavily restricted on Apple devices.
  • Maximum data sharing is used to recover part of that lost tracking.
  • In the Facebook shop setup:
    1. Switch on data sharing.
    2. Choose one of three levels: Standard, Enhanced or Maximum.
    3. Select Maximum.
  • Turn on Automatic Advanced Matching during the connection summary, before you continue. This is a setting that sends extra visitor details to help Meta match people. The tracking setup needs it.
  • Maximum data sharing combines all data sharing options.
  • It uses the Conversions API (CAPI). CAPI is a direct connection that sends data from Shopify's servers (the computers that run your store) to Facebook.
  • Because this path is server-side (sent from the store's computers, not the visitor's browser), ad blockers cannot block the data. Ad blockers are browser add-ons that hide ads and block tracking.
  • Shopify's native Facebook/Meta integration (the built-in connection) with maximum data sharing turns on CAPI alongside the pixel.
  • CAPI sends extra data with each conversion:
    • IP address (the visitor's internet address)
    • email
    • name
    • phone number
  • Shopify reportedly attributes 90% or more of conversions correctly with this setup. Attributing means giving the right ad credit for the sale.
  • Enable Shopify's Facebook/Meta integration with maximum data sharing to activate CAPI alongside the pixel.
  • The pixel alone is the least reliable option. It is the most blocked or anonymised (stripped of personal details).

Domain verification and Facebook setup order

1 min

Source C procedure:

  1. Verify your domain in Meta. A domain is your website address. Verifying proves you own it. This way, data Shopify sends back is recognised as coming from a domain you own.
  2. Connect the Meta pixel through the Shopify Meta app.
  3. In Events Manager, set up the top aggregated events in this priority:
    1. Purchase
    2. Initiate Checkout
    3. Add to Cart
    4. Search
    5. View Content Aggregated events are the limited set of main events Meta tracks for each domain.
  4. Add UTM parameters at ad level to every ad URL. UTM parameters are tags added to the end of a web address to label where a visitor came from. The ad level tags are:
    • campaign name
    • ad set name
    • ad name An ad URL is the link an ad sends people to. Shopify can then record which ad each sale came from.
  • The sources disagree on the number of events.
  • One says the top 8 aggregated events.
  • The other says 5.
  • Both give the same five events in the same order.
  • The material names only these five, so the other three are not specified here.

Per-product pixels and pixel strategy

1 min
Situation Action Source
Testing a new product Create a separate pixel for each product you test
New product, same niche, pixel already has buyer data Keep the same pixel
Several products in the same niche, one email list Share one pixel and one list across launches
Niche changes Change the pixel
Changing the pixel after every test Another practitioner advised this; a personal choice
  • Sharing one pixel across several product tests combines their conversions.
  • So you cannot tell which product sold.
  • Keep one central email list of all previous customers and leads.
  • A lead is someone who gave their email but has not bought yet.
  • Each new launch uses the same warm audience (people who already know your brand) and the same pixel data.
  • So campaigns can be profitable immediately, without weeks of pixel warm-up. Warm-up is the time a new pixel needs to collect data.
  • Example: a supplement brand with a shared pixel and a 180K email list generated $250K revenue from $9K ad spend across 4 product launches.
  • A pixel with buying data from the same niche (the same market or product type) gives Facebook more to work with.
  • This can lower CPMs (the cost per 1,000 ad views) and make targeting more accurate.
  • Old pixels can be deleted to keep the account clean.

Creating a test pixel for one product

1 min
  1. In Shopify, search for the Meta app and open it.
  2. Go to the app's Settings page.
  3. Click Create new to make a new pixel.
  4. Check that the new pixel appears at the top of the list. Double-check its ID, the pixel's unique number.
  5. Assign people to manage the pixel and give them access to all your profiles.
  6. Assign assets. Assets are the Meta items you control, such as pixels and ad accounts. Select all your ad accounts.
  7. Open Events Manager from the assets view.
  8. Rename the pixel to today's date plus the product name.
  9. Close Events Manager, refresh the Shopify page, and check that the same pixel is shown.
  • Name each test pixel with today's date plus the product name.
  • Use the format DDMM plus product name (DDMM means two digits for the day, then two for the month).
  • Example: 2404 SleepMask. This lets you match the pixel to its test later.
  • Meta has moved pixel data assets.
  • To find a Meta Pixel, go to Data Sources and select Datasets. Do not use the older location.
  • After creating a pixel, finish installing it on the store, including adding events, before you expect tracking to start.
  • The Events Manager overview shows whether the installation is still open.
  • Website events no longer need a domain selected in the ad account.
  • The website events dataset (the pixel's data collection) connected to the ad account is tracked by default.
  • URL parameters stay optional.

Lead-generation pixel

1 min
  • For a lead pixel, which tracks sign-ups, create a pixel with the Leads conversion event and give it a name. A conversion event is the action you count as a success.
  • Paste the generated code into the head section of the thank-you page. The head section is the hidden top part of a web page. The thank-you page is where people land after signing up on the squeeze page. A squeeze page is a sign-up page that collects emails.
  • Do not place the pixel on the squeeze page itself.

TikTok pixel and optimisation

1 min
  • TikTok's native tracking (its built-in tracking) is unreliable. It tracks approximately 50% of actual sales.
  • Use tracking apps or UTM parameters for accurate performance measurement.
  • Website conversions require a TikTok pixel.
  • Install it on the Shopify store through the TikTok pixel integration.
  • Then log in through TikTok Ads Manager (TikTok's ad dashboard), so the pixel connects automatically.
  • You never need to link your TikTok account to get the pixel.
  • Set the optimisation event to Complete Payment, not Add to Cart. The optimisation event is the action TikTok aims to get more of.
  • Add to Cart optimisation reports cheap add-to-cart conversions. These look like sales but are not.
  • This misleads you about profitability (whether you make money).
  • Complete Payment usually costs slightly more per result.
  • Use Complete Payment as the optimisation event.
  • So TikTok optimises toward completed purchases rather than cheaper actions.
  • Create multiple pixels and do not connect them to the store.
  • TikTok treats an ad account as new when its pixel shows no recent activity.
  • This can lead to stronger results.
  • Unlike Facebook, where pixel history and data volume matter most, TikTok handles pixels differently.
  • So creating a new pixel from time to time is recommended.
  • The sources conflict on connection.
  • One says to install the pixel through the store integration for website conversions.
  • Another says to create extra pixels and not connect them to the store.
  • The material does not explain how the two fit together.
  • Do not run Facebook and TikTok ads for the same product at the same time.
  • The traffic behaves differently and mixes the data in the Shopify and Meta pixel.
  • TikTok traffic often adds to cart and reaches checkout (the payment step) without buying.
  • This makes decisions harder.

Pinterest conversion tracking

1 min
  • The Pinterest tag (Pinterest's tracking code), installed through the Shopify marketing section, is the essential tracking step.
  • It records the visits and purchases that Pinterest uses to optimise ads.
  • Pinterest does not allow conversion campaigns until the account has conversion events.
  • The error appears as a message asking you to increase your conversion events.
