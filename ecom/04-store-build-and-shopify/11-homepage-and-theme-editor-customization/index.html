Homepage and theme editor customization

Section 4.11 · 11 of 20 in this chapter · 75 min read

In short

  • Change the look in the Customizer first. Touch the code only when the Customizer truly cannot do the change.
  • Click Save after every change, then check the live page.
  • Show only real things. Remove fake or empty social links and unused sections, because suppliers will click them.
  • Finish the homepage in about 60 minutes when your images are ready, following the set order.
  • Keep one slide in your homepage slideshow. Add more later if you need them.
More key points
  • Link a page or button only when the destination page already exists.
  • Check the store on a phone before you save.
  • Remove fake text and placeholder phone numbers before launch.
  • Save after every change, or the edit is lost when you leave the editor.
  • Check the mobile view before you save, because a page can look fine on a computer and broken on a phone.
  • Add links only to pages that already exist, or visitors hit dead ends.
  • Keep social media off until real accounts exist.
  • Hide a section instead of deleting it, so you can bring it back later.
  • The checkout (the payment page) is mostly locked. A full redesign needs Shopify Plus, a paid plan of about 2,500 USD per month.
  • Make the checkout banner 1500 × 300 px, the size most sources give.
  • Trust badges (security logos, guarantee, payment icons) helped one store's conversion rate (share of visitors who buy) go from 0.29% to 2.15% in one day.
  • Check your plan before you promise a custom checkout.

Theme editor access and basic rules

2 min
  • The Theme Customizer is Shopify's built-in visual editor. It changes a theme's look without touching code (code is the written instructions that make a website work). It adjusts the website font, color scheme, layout and store content from a side panel on the customized themes page.
  • Use the Customizer's built-in settings for everyday look changes first. Go into the theme's HTML/CSS (HTML is the page structure code, CSS is the style code) only for structural changes the Customizer cannot make.
  • Avoid editing theme code unless a change truly cannot be made in the Customizer. Opening the code editor by accident means you are in the wrong place for ordinary design work.
  • Admin path (the back office menu inside Shopify, called the admin): Online Store > Themes > Customize. The Source A Manhattan theme must be installed to use this path.
  • Steps to open the theme customization pages:
    1. Log in to the Shopify account.
    2. Click Online Store in the Shopify admin.
    3. Click Themes.
    4. Find the installed theme named Source A Manhattan.
    5. If it is the currently published theme (published means live for visitors), click the Customize button.
    6. If you are upgrading from another theme and Manhattan is not yet published, find it in the list of unpublished themes further down the page and click Customize.
    7. The side menu that opens lists the elements you can edit. Changes made there alter what visitors see on the store.
  • Before opening the theme customization pages, the basic store should already have its menus (the lists of links), some collections (groups of products, like shelves) and a demo product (a sample item used for testing). The Customizer then turns that bare structure into the finished look.
  • To open the homepage editor, go to Online Store > Themes, confirm the active theme is the one you are building, and click Customize. Check that the page dropdown (the menu at the top of the editor) says Homepage before you change anything.
  • In the sidebar, hovering over a section highlights it on the page. Clicking an element in the preview opens its settings. Each section can be hidden with the eye icon or removed with delete. Sections can be reordered by dragging the six-dot handle (the grip you drag up or down).
  • The left sidebar shows the homepage layout from top to bottom. Hovering a section name highlights it on the live preview. Clicking an element on the preview jumps to that section in the sidebar.
  • Click Save after every change in the theme editor. Then reload the live product page to confirm the change appears. The preview does not always show the final result, for example end dates or hidden blocks.
  • Theme settings apply to the whole store, including fonts, buttons and header. Section settings only affect the one section they belong to. Each section's color scheme dropdown uses the named color schemes defined in Theme settings > Colors (a color scheme is a saved set of colors). One color change therefore updates every section that uses that scheme.
  • Collection pickers in the collection list and featured collection sections only show collections that already exist. Create and fill the collections under Products > Collections first, then add them to the homepage.

Order of work and time budget

1 min

  • Budget 60 minutes to complete the full homepage customization when image assets (ready image files) are already created. The work is mainly placing those assets.

  • Work through the homepage in this order:

    1. Upload all images to Files.
    2. Set logo and favicon (the small icon shown in the browser tab).
    3. Set colors and typography (the fonts and text sizes).
    4. Set layout and buttons.
    5. Set header, sticky header (a menu bar that stays at the top while scrolling) and menu colors.
    6. Configure slideshow (a rotating set of large images at the top), collection list, featured collection, pre-footer (the strip above the footer at the bottom of the page) and email signup.
    7. Hide unused sections.

    After each step, save and check the preview on desktop and mobile.

  • The same work can be seen as four blocks:

    • Homepage and general customizations.
    • Menu customizations (header and footer menus).
    • Collection page customizations (layout and visuals).
    • Product page customizations (layout and settings).

  • Theme customization turns a Shopify store from its default basic template (gray, white and black) into a branded store. You do this by adding image assets and adjusting layout and settings inside the theme editor.

  • Advanced web design changes are optional final tweaks. They suit a store that already performs well and needs extra gains. They are not needed to get first results.

  • Shopify's native editor is moving toward more page-builder flexibility (a page builder lets you move blocks around without code). For example, you can move elements without code. This cuts the developer work needed for simple layout changes.

Full Manhattan homepage procedure (initial setup)

4 min

The complete homepage walkthrough, in order, as taught for the Manhattan theme:

  1. Upload all image assets. Go to Shopify Admin > Content > Files, click Upload files, select all Canva assets (Canva is a design tool) at once, and confirm the upload completes.

  2. Open the theme customizer. Go to Shopify Admin > Online Store > Themes, select the Manhattan theme, click Customize, and confirm Homepage is selected in the top dropdown.

  3. Hide the announcement bar (the thin strip at the very top of the store). Hover over Announcement bar in the sidebar and click the eye icon.

  4. Add the logo. Go to Theme settings (gear icon) > Logo, select the uploaded logo file, and keep the desktop logo width around 200.

  5. Add the favicon. Go to Theme settings > Favicon image and select the small logo variation file.

  6. Set global colors. Go to Theme settings > Colors, use your brand hex codes (a hex code is a short code that names one exact color), and keep the palette to 2-4 colors:

    • Accent 1 (primary brand color).
    • Accent 2 (secondary brand color).
    • Text (black).
    • Background (white).
    • Background 2 (light gray).

    Then click Save.

  7. Set typography. Go to Theme settings > Typography. Set the Heading font to a display font (a bold, eye-catching font). Set the Body font to a readable clean font, for example Montserrat. Optionally increase the Font size scale to 110%. Then click Save.

  8. Adjust layout. Go to Theme settings > Layout. If you want, increase page width to 1600 (measured in pixels, the dots on a screen). Then click Save.

  9. Remove social media defaults. Go to Theme settings > Social media. Remove the default URLs (web addresses) if you have no active accounts yet, then save.

  10. Enable the sticky header. Go to Header > Sticky header, turn on Always on, and save. Preview the page to confirm the header stays visible on scroll.

  11. Set the header menu. Leave Menu as Main menu. Set Desktop menu type to Mega menu (a large drop-down that shows many links at once).

  12. Add header contact details. Go to Header > Contact details. Add service hours (optional) and an email, for example support@yourdomain.com. Replace the email with a phone number later on.

  13. Customize header colors. Go to Header > Navigation menu color. Update the Background color, Link colors, Dropdown background, Dropdown link colors and Border colors, using only your brand palette. Then save.

  14. Configure the slideshow:

    • Use 1 slide only.
    • Delete blank slides.
    • Set Slide height to Adapt to first image.
    • Keep full width.
    • Add the hero image asset (the big main picture).
    • Add a Heading, for example a primary collection focus.
    • Add a Subheading that states a benefit.
    • Add a Button label, for example Shop Now.
    • Link the button to the relevant collection.
    • Position the content, for example bottom right.
    • Align the text, for example right.
    • Adjust button colors if needed.
    • Save.

  15. Set up the collection list (a row of group tiles):

    • Change the heading to Shop Our Featured Collections.
    • Set Image ratio to Adapt to image.
    • Set Columns to 3.
    • Optionally add a text overlay (words placed on top of the picture).
    • Add 6 collections, for example Best Sellers, Staff Picks, Top Rated, New Arrivals, On Sale Now and Under $1000.
    • Go to Shopify Admin > Products > Collections, open each one, add an Image, and save.
    • Refresh the theme customizer.

  16. Hide the rich text section (a block of free-form text). It is not needed for supplier approval.

  17. Configure the featured collection (one group of products shown in a row):

    • Change the heading, for example What's Trending in Surfing.
    • Select a collection, for example Best Sellers.
    • Set Products to show to 4.
    • Set Columns to 4.
    • Toggle Vendor (the brand name), Ratings, Secondary image and Quick View (a pop-up preview of a product) on or off as you prefer.
    • Choose a color scheme.
    • Save.

  18. Configure the email signup. Change the headline to branded text, for example Join Shaka Nation. Leave the default form. Choose a matching color scheme. Save.

  19. Configure the pre-footer. Add 4 columns, each with an icon and a short benefit headline. Example headlines: Free Shipping $100+, Surfer Owned & Operated, Fast & Secure Checkout, Easy Returns. Add links only if the pages exist. Set the background to white if it looks cleaner. Save.

  20. Hide the blog posts section. It is not needed for supplier approval.

  21. Refresh the homepage and scroll through it. Confirm the store looks legitimate, has no dead links (links that lead nowhere), uses consistent branding and has clean, supplier-ready sections.

Global settings: logo, favicon, colors, typography and layout

1 min
  • Set the desktop logo width to 200 pixels in Theme settings > Logo. The default is usually acceptable.
  • Increase the page layout width to 1600 pixels in Theme settings > Layout for a wider, more spacious look.
  • To make the page narrower instead, go to Online Store > Themes > Customize, click the gear icon for Theme settings, and open Layout. Type a value into Page width or drag the slider. Spacing and padding (the empty space around content) are controlled in the same section.
  • Note on width: the 1600 setting makes the page wider. The Page width field in the same Layout section is the way to make it narrower. This contrasts with 2024 advice.
  • Keep the global palette to 2-4 colors. Use brand hex codes and the roles listed under Colors.
  • Keep color changes in Theme settings > Colors, because every section's color scheme draws from there.

Social media links

1 min
  • Remove the default social media URLs from Theme settings > Social media if you have no active accounts. Suppliers must not click social icons that lead to Shopify's default pages.
  • Turn off the footer social media icons if you do not have real social profiles yet. Never send suppliers to a store with dead or placeholder links (placeholder means fake filler text).
  • Footer social icons in the Manhattan theme only appear for social channels that have a full URL entered in the theme customizer. Check each link, including the full https:// address, then save.
  • Footer > Show social media can stay on even with no links, because the icons only show real links. Add links later through the gear icon, in the social media fields, and make sure the show-link option is on. If no social pages exist yet, delete the empty links.
  • Do not lead the header navigation with social media links such as Facebook, Instagram, Twitter, YouTube or Pinterest. Shoppers who came to buy should first see shop pages, collections and product categories.

Conflict on footer social icons, by situation:

Situation Setting
No real social profiles yet Off (footer social media icons off)
Turning on before accounts exist Do not do it; visitors reach pages that do not exist
Profiles exist, full URLs entered On; icons show only for entered links
Show-social toggle on with no links Allowed; icons simply do not show

Source A's 2025 Manhattan footer reference value is off until social accounts exist.

Header

2 min

  • In Shopify Admin, go to Online Store > Themes > Customize. Select Header from the left sidebar. Make sure your Menu setting references Main menu. Confirm that your Desktop menu type is set to Mega menu, the standard theme default.

  • Header > Sticky header with the Always on option keeps the menu bar visible while visitors scroll. A related option shrinks the logo on scroll. This helps when the logo file is large.

  • Sticky header set to Always on keeps the menu visible while scrolling. Customers can always reach the menu without scrolling back to the top.

  • Header > Desktop logo position offers Top left, Top center, Middle left and Middle center. Top left is the common default for most stores.

  • Header > Show separator line adds a thin line under the header. It is on by default. Turn it off for a cleaner header.

  • Header mobile layout lets you move the logo on phones, for example to center or left. This is separate from the desktop position. Always save, then open the store on a phone to check the result.

  • The header in the Source D theme editor has these settings:

    • A Menu type setting (for example Sticky header).
    • A Separator line option.
    • An Enable top border option, with a color set to Use Theme Colors.
    • A Middle left position set to Main Menu.

    Scroll-up behavior is controlled by the On scroll up option.

  • Header contact details, as in the default setup: add service hours (optional), add an email, and replace it with a phone number later on.

  • Customize header colors: go to Header > Navigation menu color. Update the Background color, Link colors, Dropdown background, Dropdown link colors and Border colors, using only your brand palette. Then save.

  • A large header logo that pushes content down wastes vertical space. Use the empty header space for a short message that helps the buyer, for example free personalized note cards included with every order.

  • A header that only says "welcome to our store" is generic and wastes the top of the page. Replace it with a call to action (a short message that tells the buyer what to do, like "Shop Now") or a scarcity message (a message that says stock is limited).

  • Fast themes often ship with demo homepages and headers not built for sales. Examples include social media icons first in the header and oversized hero slideshows. Right after installing a theme, reconfigure the header, homepage and collection layout for shopping instead of keeping the demo structure.

  • Older method (2020): to place the logo in the same row as the menu, people edited code. They opened the theme editor and the code editor, then copied and pasted the required code. If you were not comfortable with code, you could hire a Shopify developer on Upwork (Upwork is a site where you hire freelancers).

  • Native option versus the older code method: the 2020 approach used header code. The current Desktop logo position setting in the Header section offers Top left, Top center, Middle left and Middle center without code.

Use a separate app (an add-on tool you install from Shopify's app store) only when the theme does not offer this, or when you prefer another solution.

Homepage structure and what to show

3 min
  • Homepage structure, in order:
    1. Show one hero value proposition (the one big promise at the top) that states the core benefit for the target audience.
    2. Link straight to best sellers (the most-bought products) and the product range.
    3. Give a short explanation of what the product does and how it differs from alternatives.
    4. Offer bundles (several products sold together) and subscriptions (repeat delivery on a schedule) to lift average order value (the average amount one buyer spends per order).
    5. Add testimonials (customer quotes) and social proof (signs that other people trust the store).
    6. Add authority logos from recognised media in the niche (logos of respected outlets in your market), placed higher up the page.
  • Arrange the homepage sections in the same order as the theme's demo store. Copying the working layout cuts setup time. Older advice (2020).
  • The home page should not replace the product page. If the home page is the only page a visitor sees, the shop is set up wrong and conversion (a visitor who buys) suffers. In a single-product store, the product should be the main page.
  • Group the homepage around one clear store theme. A homepage that mixes unrelated categories, such as gag gifts, surf, apparel and novelties with no gift theme, looks random and makes navigation hard.
  • A store must make sense within seconds for visitors arriving from a Facebook ad, a Google ad or any other source. Navigation, logo and copy should together show who the store is for and what it sells.
  • For a single-category fashion store, organize the homepage into collections by dress type. Give each collection a hero image showing a person wearing the items. This gives visitors a clear path into the collections and makes the store look like one focused range.
  • A homepage layout example uses square collection images in rows of three, followed by a row of three more. A best-sellers collection sits next to the main product collections. This layout needs six square homepage images.
  • Homepage collection tiles can be arranged in rows of three. For example, six tiles in two rows. Place the most popular collections, such as a best sellers collection, where customers see them first.
  • Remove unused default Shopify sections from the homepage, such as an empty video section or a promotions box with no content. Leftover empty sections add clutter and signal an unfinished store.
  • Competitor layouts will not map one to one onto a different theme. Rebuild the same section type (the kind of block, such as a proof block or FAQ block) with your own theme's settings. Keep the purpose of each section, such as proof, FAQ (frequently asked questions) or transformation (before and after), even when the design changes.
  • Video carousels (rotating video blocks) and slider sections are built into almost every Shopify theme, especially Atlas and Shrine. When you recreate a competitor layout, use the sections your theme already offers instead of custom development (building new code from scratch).
  • Quick navigation section above the main banner, as taught in the Source E course:
    1. Display 5-6 visual category shortcuts.
    2. Style them to resemble Instagram story cards, a visual pattern shoppers recognize.
    3. Include current sales and new product promotions.
    4. Position the section above the fold (the part of the page visible without scrolling) for immediate visibility.
  • Recently viewed products can be enabled in the theme editor under the Recently viewed products section (Settings > Enable recently viewed products). This setting applies to both collection pages and product pages. It helps returning customers, but shows nothing until a visitor has viewed products. Older advice (2021-22, Source B's theme).

Slideshow (hero)

3 min
  • Steps to set up the homepage slideshow (the rotating picture block at the top of your home page, also called the hero):
    1. Open the Slideshow section in the editor (the screen where you change how your store looks).
    2. Delete extra blank slides and keep one.
    3. Click the first slide, select an image, then click Done.
    4. Enter the heading (the large main line of text), the subheading (the smaller line under it), the button label (the words on the button) and the button link (the page the button opens).
    5. Then set the content position for desktop and mobile. Desktop means a computer screen. Mobile means a phone.
  • Full default slideshow steps (the complete setup list):
    1. Use 1 slide only.
    2. Delete blank slides.
    3. Go to Slideshow > Slide height. Select Adapt to first image, so the slide height follows the first picture.
    4. Keep full width, so the slideshow fills the whole screen width.
    5. Add the hero image asset, which means a picture file already uploaded to your store.
    6. Add a Heading (example: primary collection focus).
    7. Add a Subheading (benefit-oriented). This means a short line that says what the customer gains.
    8. Add a Button label (example: Shop Now).
    9. Link the button to the relevant collection. A collection is a group of products shown together on one page.
    10. Position the content (example: bottom right).
    11. Align the text (example: right).
    12. Adjust the button colors if needed.
    13. Save.
  • A new Shopify slideshow comes with three blank slides. Shopify is the online store software you use.
  • For a supplier demo store (a sample store that shows suppliers how your store will look), one slide is enough.
  • You can add more slides later with Add a slide, for new suppliers or seasonal sales.
  • Slideshow settings:
    • Layout: Full width or Grid layout.
    • Slide height: set to adapt to the first image, or to small, medium or large.
    • Pagination (the small markers that show which slide you are on): dots or numbers.
    • Auto rotate (slides change by themselves): set to every 3, 5 or 9 seconds.
    • Animation style: controls how one slide changes to the next.
  • The accessibility field holds a short description of the slideshow.
  • A screen reader (a program that reads the page out loud for people who cannot see well) reads this description to those visitors.
  • Something like "a slideshow about your brand" is enough.
  • Slide content settings:
    • Heading.
    • Subheading.
    • Button label.
    • Button link.
    • Desktop content position.
    • Desktop alignment.
    • Show container on desktop. A container is the box that holds the text.
    • Button color.
    • Button text color.
    • Mobile alignment.
  • In the example, the content sits bottom right, aligned right. The button label is Shop, and it links to a collection.
  • Button text must contrast with the button color. Contrast means the two colors are clearly different, one light and one dark.
  • If you change the button to a dark brand color (your store's main color), set Button text color to white.
  • Otherwise the label becomes unreadable on the slide.
  • After changes, preview the slideshow on a phone. A preview is a test view before visitors see the store.
  • If the text covers the image, adjust the mobile alignment.
  • Save only after the mobile view looks right.
  • Slideshow images that look cut off are usually the wrong size for their space.
  • Crop (cut off the edges) or resize (change the size of) the image to the required dimensions before uploading. Dimensions are the width and height of the picture.
  • This is older advice from 2019.
  • A hero image is one image shown on both mobile and desktop.
  • So you cannot upload separate versions for each screen.
  • To enlarge it on mobile, make the image taller in pixels. Pixels are the tiny dots that make up a picture.
  • Making it taller also enlarges it on desktop.
  • Hero slideshows should follow the conversion layout above, not the demo structure. A conversion layout is a page design that helps visitors take the wanted action, such as buying or signing up.
  • Oversized (too big) hero slideshows are a demo default to replace. A demo default is a sample setting that came with the theme.

Collection list

1 min

    • Heading (example: Shop our featured collections).
    • Heading size (small in the example).
    • Image ratio: set to adapt to image. Image ratio is the shape of the picture, width to height.
    • Collection description: off by default.
    • Number of columns on desktop: 3 in the example.
    • Text overlay, with position bottom left. A text overlay is text placed on top of the picture.
    • Overlay color.
  • Set the collection list grid to 3 columns when showing several featured collections on the homepage. Featured collections are collections you want to highlight. A grid is boxes arranged in rows and columns.
  • Enable view all lets mobile visitors swipe through extra collections. Mobile means a phone.
  • Turn it on if you add more collections than fit on the screen.
  • With 3 columns on desktop, six collections fill two rows on the homepage. Six is the count used in the example.
  • Add more collections only if they fit the layout and will be filled with products.
  • Example names for 6 collections: Best Sellers, Staff Picks, Top Rated, New Arrivals, On Sale Now, Under $1000.
  • These names show suppliers and customers that the store is organized and actively managed.
  • To add collections to the list:
    1. Click Collection in the collection list section.
    2. Click Select collection and pick a collection you created earlier.
    3. Click Add collection to add the next row.

  • Default setup steps:
    1. Change the heading to Shop Our Featured Collections.
    2. Set Image ratio to Adapt to image.
    3. Set Columns to 3.
    4. Add a text overlay if you want one. It is optional.
    5. Add 6 collections.
    6. Go to Shopify Admin > Products > Collections. Shopify Admin is the back office where you manage your store.
    7. Open each collection.
    8. Add an image to each collection.
    9. Save.

Featured collection

1 min
  • Featured collection section settings:
    • Heading (example: What's trending in surfing).
    • Collection (example: Best sellers).
    • Number of products: 4.
    • Number of columns: 4.
  • So four products show in one row.
  • Show 4 products in 4 columns in the featured collection section on the homepage. This gives a balanced look.
  • A featured collection section with real products on the homepage makes your store look like an active business with products to sell.
  • This matters for both supplier approval and customer trust.
  • A product card is the box that shows one product. Its options:
    • Show or hide a secondary image (a second picture of the product).
    • Show or hide the vendor (the brand or seller name).
    • Show or hide the product rating (the star score from buyers).
    • Set the sale badge position. A sale badge is a small label, such as "Sale."
    • Set the sale badge color scheme (its set of colors).
  • Quick view is a pop-up that opens a product on the same page.
  • When Quick view is on, the product opens in place, with an add to cart button. Add to cart puts an item in the shopping basket.
  • When Quick view is off, the visitor goes to the product page.
  • Use 5 to 10 products for the best sellers, top rated and staff picks sections on the homepage.
  • Best sellers are the products that sell most. Top rated means the highest reviews. Staff picks are products your team chooses.
  • This is 2023 advice. It differs from the 4-product setup above.
  • Apply the 5 to 10 rule to those sections only.

Image banner

1 min
  • An image banner is a wide picture with text on top.
  • Image Banner section on the homepage:
    1. Hide the section if you don't have content ready.
    2. If using it, select an image.

Slideshow and hero banner

4 min

Hero banner principles

  • A hero banner is the big picture and text at the top of the homepage.
  • A homepage banner should show the customer's outcome (the result they want) or passion, so a visitor immediately sees they are in the right place.
  • Its main job is to state what the business does for the customer.
  • A temporary promotion is a secondary use.
  • A hero banner needs four elements: a title, a subheader (smaller text under the title), social proof, and a call to action.
  • Social proof is a sign that others trust you, such as review counts or numbers of items saved.
  • A call to action is the button or line that tells the visitor what to do next.
  • A missing call to action is one of the most serious gaps.
  • Homepage banner pattern:

    [Store name] introducing [top-rated or number one rated] [product] for [customer type] in [country], paired with a benefit-driven image, followed by a short section on why the product helps and what the store stands for. It works because the visitor instantly sees the brand, the product and a clear benefit. Example one: Lumora introducing the top rated travel pillow for frequent flyers in Germany. Example two: Brinelo introducing the best rated desk mat for home offices in the UK.

  • Homepage structure for a niche store (a shop for one specific interest) begins with a banner that matches the feeling of the exact customer.
  • Most traffic (visitors) arrives via ads directly to product pages.
  • So keep the page clean and branded.

  • Slideshow section margins (space outside the section) add space above or below the whole section.
  • Use them to adjust the gap between the slideshow and the sections around it.
  • Keep one slide for the demo store.
  • Delete the blank default slides.

Homepage structure and order of work

4 min

Principles

  • The homepage is the first page visitors see on the root domain and the hub of the site. It should introduce the business, state what is good about it, give reasons to buy, and introduce the products sold. It connects to all other pages through the main menu, the bottom navigation and the search bar.
  • In high-ticket dropshipping the reseller sells the same products as other sites, so the homepage must sell the business as well as the products. Customers compare where to buy as well as what to buy. At launch the competition is on identical products; a brand's own products come later.
  • A weak store design holds back sales even when ads perform. Improve the store before running ads, with better images and a clear layout.
  • Homepage imagery must match the store's product type. Show people using the products and link to the category collections of that product type.
  • A homepage that mixes lifestyle photos unrelated to the products confuses visitors and makes the store look incoherent.
  • Shopify core components are the announcement bar, header, footer and the main page types (home, product, collection, cart, blog and checkout). Set up these components before adding more content.
  • The home page can stay simple with two or three sections: a banner related to the current product, the product itself, and a benefits section with badges such as priority shipping and money-back guarantee.

    4. One customer testimonial.
    5. More product images.
    6. A best-sellers section with a link to each product the visitor can choose.

Hiding vs deleting sections

2 min

A section is one block on a page, such as a banner or a product list.

  • Deleting or hiding a section can be undone in the customizer (the visual editor for your theme).
  • Deleting also removes the section's settings.
  • For a first version, hide sections with the eye icon instead of deleting them.
  • While building a theme, hide a section you are unsure about with its visibility toggle (an on/off switch).
  • This lets you restore it without rebuilding. (Shrine theme.)
  • Delete a section only when you are sure you will not need it. (Shrine theme.)
  • In the first version of a store with no content yet, hide Rich text (a formatted text block) and Blog posts (a list of articles).
  • Enable them later, once content exists.
  • To remove a section: click into it. Click the three dots at the top of the panel. Choose Remove section.
  • In a Shopify theme (Shopify is the online store software), the header, announcement bar, utility bar and slideshow sections are fixed. They cannot be removed.
  • The header is the top of the page. The announcement bar is a thin strip with a message. The utility bar is a small strip with links. The slideshow shows rotating images.
  • The footer is always part of the site.

Checkout branding

1 min

The checkout is the page where the customer pays.

Checkout branding: what can be changed

1 min
  • Shopify controls the checkout for security. It uses 256-bit encryption, a very strong way of scrambling data.
  • Because of this, the checkout cannot be fully redesigned.
  • Store owners can only add a custom logo.
  • Store owners can add a background image of about 1000 x 400 px (px means pixels, the small dots that make up a screen).
  • Store owners can change some colors and buttons.
  • Shopify Plus (a higher, paid Shopify plan) is required to customize the checkout. It costs about 2,500 USD per month.
  • Without Shopify Plus, the checkout is the same for all Shopify stores.
  • Within that limit, upload the brand font (the store's own text style) in Shopify so it appears at checkout.
  • Set the logo in the checkout settings.
  • Use a logo with trust signals (small badges that show a customer the store is safe), such as free shipping or a money-back guarantee.
  • Conflict on access means two sources disagree. One says full checkout customization requires Shopify Plus.
  • The other describes adding a checkout banner under Settings > Checkout without naming a plan.
  • Check your plan before you promise a custom checkout.
  • Conflict on size also means two sources disagree. The checkout banner is 1500 × 300 px.
  • The older source gives a background image of about 1000 × 400 px.
  • Use 1500 × 300 px for the checkout banner under Settings > Checkout.
  • Use the 1000 × 400 px background only where the older Superstore-era guidance applies.

Checkout banner and trust elements

1 min
  • Shopify checkout image: a banner shown at checkout (the checkout banner). Go to Settings > Checkout and add an image.
  • Recommended size is 1500 × 300 px.
  • Create it in Canva (an online design tool) with custom size 1500 × 300.
  • Add the logo.
  • Add trust badges such as Privacy Protected, Secure Checkout and Satisfaction Guaranteed.
  • Get these badges from Canva's Elements section (its library of ready-made graphics).
  • Add payment icons: Visa, Mastercard, PayPal.
  • Optionally add a 30-day money-back guarantee.
  • Case: a store changed nothing except adding checkout trust elements (secure checkout, guarantee, payment logos).
  • Its conversion rate (share of visitors who buy) rose from 0.29% to 2.15% in one day.
  • Its Add to Cart rate (share of visitors who click the Add to Cart button) was around 8%.

Checkout settings procedure (Superstore theme, 2021-2022, older advice)

1 min
  1. Open Checkout in the theme settings.
  2. Upload the logo as a custom image, set it to Medium size, and place it in the center.
  3. Leave error messages red.
  4. Change the button color to match the site buttons. Change the accent color (the highlight color) to the main brand color.
  5. Click Save before leaving the editor. Unsaved changes are lost.
