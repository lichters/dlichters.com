Navigation and menus

Section 4.10 · 10 of 20 in this chapter · 36 min read

In short

  • Menus are the clickable link lists on your store. You build them in the Shopify admin (the back office where you run the store).
  • Create collections (groups of products), pages, and policies first. Menus can only link to things that already exist.
  • Save after every change, then refresh the store to check it.
  • Keep menus simple: link only to what customers really use, and expect to change them later.
  • Put Refund, Shipping, Privacy and Terms pages in the menu from the Policies list. About Us and Contact Us come from the Pages list.
More key points
  • Build the Quick Links menu with its six items in the exact order given.
  • Do not build mega menus until real products and collections exist.
  • After any menu change, save and refresh the live shop to check the result.
  • Your store has three levels, and the homepage is the top one.
  • If you sell one main product, keep the top menu short.
  • Put a big search bar at the top of every page, so shoppers can find products fast.
  • Keep breadcrumbs on. Turning them off is a mistake.

Menu basics in Shopify

2 min
  • Menus are managed in the Shopify admin (the back office where you run the store) under Content > Menus.
  • Older material (2021-2022) gives the path as Online Store > Navigation.
  • Menu items can link to collections (groups of products), products, pages, blog posts, the homepage, the search page, policy pages, or external URLs (web addresses outside your store). Choose the link type in the item's Link field before saving.
  • Menu item names are free text (you type any name). They do not have to match the linked page or collection. A refund policy can be listed as Returns/Exchanges.
  • Policies appear under the Policies heading in the link search once they exist.
  • Shopify does not allow a menu item without a URL (web address).
  • Create everything first. Create all collections, pages, and policies before building menus, because menu items can only link to existing items. This includes shortcut collections such as Bestsellers and On Sale Now.
  • When searching for a collection in the link field, copy its exact name from the collections list and paste it. The search matches text, so a near-miss can return the wrong result.
  • Give each menu a unique name. Two menus with the same name cause confusion.
  • Each menu gets a handle (a short internal name) made from its title in lowercase with hyphens, for example main-menu. The theme (the design template your store uses) uses the handle to find the menu, so the default handle is what the theme looks up.
  • The header (the top area of every page) menu title is not displayed on the storefront (the public store pages), so it can keep a plain internal name. Footer (the bottom area of every page) menu titles appear as visible headings and must read as meaningful labels such as Company or Products.
  • Save after every change, because lost connections can discard unsaved work.
  • Save, then refresh the storefront. Menu changes can take a minute or more to appear.
  • Menus show on the live site only after the theme loads them, so check the live page to catch missing links early.
  • Before replacing a menu, take a screenshot of its items so the original structure can be rebuilt.
  • Deleted menu items can be re-added at any time, so removing a wrong item is not a lasting error.
  • The arrow beside a parent item (the main item that sub-items sit under) in the menu editor collapses or expands its sub-items. This only helps while editing and does not change the storefront.

Default menus in a new store

1 min
  • Sources differ on how many menus a new store starts with. One source says three default menus, and most themes include at least three menu spaces (a main menu and two footer menus).
  • Another source says two default menus: Footer menu and Main menu.
  • Check the menu list in your own admin.
  • The default main menu contains Home, Catalog, and Contact.
  • The default footer menu is initially labelled Search.
  • In older (2021-2022) default setups, the default footer menu loads the main menu items, which is not useful in the footer. Replace it with purpose-built footer menus.
  • If a theme has different menu locations, the menu positions change, but the same menu types can still be built.

Planning the three menus

2 min
  • Shopify menus organize site navigation (how visitors move around) in headers and footers, so visitors can find products and important pages without deep browsing.
  • Menus can link to collections, pages, policies, search, and external links.
  • The main menu runs across the header and can hold dropdowns (lists that open under an item).
  • The sidebar menu filters products on collection pages. Footer menus hold links at the bottom of the site.
  • Build three menus for a professional store:
    • Main Menu: product navigation at the top, using collections.
    • Footer Menu: category and promotional links.
    • Quick Links Menu: required pages and policies.
  • The Manhattan theme supports all three menus by default. Other themes typically support similar menu structures.
  • The Source A theme uses Main menu, Footer menu, and Secondary footer menu. These are assigned to the header and footer positions separately in the theme customization (the editor where you change the look).
  • The menu structure does not need to be perfect and can change as the store evolves.
  • Navigation and collections are temporary at an early stage. Revisit and adjust all menus and collections just before launch (the day the store goes public), so they match the products actually on the site.
  • There is no required number of top-level items or dropdowns in a main menu. Build the structure from the real product categories and expect to change it as the catalogue (your full product list) and suppliers grow.
  • Older (2021-2022) reference structure for a store with five collections:
Menu Location Purpose Items
Main menu Header Product category navigation Five collections, with optional dropdown subcategories
Top Bar menu Very top of the site Business and policy pages About Us, Contact Us, Shipping, Easy Returns, Privacy and related pages
Company footer menu Footer Company and legal pages About Us, Privacy, Terms of Service, Contact Us
Products footer menu Footer Entry points to categories The same five collections, no dropdowns
Shopping info footer menu Footer Buying information Shipping, Easy Returns, Price Match

Building the main menu: adding top-level category links

2 min

  • Basic procedure, from the Main Menu in Content > Menus:

    1. Open Main Menu.
    2. Leave Home as the first item.
    3. Click Add Menu Item.
    4. Name the menu item after its collection.
    5. Set the link type to Collection.
    6. Select the matching collection.
    7. Click Save.

  • Alternative procedure for the same task, with the default Home item kept:

    1. Go to Shopify Admin > Content > Menus and open Main menu.
    2. Keep the default Home item.
    3. Click Add menu item.
    4. Enter the item name (for example Surfboards).
    5. In the Link field, choose Collections, search for the matching collection, and tick its checkbox.
    6. Click Save.
    7. Add each category the same way, one item per collection.
    8. For a dropdown, add the sub-category item the same way, then drag its dot handle (the small grip dots at the left of an item) to the right so it nests (sits inside) under the item above.
    9. Repeat nesting for every sub-category that belongs to that parent.
    10. Click Save, then refresh the storefront to check that the dropdown shows under the parent item.

  • Older alternative (2021-2022) for five collections:

    1. Go to Online Store > Navigation and click the title of the main menu.
    2. Delete the default items you do not want, such as Home and Catalog.
    3. Click Add menu item.
    4. Enter the name exactly as it should appear on the site, matching the collection name.
    5. In the Link field, search for the collection by name or paste its link, then select it.
    6. Click Add.
    7. Repeat steps 3 to 6 for each of the five collections.
    8. Click Save menu.

  • Second alternative:

    1. Open the Main menu in Online Store > Navigation and remove unwanted items (for example Contact and Catalog) with Delete or Remove.
    2. Click Add menu item, search the category name, and select the matching collection. Leave the filter collection with tags field empty (tags are labels on products, and this field filters products by them) and click Add.
    3. Click Save menu, then refresh the storefront.
    4. To create a dropdown sub-item, add the item as a normal menu item, then drag its dot handle to the right under the parent item. It then appears as a submenu with a small arrow icon.
    5. Repeat for each subcategory, save, and verify on the store by hovering over (moving the mouse over) the parent.

  • Renaming an existing item: in Online Store > Navigation, change Catalog to Collections, click Apply, then click Save.

Deciding on Home

1 min

Sources disagree on the Home item:

  • Keep Home as the first item, as in the default main menu.
  • Remove Home from the main menu. Open Content > Menus, open the main menu, click delete on the Home item, then click Save. The homepage still works without the link.
  • Source E advice: put Shop first, before Home. Do not highlight Home, because the aim is to send visitors into the shop. Keep the logo as a homepage link, since clicking it already returns to home.
  • Use Shop-first when the aim is to send visitors into the shop, and keep Home when it is a sensible entry point. Both are described in the sources without a stated rule for choosing between them.

Ordering and shortening the header

1 min
  • Order header categories from left to right by sales, with the best-selling category first and the weakest last.
  • In a new store, make an estimate and change the order later based on sales data.
  • Only lead with a category that is clearly the top seller.
  • Shorten the header menu. Start it with a Shop item that opens a dropdown listing the main product categories by plain names, such as bracelets, earrings, necklaces, rings, and blankets. Avoid vague category names that visitors cannot interpret.
  • Keep the menu as simple as possible and include only links customers will use. Look at top competitors, then check your own menu from a customer's point of view to decide what to remove.
  • Use the header space for navigation to categories and collections, not for policy links, to maximise navigation options.
  • Place the logo on the left of the header so the menu takes less space and does not cover product titles.
  • Test the menu for hover sensitivity bugs (menu items that react too easily when the mouse passes over them) before scaling traffic (sending many visitors). A product page navigation that forces a visitor into another product page when the cursor hovers over the menu blocks the shopping experience.
  • Each top-level link can be a plain link, a standard dropdown, or a mega menu (a large panel with columns of links). The choice should follow how the shopper navigates the store, based on how many subcategories the link has.
  • The main menu supports plain links and dropdowns, which is enough for an early demo store (a sample store).

Store types and special items

2 min

  • A store with only three main navigation items (Shop Now, Track Your Order, and Support) is missing category links. Adding dropdown links for each product category helps visitors find what they want.

  • Place Subscribe and Bundles (recurring orders and multi-pack deals) in the main top navigation, so these options are visible on every page. This keeps higher order values (bigger orders) one click away instead of buried in a single product page.

  • When a store is built around one product category, the top navigation should link straight to the product types within it, such as dress types. Add-on products (extra items sold with the main product) do not need to take up navigation or homepage space.

  • In a gift store, build navigation by recipient group, and show the best sellers for each group under its own heading. Questions such as what people buy for men, women, parents, or grandparents each get their own section.

  • Adjust the main navigation to the products you actually have after supplier approvals, because categories from the demo store are often incomplete. Every product must be reachable from the main menu through a category, subcategory, or product type.

  • Add a main menu item called Brands or Our Brands. Its dropdown lists every approved brand, and each entry links to a brand collection that contains only that brand's products.

  • Preinstalled collections that Shopify creates by default do not need to be added to the main menu. Keep the main menu limited to the product categories you actually sell.

  • When the store is live and a collection is empty, remove it from the menus instead of deleting it. Add it back once it contains live products.

  • In a one-product store, put a direct link to that product in the header. Visitors on any page can then return to the product page in one click.

  • Procedure to add a single product link to the header of a one-product store:

    1. Go to Products and create the product, using the product name as the title and uploading its image.
    2. Go to Online Store > Navigation and open the Main menu.
    3. Add a menu item and name it with the product name.
    4. Select the Products option and choose the product.
    5. Click Apply, then Save.
    6. Open Online Store > Themes > Customize and confirm the product link appears in the header.

  • To show a collection link in the navigation, add it as an item in the menu under Online Store > Navigation. The collection link then appears in the header menu.

  • Do not send store visitors to Amazon links, because customers who leave for Amazon are lost sales. Accepting Amazon Pay (Amazon's payment method) as a payment option on your store is fine.

Creating a dropdown

3 min

  • Nesting a menu item: drag the dot handle on the left side of the item to the right, and it becomes a sub-item (an item under another item) of the item directly above it. A nested item shows as a dropdown under its parent in the storefront, with a small arrow beside the parent.

  • Older method (2019): click the menu item that should be the sub-category, drag it slightly to the right under its parent item, then click Save. The sub-items then appear when you hover over the parent item.

  • Older note (2020): nested navigation menus are created by dragging each item to where you want it to appear. Nested menus are available in any theme. A custom menu requires an app (a small add-on program).

  • Procedure for building a dropdown in the main menu, from the 2025 material:

    1. Go to Content > Menus > Main menu.
    2. Open the parent item, for example Accessories, to see its nested items.
    3. To test or reposition, drag a child item out with its drag handle so it becomes top-level, then click Save.
    4. Drag the item back under the parent so it sits as a nested child. Hold it while moving, then click Save.
    5. Reload the storefront and confirm the parent item now opens a dropdown.

  • Older procedure (2021-2022) for dropdown subcategories:

    1. In the menu editor, click Add menu item and enter the name of the sub-item, such as a product subcategory.
    2. Link the item to a page or collection. If no page exists yet, a placeholder # link (a stand-in link) can be used, but it only makes the item appear and sends visitors to the homepage.
    3. Drag the new item up and slightly to the right so it sits directly beneath the parent menu item.
    4. Repeat for each subcategory.
    5. Click Save menu.

  • Pattern for a dropdown: the parent item links to a collection, the subcategory items are nested under it, and a final sub-item named All [category] links back to the parent collection.

  • Example structure built in the guide:

  • Surfboard example from the same example: nest Hybrid Surfboards, Shortboards, Mid-Length Boards, Longboards, and All Surfboards under the main Surfboards item, and nest Bathing Suits, Wetsuits, and All Swimwear under Swimwear.

  • Procedure to add sub-items under Surfboards and check them:

    1. Add additional menu items for sub-collections.
    2. Drag sub-items slightly to the right under the main item to nest them as dropdown items.
    3. Save the menu.
    4. Refresh the store to confirm dropdown behaviour.

  • Checking a dropdown: hover over the top-level item in the live preview (the preview of the menu as customers will see it). A mega menu opens a multi-column panel with sub-groups, while a standard dropdown shows a simple list of links.

  • To restore a moved or wrong item: drag it out again to move it back to the top level. Items can be deleted and re-added at any time.

Price and filter dropdowns

1 min
  • To build a By Price dropdown in the main menu:
    1. Add a menu item named By Price and link it to Products > All products, because no price collection exists under that name.
    2. Under it, add one sub-menu item per automated price collection (a collection that fills itself using a price rule), using the exact collection names (for example the under $100 range and the 100 to 500 range). Drag each one to the right so it nests under By Price.
    3. Save the menu and refresh the store. Visitors clicking By Price land on all products and can filter by price in the sidebar.

Placeholder links in dropdowns

1 min
  • Shopify does not allow a menu item without a URL. If the collection for a subcategory does not exist yet, point the item to an existing related collection as a placeholder (a temporary stand-in), and replace the link once the real collection is live.
  • A placeholder # link on a dropdown item sends visitors to the homepage. Replace every placeholder with the real collection or page link before launch, or delete the item.
  • If a collection does not exist yet, a mega menu section can be left unlinked or linked to a temporary collection, and the link should be updated once the real collection is live.
  • In a live store, menu items should not all point to the general category page as placeholders. Each option needs its own collection, for example a beginner collection built from products tagged beginner, before the option is linked.

Building the footer

2 min

  • Procedure from the Shopify admin:

    1. Go to Shopify Admin > Content > Menus and open Footer menu.
    2. Keep the default Search item.
    3. Click Add menu item and name it after the main category, for example Surfboards.
    4. Link it to the matching collection in the Collections list, and tick the checkbox.
    5. Add more common shortcuts the same way, such as Bestsellers and On Sale Now, each linked to its collection.
    6. Click Save and refresh the storefront to check the footer.

  • Another procedure with a different example set:

    1. Open Footer Menu.
    2. Remove or keep the default Search link.
    3. Add these menu items: Surfboards (collection), Best Sellers (collection), On Sale Now (collection).
    4. Save changes.
    5. Refresh the store to confirm updates.

  • Starting footer content in one older example:

    • Rename the default footer menu (initially labelled Search) to the store name, for example Shaka Surfboards.
    • Starting items are Search, the main niche category collection (for example Surfboards), the New Arrivals collection, and the On Sale Now collection.
    • Save the menu.
    • These four items are described as a sufficient starting point.

  • Footer menus should contain common shortcuts such as bestseller and sale collections, the main product niche (your core product area), and the search item. The exact contents can change over time and depend on your store.

  • Footer links from an ecommerce example: FAQ, Return and Refund Policy, Terms and Conditions, Shipping Policy, Delivery Times, Privacy Policy, and Contact Form. The example store also had a Sign Up and Save email box offering early access and special discounts.

  • The store footer menu must link all five required pages (shipping, returns, privacy, terms, and contact us) so they are easily accessible.

  • Older (2021-2022) footer setup:

    1. Create the three footer menus in the navigation settings beforehand, for example Company, Our Products, and Useful Info.
    2. In the footer section, open each menu block (the section of the footer that shows one menu) and click Change.
    3. Select the matching menu (Company, Our Products, Useful Info) and click Select.
    4. Verify that each block now lists real pages or collections that exist on the site.

  • Older example content from the same example store: the Company menu has About Us, Contact Us, Privacy, and Terms of Service. The Our Products menu has the product collections set up for the store. The Useful Info menu has Shipping, Easy Returns, Price Match, and Why Buy From Us.

  • Footer menu rules:

    • Create at least two, and preferably three, footer menus, each with its own distinct title. Avoid generic titles such as Footer menu or Main menu.
    • Footer menus must stay flat, with no dropdown submenus, because nested items look poor in the footer.
    • Footer blocks display only the top-level links of a menu. Any dropdown items added to a footer menu will not appear on the live store, so build footer menus with the links that should be visible directly.

  • Many themes support a second footer menu displayed in an additional column.

  • Footer menu titles appear on the site as visible headings.

Secondary footer and policy menus

1 min
  • A secondary footer menu is created via Online Store > Navigation > Add menu, named Quick Links. Typical items are About Us (Pages > About us), Privacy Policy and Terms of Service (both under the Policies section in the link search box), and Contact Us (Pages > Contact us).
  • To replace the footer quick links with a policy menu:
    1. Go to Online Store > Navigation and create a menu named Our policies.
    2. Add the policy pages to that menu.
    3. In the theme editor (where you change the look of the store), open the footer and click the menu block.
    4. Click Change menu and select the Our policies menu.
    5. Click Save.

Quick Links and policy pages

3 min

  • The Quick Links menu (a list of links to key pages) must contain these items, in this exact order:

    1. About Us (Page)
    2. Returns / Exchanges (Refund Policy)
    3. Shipping (Shipping Policy)
    4. Privacy Policy (Policy)
    5. Terms of Service (Policy)
    6. Contact Us (Page)

  • Procedure to build the Quick Links menu:

    1. Click Create Menu.
    2. Name it Quick Links.
    3. Add menu items in this order: About Us (Page), Returns / Exchanges (Refund Policy), Shipping (Shipping Policy), Privacy Policy (Policy), Terms of Service (Policy), Contact Us (Page).
    4. Use Pages or Policies when selecting link types. (Pages and Policies are the two lists of store pages in Shopify.)
    5. Save the menu.

  • Second Quick Links procedure, with the policy and page sources spelled out:

    1. Go to Shopify Admin (the back office where you run your store) > Content > Menus and click Create menu.
    2. Name the menu Quick Links.
    3. Click Add menu item, name it About Us, and link it to the About Us page in the Pages list. Tick the checkbox.
    4. Add an item named Returns/Exchanges and link it to the refund policy in the Policies section.
    5. Add an item named Shipping and link it to the shipping policy in the Policies section.
    6. Add an item named Privacy Policy and link it to the privacy policy in the Policies section.
    7. Add an item named Terms of Service and link it to the terms of service page.
    8. Add an item named Contact Us and link it to the Contact Us page in the Pages list.
    9. Click Save.
    10. Refresh the storefront (the public shop that customers see) and check that all six links are present.

  • Policy pages (refund, shipping, privacy, terms) must be selected from the Policies section. (Policies is the list of legal pages.)

  • About Us and Contact Us are normal pages. Pick them from the Pages list.

  • Choosing from the wrong list links to the wrong page.

  • Quick links menu in the footer (the bottom strip of the site): in the theme customizer (the editor that changes how the store looks), go to the footer settings and select the correct menu. It will then appear.

  • In the menu setup, the header (the top area of the site) menu must be set to Main menu. The footer Quick links block must be set to the Quick links menu via Change menu.

  • Older top bar menu (2021-2022):

    1. Go to Online Store > Navigation and click Add menu.
    2. Enter a title such as Top Bar menu.
    3. Add menu items linking to your business pages, such as About Us, Contact Us, Shipping, Easy Returns, and Privacy.
    4. Click Save menu.
    5. Make sure the theme supports a top menu before expecting it to appear on the site.

  • The top bar is the thin strip along the very top of the site.

  • It only appears if the theme supports it.

  • Terms of service and privacy policy pages should appear in more than one navigation location. Navigation means the menus that guide visitors around the site.

  • Examples: a dropdown (a menu that opens when you hover over a link) under the company item, the top bar, and the footer.

  • Ad platforms (services such as Google or Meta that show your ads) may refuse to run traffic if they cannot clearly see these legal pages.

  • Showing the pages in several places, which is called redundancy, removes any doubt.

  • The phone number, Privacy Policy, Terms of Service, and Contact Us links must appear in the header and footer of the site.

  • Google checks for these links. Missing links can cause approval problems.

  • Conflict on policy links in the header. Two sets of advice disagree.

  • 2025 advice: header menus should use their space for categories (groups of products) and collections (groups of products that a link opens), not policy links.

  • put policy and business pages in the top bar and the header. Ad review (the check ad platforms run before approving ads) requires the legal links to be visible.

  • Use the top bar for policy and business pages. Keep the header main menu for categories, as the newer advice describes.

  • Menu links may not appear immediately on the website after saving. This is normal.

  • Final menu placement happens during theme customization.

  • A newly saved menu may not show in the correct spot on the storefront right away.

  • Check the menu placement in the theme settings before assuming the menu is broken.

Mega menus

11 min

Deciding whether to build one

  • Do not build mega menus for a demo store (a test shop used for practice).
  • Mega menus are expanded menus showing categories, skill levels (how experienced a buyer is, such as beginner or pro), colours, and price ranges.
  • Build them later, when real products are added.
  • A mega menu shows a dropdown as a multi-column panel (several columns side by side).
  • It splits categories into sub-groups such as product type, level, or colour.
  • It only pays off once the store has many real products with sizes, colours, or prices. So it can wait.
  • In the Manhattan theme (one of Shopify's store designs), the header settings contain an Add mega menu option.
  • The desktop menu type can stay on mega menu.
  • Adding the mega menu block is optional at the start. It can be deleted again.
  • Setting up detailed mega menus before any products are live means the menu shows empty or placeholder content (stand-in filler text).
  • Links may also point to the wrong place.
  • Add the mega menu once products with variations (versions of one product, such as sizes or colours) are uploaded and collections (groups of products) exist.
  • Mega menus make product variations such as size, colour, weight, or skill level easy to reach from the top menu.
  • Customers reach the right product page faster.
  • This tends to raise the conversion rate (the share of visitors who buy).
  • The feature is most useful once supplier (the company that provides your products) products with several variations are on the store.
  • A store can have several mega menus, for example one per main category.
  • It can also have more for subcategories (groups inside a category), such as stand-up paddle boards or car racks.
  • Only the main niche (your chosen product focus) category needs a mega menu to start.
  • The mega menu is a multi-column dropdown in the Shopify header.
  • Shoppers can browse by category, type, skill level, or colour when they hover (move the mouse over) a top-level link (a main link in the top menu).
  • It is meant to make the store easier to navigate and find products in.

What a mega menu is in the Manhattan theme

  • In the Manhattan theme, a mega menu is a built-in dropdown option under the header settings in the Theme Customizer.
  • It turns a top-level menu item into a wide panel. The panel shows subcategories, filters (choices that narrow down products), and featured products (picked products shown to draw attention).
  • It does not replace the standard menu.
  • Only the items you choose need to be converted.
  • The Manhattan theme includes built-in mega menu support through the Add mega menu option under Shopify Admin > Online Store > Themes > Customize.
  • Each mega menu affects only the item it is linked to.
  • The other dropdowns keep their standard look.
  • Each one needs its own name, link, sections, and featured products.
  • A mega menu supports up to six columns, though fewer can be used.
  • Each mega menu can have up to six columns.
  • A mega menu allows up to six sections, which can fill the full width of the screen.
  • Use only as many sections as help customers filter and find products.
  • Adding more can clutter the menu.

Fields in the mega menu settings

  • The Manhattan theme's Theme Customizer under Header > Mega menu has these fields:
    • Mega menu name (set to the collection name).
    • Mega menu link (the collection the top-level item links to).
    • Enable mega menu one item (switches the feature on).
    • An image and title for each section.
    • A link for each section title (can be left blank if no collection exists).
    • A select-menu field (a drop-down list) where a Shopify menu is chosen for that section.
    • At the bottom of each mega menu, you choose up to two products to feature.
  • Each section must be switched on with its own toggle (an on/off switch).
  • The first toggle is labelled Enable mega menu one item.
  • The following sections use the same pattern: Enable mega menu two item, Enable mega menu three item, and so on.
  • There are up to six sections in total.
  • Each mega menu column is set up separately.
  • Enable a mega menu item. This reveals a small caret (a small arrow).
  • Then choose an image for the column, set its name, and select the menu it links to.
  • The column name is the heading in the dropdown.
  • The linked menu's items appear beneath it.
  • When a mega menu item is enabled in the theme editor, it links to the main menu by default.
  • Change that link to the menu meant for the column, such as a Skill Level menu, before saving.
  • Otherwise the column shows the wrong links.

Creating the mega menu

  • Shopify places new mega menus on the right by default. It treats them as new menu items.

  • To control placement, create a new menu first, then assign it to the header.

  • A new mega menu lands on the far right of the header, after all existing items.

  • Shopify does not allow drag-and-drop (moving items with the mouse) reordering.

  • So moving it next to Home (the link back to the homepage) requires changing which menu the header uses.

  • Procedure in the Shopify theme editor:

    1. Go to Shopify Admin > Online Store > Themes and click Edit theme to access the store theme editor.
    2. In the theme editor, click Header, click Add mega menu, name it (for example Surfboards), and link it to its main collection.

  • Procedure to place a mega menu directly after Home:

    1. Go to Content > Menus and create a new menu with a Home item (linked to the homepage) and a category item (linked to the category collection).
    2. Save the new menu.
    3. Go back to Online Store > Themes > Edit theme and open the Header section.
    4. In the menu field that currently says main menu, select the new menu and save.
    5. Click Add mega menu, name it, link it to the category collection, and save.

  • Second procedure to place a mega menu after Home:

    1. Go to Content > Menus.
    2. Click Create new menu.
    3. Name it (for example Mega Menu).
    4. Add Home, linking to the homepage.
    5. Add your main category, linking to its collection.
    6. Save the menu.
    7. Go to Online Store > Themes > Edit theme > Header.
    8. Change the Menu dropdown from Main menu to the new menu name.
    9. Save changes.

  • After assigning a new menu to the header, click Add mega menu, name it, and link it to its collection.

  • This places the mega menu directly after Home.

  • Setup in the Manhattan theme Theme Customizer:

    1. Open the Theme Customizer and go to Header > Mega menu.
    2. Rename the default mega menu item to the name of the collection it belongs to, for example surfboards.
    3. In the mega menu link field, select the matching collection so that clicking the top-level item opens that collection.
    4. Turn on Enable mega menu one item and click Save.
    5. Refresh the published store to check the change. At this point the panel shows only the featured product until sections are added.
    6. Create the section content (images, titles, linked menus) in the mega menu settings.
    7. Assign the menus you created in Shopify to each section and click Save after each change.
    8. Refresh the storefront and hover over the menu item to check the result.

  • Mega menu setting from 2025: a mega menu can be deleted from the Header section of the theme editor and rebuilt from scratch.

  • This is a quick way to restart a menu layout that has become tangled (messed up).

  • It avoids repairing each column one by one.

  • The Add mega menu button under Header > Mega menu creates an additional mega menu for another top-level menu item.

  • The theme editor preview can show old values after a save.

  • Check the mega menu on the live storefront after saving and refreshing the page.

  • Do not rely only on the editor's preview.

Building the columns and sections

  • Prepare one small image per mega menu section before you configure the mega menu.

  • The section image field only lets you choose images that are already uploaded.

  • Using a different colour for each section helps you tell them apart.

  • Prepare one image for each mega menu column before building the menu.

  • The theme editor asks for an image for every column.

  • Create the menus that feed a mega menu section:

    1. Click Create menu in the mega menu section selector, which opens Shopify's Menus page.
    2. Give the menu a name that matches the section, for example surfboards.
    3. Click Add menu item for each subcategory, enter the item name, and link it to the matching collection using the Add button.
    4. Add as many items as help visitors find products easily. Keep item names and collection names consistent.
    5. Click Save menu.
    6. Return to the Theme Customizer, open the mega menu, and select the new menu for the section. If it does not appear, refresh the page and make sure the menu was saved.
    7. Click Select, then Save.

  • Procedure to fill a mega menu column with sub-links:

    1. Go to Content > Menus and create a menu named after the column, for example Surfboards.
    2. Add one menu item per option, each linked to its own collection, for example Hybrid, Shortboards, Mid-length Boards, and Longboards.
    3. Save the menu.
    4. Return to the mega menu, open the column, click Replace, and select the new menu.
    5. Save and refresh the page to confirm the links show under the column heading.

  • Procedure to fill a mega menu column, with a different sequence:

    1. In the mega menu editor, rename the column (for example Surfboards by Type).
    2. Select an image for the column.
    3. Create a new menu with the column name.
    4. Add menu items (for example Hybrid Surfboards, Shortboards, Mid-Length Boards, Longboards).
    5. Link each item to its corresponding collection.
    6. In mega menu settings, assign this menu to the column.
    7. Repeat for other columns (for example Skill Level with Beginner and Pro; Color with Blue, Yellow, Red).

  • Procedure to add another section to an existing mega menu in the Manhattan theme:

    1. Open the Theme Customizer, go to Header > Mega menu, and open the mega menu for the top-level item.
    2. Scroll down and enable the next section toggle, for example Enable mega menu two item.
    3. Select an image for the section from the images already uploaded.
    4. Enter the section title.
    5. Link the title to its collection, or leave the link empty if the collection does not exist yet.
    6. Select the Shopify menu that should appear under the title.
    7. Click Save, refresh the storefront, and hover over the top-level item to check the result.

  • After creating mega menu columns, go to Content > Menus.

  • Edit the Mega Menu and add the remaining links (for example Swimwear, Essentials, Car Racks) as simple menu items.

  • Then save.

  • To restore the other top-level links after switching to the new menu:

    1. Go to Content > Menus and open the menu used by the header.
    2. Click Add new menu item and search for each collection you want, such as Swimwear, Essentials, and Car Racks.
    3. Check the items off and save.
    4. Refresh the storefront to confirm the links appear in the header.
    5. Before replacing a menu, take a screenshot (a picture of your screen) of its items so the original structure can be rebuilt.

  • The menu selector in each mega menu section lists the default Shopify menus, such as Main menu and Quick links.

  • It also lists any custom menus you have saved.

  • A new menu appears only after it has been saved in Shopify.

  • The Theme Customizer may need to be reloaded before it shows up.

  • A Shopify menu that is not yet filled or saved may not show in the mega menu selector.

  • Refresh the Theme Customizer after creating a menu.

  • Check that the menu was saved before expecting it to appear.

  • A menu created under Content > Menus does not appear in a mega menu column's menu selector until the list is refreshed.

  • If the new menu is missing, reload the theme editor and check again.

  • Do this before assuming it was not saved.

  • Each mega menu section can link to a collection or to nothing.

  • If the matching collection does not exist yet, a section can be left unlinked.

  • Or it can be linked to a temporary collection.

  • Update the link once the real collection is live.

  • Example from a surfboard shop: the surfboards mega menu can have three sections.

  • Board type (hybrid, shortboard, mid length, long board), skill level (beginner, intermediate, pro), and colour (for example blue, pink, red, white).

  • Sections for skill level and colour can first link to the general surfboards collection.

  • Do this until filtered collections (narrower groups of products) are created.

  • Example of a surfboard store with three mega menu columns: Surfboards (Hybrid, Shortboards, Mid-length Boards, Longboards), Skill Level (Beginner, Intermediate, Pro), and Color (Blue, Yellow, Red).

  • Each was built as its own menu and assigned to a column.

  • The Color menu was added to column three after the first two were set up.

  • Choose column types that match how customers sort the products.

  • Examples: product type, skill level, colour, material, wattage, or price range.

  • Base the choice on the attributes (product details such as colour or material) the supplier data provides.

Featured products

  • A mega menu can show up to two featured products per column or mega menu.
  • Use them to highlight best sellers or priority items.
  • Choose the best-selling or highest-profit products, and update them as sales data (records of what sold) changes.
  • Choose the products you most want to sell at launch.
  • Replace them with best sellers once sales data exists.

Mega menu checklist

  1. Create your primary mega menu with logical columns that reflect how customers shop (by type, skill level, colour, brand, and so on).
  2. Add up to two featured products to each column.
  3. Add remaining menu links as simple items.
  4. Tag all products with relevant attributes. (A tag is a label on a product, such as a colour.).
  5. Expand collection filter tag lists based on your product tags.
  6. Test navigation and filters for usability.

Header settings

  • The default is Main menu.
  • Click Change to select another menu created earlier in Shopify's navigation settings.
  • The header menu is linked to the main menu by default.
  • It should stay linked.
  • Header > Desktop menu type offers Mega menu, Drawer, and Dropdown.
  • Mega menu is the option used in the example.
  • Drawer turns the menu into a hamburger icon (a three-line button) that opens in a side panel.
  • The desktop menu type offers mega menu (the default in this example), drawer, and a third option.
  • Drawer shows a hamburger icon and opens the menu in the sidebar.
  • Header menu typography (how menu text looks): the menu font size is 14 by default.
  • Font weight (how bold text is) of 500 is the usual setting for menu text.
  • Change the size only if your chosen font looks too small or too large at 14.
  • Navigation menu colour scheme used in the example: background black, first-level link white, sub menu background white, sub menu link blue, sub menu border pink, active link white (the link for the page the visitor is on).

  • In 2025 guidance, check whether a top-level item is a mega menu by hovering over it in the live preview.
  • Refresh the storefront after saving.
  • Menu changes sometimes take a minute or more to show on the live store.
  • So refresh before judging the result.
  • Save, then refresh the page.

Common mistakes

1 min
  • If you save without dragging items to the right (moving them with the mouse so they sit under another item), every item stays on the top level.
  • Then no dropdown appears.
  • Menus with placeholder # links (dummy links that point nowhere) send visitors to the homepage.
  • Mega menu columns showing the wrong links usually mean the column's menu link was left on the main menu.
  • Linking to Amazon sends shoppers away and loses sales.
  • Footer menus with nested items (items placed inside other items) show only top-level links on the live store.
  • The default footer menu loads the main menu items.
  • That is not useful in the footer.
  • Choosing a policy or page from the wrong list links to the wrong page.

Site structure and levels

1 min

A typical online store has three levels, with the homepage (the front page of the store) at the top.

Level Page Position and links
1 Homepage Root domain entry point (your main web address, like yourstore.com); links to all level 2 pages through the main menu, bottom navigation (links at the bottom of the page), and search bar
2 Collection pages (Shopify: collections) Grouped product tiles (a collection is a group of products, like all shirts; a tile is a small box with one product's picture and name); each tile opens a product page
2 Single pages (Shopify: pages) About Us, Contact Us, Shipping Policy, Privacy Policy, Terms of Sale, Returns Policy (policy pages are legal pages with store rules); linked from the homepage and navigation
2 Blog page Lists blog posts (articles); each post opens its own page
3 Product pages Reached from collection pages; use one template for all products (a template is one fixed page layout that is reused)
3 Blog posts Reached from the blog page; created only after launch

When navigation matters

1 min
  • Navigation (the menus that help people move around the site) matters most when the store has many products (hundreds or more) or a large amount of content besides product pages.
  • A single-product store needs little navigation beyond getting shoppers to that product.

Header menu

1 min

The header is the strip across the top of every page.

Keeping the header short

1 min
  • Keep the header menu short when the store sells one main product or only a few items. Use just the essential links, such as shop, collection, or the product itself.
  • Stores with many product categories can add more header menu entries to help visitors find each group.
  • Keep the top menu minimal, for example only Shop and Contact. A focused layout keeps the visitor's attention on the product description and the buying decision.

Changing the header menu

1 min
  1. Create the new menu under Online Store > Navigation with its own items.
  2. Open the header section in the theme editor (the screen where you change how the store looks) under Online Store > Themes > Customize.
  3. Change the menu setting from Main menu to the new menu.

Search bar in the header

1 min
  • Place a large, prominent, sticky search bar in the site header. "Sticky" means it stays on screen while the shopper scrolls. Returning visitors often land on the homepage looking for a product they already viewed, so the search bar gets them there fastest.
  • The search bar should show dynamic results, which means results that update as the shopper types. They appear in a dropdown (a box that opens under the bar).
  • Avoid sending shoppers to a separate search results page, because it adds one extra step.

Footer menu and quick links

1 min

The footer is the strip across the bottom of every page.

Setting up the footer menu

1 min
  1. Go to Content > Menus.
  2. Create or select a footer menu.
  3. In the theme editor, open the Footer section and the Menu - Quick links block (a box of short links).
  4. Select the footer menu instead of the main menu, since the main menu has only three items.
  5. Add links to About us, a product page, Contact us, and the policy pages.
  6. Save and refresh the preview (a test view of the page before it goes live) to confirm the links appear.

Breadcrumb navigation

1 min
  • Breadcrumb navigation is the small line of links along the top of product and collection pages. It shows where the shopper is. It adds internal links (links from one page of your store to another), so keep it on. Some store owners turn it off because they dislike its look, and that is a mistake.
  • In most Shopify themes (Shopify is a store-building platform, and a theme is the design your store is built on), breadcrumb navigation is an on/off option in the theme's settings.
  • If a theme has no breadcrumb navigation at all, have a developer (a person who writes code) add it. This is usually not a major coding job.

Further details

1 min

  • To add a mega menu (a large drop-down menu with many links at once) in Shopify, go to Online Store > Themes > Edit theme. Open the Header section in the left panel, and click Add mega menu. Name it and set its link to the relevant collection, such as the main category collection.

  • Shopify menus organize how shoppers move through the store by linking to collections, pages, policy pages and blog posts. Each theme places menus in fixed spaces, so the menus you build are shown in those spaces.
