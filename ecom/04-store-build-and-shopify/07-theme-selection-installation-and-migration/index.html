Theme selection, installation and migration

Section 4.7 · 7 of 20 in this chapter · 37 min read

In short

  • A theme sets how your store looks and works. Products and store content stay the same when you change it.
  • Upload the theme as a .zip file, not a folder. Click Publish only when the store is ready.
  • Only one theme can be live at a time. Uploaded themes stay hidden until you publish them.
  • Most visitors use phones, so pick a theme that works well on mobile.
  • A free theme is enough to start. Paid themes are not needed on day one.
More key points
  • Build every change in a draft first. The live store stays untouched.
  • Publishing replaces the live theme at once. Only publish when setup is finished.
  • Make a backup before you change any code.
  • Switching themes keeps your products, but you must redo colors, logo and layout.
  • Do not switch just because a new theme exists. A working store can stay as it is.
  • Buy themes only from the official source or a verified seller. Pirated themes can hide harmful code that breaks your store.
  • An uploaded theme is seen only by your store team until you publish it (make it live for shoppers).
  • You can publish a theme while the store is still locked with a password, so you can prepare it first.
  • When moving to a new store, export and import the theme and lists, then rebuild what did not transfer.

Theme basics and where themes sit in Shopify

2 min
  • A theme is the design package for your store. It controls how the store looks, how pages are built, and how customers use the site. Shopify provides the backend (the hidden engine that runs orders, payments and products). The theme provides the presentation (what visitors see) and the user experience (how it feels to click around).
  • The theme controls the storefront (the shop side that visitors see) and how it behaves. Products and store content stay the same when the theme changes. Themes are installed as ZIP files through the Shopify admin (the back office where you run the store).
  • Free and paid themes both change how the storefront looks and works. Products and store content stay the same. A theme is a separate layer from the store's catalog (the list of products) and settings.
  • A theme sets the overall design, the page structure, and how far the store can be customized. Any installed theme can be changed to fit the store. A theme is a structure and does not include product images or content.
  • A developer (a person who writes website code) builds the base theme and supplies all site code. The store owner adds branding (colors, images, a few settings) through the theme editor (the visual tool for changing the look). The owner does not need to code from scratch.
  • A theme provides the basic site layout and structure. After installing it, add your own branding (your name, logo and style), colors, and fonts (text styles).
  • Themes are managed under Online Store > Themes. In one source the path is written as Sales channels > Online store > Themes. The page shows the active theme (the one visitors see now) and an Add theme button. The Theme library (the list of all uploaded themes) sits lower down on the page.
  • The Themes page has a Visit theme store link near the bottom. The theme store lists free and paid themes. Paid themes are generally better built than free ones.
  • The Themes page also links to Free themes and the Shopify Theme Store (Shopify's official shop for themes).
  • The Customize button opens the theme editor. Most store layout and branding work happens there.
  • An unpublished theme (not yet live for visitors) shows Customize and Actions buttons. Use Customize only when editing.
  • A store can hold several uploaded themes, but only one can be published and shown to visitors.

The default theme on a new store

1 min
  • New accounts receive the free theme Dawn. It is the active theme from the start and stays active until another theme is published.
  • Dawn is Shopify's free default theme and a common base for a first store.
  • The course store in one source used Dawn. The source advised keeping the store simple at first. The offer (what you sell and at what price) and product images matter more than design complexity.
  • The course material of that period says a new store starts with the free theme Debut. Debut shows only placeholder content (dummy text and images) and no branding. It must be customized before launch.
  • Where sources disagree on the default, use Dawn for current accounts. Use Debut only for stores described in the older 2021-22 material.
  • The free default theme without customization looks very basic. Changing only the header (the top bar of the page) while leaving default colors in other sections creates an inconsistent look that signals a beginner.

Choosing a theme: criteria

5 min
  • Start with a lightweight theme (one that loads fast because it uses little code) for site speed. The 2022 advice recommended the Charlotte theme.
  • Speed is one of the first things to check. Check a theme on stores that already run it. Run speed tests (tools that measure how fast a page loads) on those stores before buying.
  • Check when the theme was last updated and how long its developer has supported it. Themes untouched for four or five years can produce errors with the current Shopify framework (the base system the theme runs on).
  • Use a mobile-responsive theme (one that adjusts its layout to fit phones). Most purchases now happen on phones. A web-only theme loses sales to competitors and needs a full rebuild.
  • Mobile traffic (visitors arriving on phones) can be 80 to 90 percent of visits. The theme should work well on phones out of the box. Mobile-only design changes that differ from desktop need a developer. Make them only when a specific error or problem appears.
  • Check every key page at laptop-width screens too, as well as desktop and mobile. If the theme stops at a fixed maximum width, the side margins stay cramped. The white space (empty space that keeps a page easy to read) disappears. Choose a theme that scales to wide screens.
  • Prefer a theme with minimal, clean code (little, tidy code). Theme and app (an add-on program) code quality varies. Some popular-looking themes are coded inefficiently and slow the page.
  • Choose a theme with built-in features, so fewer third-party apps (add-ons made by other companies) are needed. Fewer apps generally means faster pages and fewer plugins (small add-ons) to maintain.
  • A premium (paid) theme is worth choosing over a free one when it already includes conversion elements (parts that help visitors become buyers). The store then needs fewer paid apps for the same features.
  • Before buying a paid theme, check that it supports the features you need. Examples are bundles with variants (one package with size or color options) and free gift offers. Themes that lack these features may force a costly workaround (a messy fix).
  • Give the person building the store clear written requirements. Make sure the theme is installed correctly and reviewed before launch. A poorly installed theme can make a store look messy.
  • Choose the base theme with your planned amount of custom work in mind. A simpler base with fewer built-in features can be easier to customize heavily than a feature-rich theme.
  • A dropshipping-focused theme is built for dropshipping (selling products that a supplier ships to the buyer, so you hold no stock). It can be more efficient than comparing many general themes. The theme affects both conversion and setup effort. Treat claims about higher conversions as unverified (not proven) until you test them on your own store.
  • Manhattan is built specifically for high-ticket dropshipping (selling expensive products through suppliers). It is optimized (tuned) for higher conversions and supplier-ready presentation (a look that makes supplier products look good). It includes features that usually need paid apps. This lowers setup cost and complexity compared with choosing and buying individual apps.
  • The higher-conversion claim for Manhattan is a vendor statement (what the seller says). Test it on your own store.
  • A dropshipping-focused theme can be customized in every element. The same theme works for an elegant brand look or a playful one. It is a free download for stores built on the blueprint (the course's build plan).
  • Pick a theme you expect to be happy with long term. Switching themes costs time that could go to revenue-generating work (work that brings in money). Themes from established vendors that do what you need are a sound choice.
  • Buy themes only from the Shopify Theme Store or from established theme vendors (companies that sell themes). Unverified theme code can contain malicious code (harmful code) and cause problems later.
  • Choose a theme from the Shopify theme store or from a trusted, certified developer (a builder with proof of skill). A developer who builds themes full time, with a team of about 3 to 5 people, is a stronger choice. A person who sells a theme as a side project is a weaker choice.
  • Before adopting a third-party theme (one made by another company), check community discussions about the vendor's support quality. Poor support can leave your customizations broken. Search the store owners' Facebook group for the theme name to see what other users report.
  • Shopify planned to separate theme design from store content. A theme could then be replaced without rebuilding all content. Once available, this would make theme updates faster. It would also reduce the need for third-party page builders (add-on tools for building pages, such as PageFly or Shogun), which may become less useful as native (built-in) features improve.
  • A brand that takes branding seriously usually needs a custom build from a design file. One example is a pixel-perfect (exact copy) conversion of a Figma design (a design file made in the Figma tool) into a Shopify store. Prototyping (making a quick test version) in a page builder first, then having a developer make a polished version, is a common approach among high-revenue brands.
  • A plug-and-play store theme (one that works right after install) gets a high-converting store running fast. You do not build a website from scratch. It reduces development time, so the focus can move to marketing and sales.
  • Shopify beginners do well with a theme that has many built-in features and handles most of the layout work. Its graphics (images) are simple to make and upload and need little design skill. Other themes need their own graphic sizes. Confirm the chosen theme's sizes first.
  • For beginners without web design experience, the Source A theme is a strong choice. It has many features and needs little design work from the merchant (the store owner). Its graphics are simple to upload because the theme handles much of the layout.
  • Free Shopify themes suitable for beginners include Sense, Refresh and Dawn. Find them under Online Store > Themes. You can use them right after sign-up.
  • The course material pointed to Refresh as a starting theme for a first build.
  • Winning Hunter's Sales Tracker Details page (a page in a tool that tracks competitor stores) shows which Shopify theme a competitor runs. It also shows the launch date and shop URL (web address). Note the theme when you study a competitor's build. It shows what a working store layout looks like on that platform.

Free versus paid

1 min
  • A free theme is enough for conversions unless a paid theme has built-in functions you cannot get elsewhere. Beautiful design alone does not drive sales. Speed plus trust matter most.
  • Premium paid third-party themes, some costing around 500 dollars, are not needed to start. A free theme is enough. The theme is not what makes a store profitable.
  • Premium themes are worth the cost because they are highly customizable, load fast and come with strong support. A store with many products benefits most from these features.
  • Out of the Sandbox themes are recommended for large-inventory stores when the budget allows.
  • Upgrading to a paid premium theme was seen as sensible once the store earns good revenue. One source bought a premium theme for about 200 USD with a 20 USD discount.
  • Premium Shopify themes from paid developers can retail for around $300. Budget for this if the theme is not included free with a course or purchase.
  • Off-the-shelf (ready-made) premium themes are a far cheaper route than a fully custom theme. A custom theme can cost thousands of dollars.
  • Free line item property code snippets (short pieces of ready-to-paste code) exist online. You can add them to a Shopify theme by hand.
  • Ecomify Pro was a one-time payment of $249 when the material was made. Lite was free. Upgrades to the next major version were announced as small fees of about $50 instead of a new $249 payment.
  • Check the current price on the store page before buying. Sale prices can differ from standard prices.
  • Prices differ between sources and dates. Treat each figure as the price at the time of its source.
    • About 180 USD for a Theme Store listing.
    • About 300 USD for a comparable premium theme (same period).
    • About 200 USD for a premium theme bought at a discount.
    • 300 to 500 USD for Out of the Sandbox themes.
    • About 500 USD for the high-end paid themes that a free theme replaces.

  • Charlotte versions: Charlotte 1.0 was the original download from the blueprint.
  • Version 1.3 is the latest downloadable Charlotte version, released 21 February 2022.

  • Source A version: the newest Source A theme was last updated 12 December 2022.
  • A later source named version 1.3 as current and said the course downloads carry it.
  • Charlotte or Manhattan for an existing store: a new store should use Manhattan. An existing store on Charlotte does not need to be switched.
  • Speed: older advice (2022) recommended Charlotte for speed. Later advice says Manhattan is somewhat faster than Charlotte. Use the newer comparison when choosing for a new store.
  • Premium value: for large-inventory stores, premium themes are worth the cost. For a starting store, a free theme is enough. Use the premium argument only when the store has the volume or features to justify it.
  • Publishing a new theme: publish straight away only on a brand-new store with no other active theme in use. On a store that already has visitors and sales, keep the theme unpublished until setup is finished.

Fixing a zip download on a Mac

1 min
  • On a Mac, downloading a.zip file can automatically unpack it into a folder. The folder shows as a blue folder icon instead of a zip icon. Uploading that folder fails because Shopify needs the.zip file.
  • if macOS unzipped the theme, re-zip the folder (pack it into a new zip file). Other folder types fail to upload.
  • Fix a Mac download that was unpacked into a folder:
  1. Right-click the blue folder.
  2. Choose Compress (make a new zip file) with the theme file name (for example Source A Manhattan) from the menu.
  3. Use the new.zip file that macOS creates for the upload.

Uploading a zip file

1 min
  • Upload a theme to Shopify (current procedure):
  1. Go to Online Store > Themes and open the Theme library.
  2. Click Add theme.
  3. Click Upload zip file.
  4. Drag the.zip file into the upload area or select it, then click Upload file.
  5. Wait while the message Installing theme appears. This takes about 30 seconds while Shopify processes the file.
  6. Check that the new theme appears in the Theme library with its name and version number, for example Manhattan version 2023.
  7. Click Publish only if the store has no active theme in use yet. This is the case for a brand-new store.
  • Processing a theme file takes about 30 seconds. The progress message Installing theme appears during this time.
  • Large theme files take a while to upload. Wait until the theme shows in the Theme library and the installation has finished. Then click Publish.
  • A theme uploaded to Shopify is unpublished by default. Uploading it does not change what visitors see. You can edit the new theme safely before publishing it.
  • Uploading a theme does not activate it. The previously published theme, usually the default Shopify theme, stays live until you click Publish on the new theme.

Upload procedure

1 min
  1. In the Shopify admin, go to Online Store > Themes.
  2. Click Upload theme under Theme library.
  3. Click Add file and select the theme file. It must be a.zip archive. Re-zip the folder if macOS unzipped it automatically, because other folder types fail to upload.
  4. Click Upload file and wait for the upload to finish. The theme is added unpublished by default. The maximum file size is 50 MB.
  5. Click Actions on the uploaded theme. Use Customize only when editing. Do not change the code editor settings in Actions at this stage.
  6. Click Publish, then confirm with Publish again. This replaces the current theme and makes it the active theme.
  7. Preview the store using the eyeball icon to check the change.

Updating a theme

3 min
  • A new theme version is not an automatic update to an existing store.
  • It has to be uploaded and installed like any other theme. Plan the switch and test the store before going live.
  • Theme updates are not applied automatically.
  • The developer notes what changed and how to apply it, because automatic updates could break a customized store.
  • Before updating a Shopify store theme, confirm which theme version is installed.
  • Ask support whether the update will keep your customizations.
  • Do not assume a theme update will leave custom changes intact.
  • Upgrading a theme without losing the live store (2020):
  1. Open the Shopify admin.
  2. Go to Online Store, then Themes.
  3. Upload the newest version of the theme.
  4. Adjust colors and layout in the draft. This does not change the live store.
  5. Click Publish only when the draft is ready.
  6. If needed, republish the previous theme.

Shrine Pro setup

2 min
  • Premium themes (paid themes) are worth choosing when they include conversion elements. Then the store needs fewer paid apps.
  • Shrine Pro was chosen because it has the most sections of the Shrine theme versions.
  • One license is enough for one store. A license is permission to use a paid theme.
  • The email address entered at checkout for a Shrine license must be correct.
  • The license keys (codes that unlock the theme) are delivered to that address. A wrong address can prevent access to the keys.
  • Set up a premium Shrine Pro theme in Shopify, in this order:
  1. Open the Shrine Pro page and click Get started.
  2. Select one license, because only one store is being built, and click Add to cart.
  3. Click Checkout.
  4. Check that the email address entered at checkout is correct.
  5. Accept the terms and conditions, click Complete purchase, and then click Continue.
  6. Open the email from Shrine that contains the license keys, and click Open Shrine Dashboard. The dashboard is your Shrine account page.
  7. If there is no Shrine account yet, click register and create an account, then log in.
  8. Click Next step, then click Add key, and enter the license key to activate it.
  9. In Shopify, go to Settings > Domains and copy the myshopify.com URL. This is the free web address Shopify gives your store.
  10. In Shrine, go to Settings > Accounts > Whitelist your URLs. Whitelist means adding addresses to an allowed list. Paste the myshopify.com URL into the Shopify URL field, with https:// in front.
  11. Copy the custom domain of the store from Shopify Settings > Domains. Paste it into the Main URL field, with https:// in front. If a second website URL exists, add it in the Secondary URL field the same way.
  12. Click Save and generate token, then copy the authentication token and store it safely. A token is a secret code that links the theme to your store.
  13. Download the theme zip file from Shrine.
  14. In Shopify, go to Online Store > Themes, click Import theme, upload the zip file, and select the Shrine Pro theme file. Wait until the upload has finished.
  15. Click Publish to make the theme live, even though the store is still password protected.
  16. Click Customize to open the theme editor and add sections.

Moving to a new Shopify store while reusing content

1 min

Moving to a new Shopify store while reusing content (using again what you already built):

  1. Create the new store with another email (a different email address).
  2. Export (save a copy of) the theme from the online store section and import (load) it into the new store.
  3. Export and import the customer and SMS lists (lists of customer contacts for text messages), and set up the email settings and apps (add-on tools) again. Shopify's export and import buttons handle the data.
