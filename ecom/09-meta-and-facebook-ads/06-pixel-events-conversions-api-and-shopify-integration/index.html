Playbook › 9. Meta and Facebook ads

Pixel, events, conversions API and Shopify integration

Section 9.6 · 6 of 22 in this chapter · 24 min read

In short

  • Since iOS 14 (Apple's phone update with privacy limits), tracking is weaker, so connect the store to Facebook with maximum data sharing.
  • Even with maximum sharing, you get back only part of the lost tracking. Do not expect every sale to show up.
  • Set up Facebook's tracking code (the Meta Pixel) and the events Add to Cart, Initiate Checkout and Purchase, or Facebook has nothing to learn from.
  • While you test, keep one pixel per niche (a product market) and share it between products in that niche.
  • Before you confirm any link, check that the two IDs match: the ad account ID and the pixel ID.
More key points
  • Test your tracking before you trust it. A test purchase should create a Purchase event (a record of a sale).
  • Set products to active, publish them, and wait for "Catalog in sync" before running ads.
  • Keep each product description under 5,000 characters, or Facebook will not publish it.
  • Pick the correct Business Manager, page, profile and pixel, or your store connects to the wrong account.
  • Setup is not finished until test events appear in Events Manager.

iOS 14 Limits and Why Server-Side Tracking Matters

2 min
  • Since iOS 14 (Apple's phone software update with privacy limits), tracking with cookies (small files that follow a visitor around) is limited.
  • The Conversions API (a way to send data from the store's server straight to Facebook and Google, server to server) helps. So connect the store with maximum data sharing to keep tracking accurate.
  • Connecting Shopify (online store software) directly to Facebook through its built-in integration uses the Conversions API. This keeps conversion tracking (counting sales from ads) reliable after the iOS 14 privacy changes.
  • Linking Facebook and Shopify with the correct pixel setup (a tracking code on the store) from the start still recovers some data. Some data is lost through Safari (Apple's web browser) blocking. Nothing fully restores tracking from before iOS 14.
  • Maximum data sharing with the Conversions API recovers only part of the tracking lost after Apple's iOS 14.5 changes. Do not assume it brings back all lost conversions.
  • After the iOS update, many conversions are not tracked. So the pixel needs larger audiences (the groups of people your ads reach) to find results.
  • Audiences of around 40 to 50 million or more give the pixel more data than tightly restricted ones.
  • Remarketing (showing ads again to people who visited before) audiences shrank after iOS 14. The minimum usable remarketing window is now about seven days. A window is the time span of past visitors you target. Make windows as large as the traffic allows, instead of very narrow.
  • Before iOS 14, a site with a few hundred daily visitors could split Facebook remarketing into windows of 2, 4 and 7 days, then wider windows beyond 7 days. These narrow windows no longer work well, because audiences shrank after the update.
  • Audience changes by device (phone or computer) for Facebook and iOS are not required at small ad budgets. They matter more as spend and audience size grow.
  • The Facebook ad guidance (the advice for running ads) was updated after the iOS privacy changes. Current practice differs mostly in how Shopify connects the store to Facebook ads.
  • Set Shopify's Facebook data sharing to maximum. This lets Meta (the company that owns Facebook and Instagram) capture more users for remarketing.

Prerequisites and Account Structure

2 min
  • Meta Pixel: a tracking code on the store. It reports visitor actions, such as add to cart, checkout and purchase, to Meta. Meta uses this data to learn which people are likely to buy and to optimise ads (improve who sees them).
  • Events must be configured. In Events Manager (Meta's page for tracking actions), set up Add to Cart, Initiate Checkout and Purchase. This tells Meta which actions count as success.
  • Events that are not configured give Meta no signal to optimise towards.
  • Backend setup order between Facebook and Shopify. The backend is the behind-the-scenes setup. Do these steps in this order:
    1. Connect your Facebook Page to Shopify, so Facebook knows which store to send people to.
    2. Verify your domain, which proves that you own the website.
    3. Create your Meta Pixel and connect it to the store.
    4. Configure events in Events Manager for Add to Cart, Initiate Checkout and Purchase.
    5. Add a payment card, because Meta needs a way to charge ad spend (the money your ads cost).
  • Connect a Meta Pixel to your existing Business Manager (business portfolio, Meta's hub for your business accounts). Do not create a new one. The pixel is a dataset (Meta's name for a pixel). It lives under the Business Manager and is linked to the ad account from there.
  • Domain verification: when Meta and Shopify are linked through the Meta sales channel, the integration handles domain verification. A separate meta tag in theme.liquid (the main code file of a Shopify theme) is not needed. (2025)
  • Connecting the online store to the Business Manager is a separate step after domain verification. It is required before running dynamic remarketing ads (ads that show the exact products a visitor looked at).
  • Requirements for complete conversion data (sales counted correctly): a connected and verified domain, the Shopify Conversions API integration, and the tracking data switches turned on. Without all three, conversion data is incomplete.
  • A Meta Commerce account (a Meta account for selling products) must be created inside the Meta Business Manager. Then the Shopify products can be placed in the Business Manager. This is required for dynamic remarketing with product catalogs (lists of your products for ads).
  • A pixel you create yourself, outside the Business Manager and the Shopify integration, may not connect properly. Always create the pixel from the business portfolio that owns the ad account, and connect it through the partner setup.
  • Setting up the connection and the Commerce account does not spend any ad budget. Ads are created in later steps.

Creating the Pixel (Dataset) in Meta

2 min
  • The pixel must already exist in Meta Events Manager before you link it in Shopify. If no pixel exists, Shopify's dataset step offers a Create new option instead of listing an ID.
  • Create the pixel in Meta Business settings:
    1. Go to Business settings and open Data sources.
    2. Open Data sets. The pixel was moved from its former location to data sets.
    3. Click Add, then Create new data set.
    4. Name the data set after the store and click Create.
  • Ad set > Conversion > Dataset is the Meta pixel. An ad set is a group of ad settings. This should already be selected by default. If no pixel exists, create one, add it to the website, and grant the needed permissions to the user and the Business Manager.
  • Create a new Meta pixel for each new product test. You create it yourself inside the account, so it does not need to be bought.
  • Alternative to Shopify: install the Facebook pixel directly through Facebook, and the Google pixel directly through Google. This keeps full control over tracking and retargeting (showing ads again to past visitors).
  • For a beginner who wants to start immediately, Perfect Audience (a tracking tool) can track both Facebook and Google visitors with one line of code on the site.
  • Three ways to set up the pixel on the Set up Meta pixel screen:
    • Add the pixel code to the website yourself (marked Recommended).
    • Send instructions to a developer.
    • Set up with a partner such as Shopify or WordPress. For a Shopify store, the partner route connects the pixel through the Shopify integration.
  • Traffic route: send Facebook traffic (visitors from your ads) to your Shopify store, rather than using Facebook's built-in direct-sell option. This was the practice as of early 2023 and may change.
  • Facebook Commerce Center (Facebook's shop-building area): the new Facebook sales channel uses it. It needs fewer apps and no extra fees, which makes setup easier than the older process.

Connecting Shopify to Facebook and Instagram

3 min

Two procedures reach the same Facebook & Instagram channel (the link between Shopify and both apps). Use procedure A for the current Shopify flow. Procedure B is the order used in a separate setup.

  • Shopify app: install the Facebook & Instagram app from the Shopify App Store. The developer is Meta. It is free to install, but additional charges may apply. Then click Get started and log in to Facebook.
  • The personal Facebook profile is used only as the access route to the business accounts. It is not the owner of the pixel or catalog.
  • Shopify asks for a business portfolio. A portfolio that does not meet Meta's requirements for shops cannot be selected. The Connect button stays unavailable for it. In that case, choose Create new business portfolio or pick a portfolio that qualifies before connecting.

Procedure A

  1. In the Shopify admin (Shopify's back office), install the Facebook & Instagram app and click Get started. Then connect your Facebook account.
  2. Under Set up Ads on Facebook and Instagram, connect the business portfolio (Business Manager) that owns the product catalog. Choose or create a catalog, and accept Meta's Product Catalog Terms.
  3. Under Manage Facebook & Instagram data sharing preference, select Maximum and save. Maximum shares the most data with Facebook. It uses the Meta Pixel, advanced matching (extra customer details sent to Meta) and the Conversions API.
  4. Submit for review and wait while the channel setup finalizes. This takes several minutes. Do not refresh.
  5. In Ads Manager (Meta's page for running ads), open the ad account. Then open Events Manager from the left column.
  6. Choose Connect data, select Web, then Create a new dataset (pixel). Leave the name field empty if you wish. Agree to the Meta Business Tools Terms.
  7. Choose the option to set up the pixel with a partner (Shopify). Go to Shopify and confirm the connection.
  8. In Shopify, make sure the Facebook and Instagram sales channel is installed. Set the data sharing to Maximum.
  9. Return to Events Manager and click Next. The status stays inactive until test traffic is sent.
  10. Click Send Test Traffic, then Finish.

Procedure B

  1. In the Shopify admin, go to Sales channels. Search for Facebook (the Facebook & Instagram app), then click Get started.
  2. Click Connect account.
  3. Log in with the Facebook profile you want to use. Shopify uses this personal profile only to access your business accounts. Review the requested access (name and profile picture, view access) and continue.
  4. Choose the business profile that owns the ad account you want to use (the one you created in your ad account).
  5. Choose the data sharing preference. See the data sharing section below.
  6. In the dataset step, select the existing pixel. If no pixel exists yet, click Create new.
  7. Click Confirm, then wait while Shopify shows Finalizing channel setup.
  8. Continue to the catalog step and sync products (send your product list to Meta).

Procedure B also notes that if you have a product catalog, you should connect the business portfolio that owns it during setup. You can manage how your products are advertised later.

  • The Set up Meta pixel screen for Shopify is handled through the partner route. The pixel connects through the Shopify integration.
  • Changing the connected Business Manager: remove the existing Facebook channel or business manager connection in the Shopify Facebook app. Then connect the new Business Manager there.
  • Older Shopify procedure (2022): enable the Facebook pixel under Online Store > Preferences. Choose the highest level of data sharing in the customer privacy settings. Then connect Shopify directly to Facebook, since this is used for the product feed (the product list sent to Facebook).
  • Orders bought through Meta still appear in Shopify if the purchase runs through your Shopify store. The checkout option you choose in Meta does not change this.

Data Sharing Levels in Shopify

1 min

Shopify's Facebook & Instagram data sharing preference has three choices: Conservative, Enhanced and Maximum. Shopify shows the choice as "Manage Facebook & Instagram data sharing preference" and "Choose your data sharing preference."

Level What it means Source When it applies
Conservative Listed as a choice; the sources give no further detail. Not used in the setups listed here.
Enhanced Customer activity is sent through the Meta Pixel, advanced matching and the Conversions API. Customers can stop this from their own Facebook account settings. Used in one setup. Maximum is also a valid choice.
Maximum Shares the most data with Facebook. Uses the Meta Pixel, advanced matching and Conversions API. Continually updated with Meta's latest ad technology. Recommended by most sources for the best possible results.
  • Shopify's setup guidance cites a 17.8% lower average cost per result for advertisers who used the Conversions API alongside the Meta Pixel.
  • Meta reports that sending customer data through both the Meta Pixel and the Conversions API together lowers cost per action (CPA, the money paid for each wanted action). This is compared with the Pixel alone. This is why Enhanced combines both channels.
  • Data sharing is a single setting. If it is correct, the audience sizes in Meta should be correct.
  • Maximum sends customer personal data to Meta. Before saving the setting, the store's privacy policy must describe how personal data is used and shared with third parties such as Facebook. Shopify's share data settings are where this preference is chosen.
  • Maximum data sharing is also needed for purchase conversions to appear in campaigns. Without it, the Purchase event may not reach Meta. The Purchase option will then not appear in the Meta campaign event drop-down (the list where you pick your goal).

Dataset Settings and Verification

2 min
  • Website settings in the dataset (Events Manager > Settings):
    • Turn on Automatic website matching. It uses hashed customer data (scrambled email or phone details that can match people but not be read) to match customers to Meta accounts. This helps attribute more conversions (credit sales to ads) and supports remarketing.
    • Turn on Automatic advanced matching.
    • It is recommended to keep website matching on and track events without code. The dataset feature turns off after 90 days of inactivity.
  • Auto-tracking in dataset settings: turn it on only when you want campaigns to draw on offline events (sales made outside the website, such as in a physical shop) from this dataset. This is for ad tracking and attribution. Once enabled for an ad account, every new campaign there uses this dataset for offline event tracking by default. Keeping it off is a valid choice if you have no plans to use it.
  • Extend attribution uploads (Events Manager > Settings) can extend the offline event upload window from 7 days to 90 days. Use it only if your business cannot upload events within at least seven days after they occur. Extensions apply only to offline events from a physical shop.
  • Sharing a dataset: open the dataset's Settings in Events Manager, go to Sharing, and choose Share With an Ad Account. To give another business portfolio access instead, use the option Give another business portfolio access to this dataset.
  • Verify the connection. Check that the pixel ID (the pixel's number) is linked to the ad account ID (the ad account's number) in Events Manager and the Business Manager. Check that the pixel status shows connected to the ad account. Check the pixel ID and ad account ID on both screens.
  • In Events Manager under Integrations, the Shopify (online) entry should show the status Connected and the number of pixels connected to it. The dataset page should show it as connected to one ad account.
  • Events Manager pixel tabs: Overview, Test events, Diagnostics, History and Settings. The Overview's event table shows Total events and the Last received time for each event, such as Add to Cart, Initiate Checkout and Purchase. Use it to confirm that data is flowing.

Find and verify the two IDs before linking

  1. Ad account ID: open Ads Manager and check the ad account selector. The numeric Ad account ID is shown under the account name.
  2. Pixel ID: open Events Manager and select the pixel, which Meta now lists as a dataset. The numeric ID is shown on its overview and in the page URL.
  3. In Shopify, confirm that the selected business profile and ad account match the ad account ID from step 1. Confirm that the dataset matches the pixel ID from step 2.
  4. Confirm the link only when both IDs match.
  • If the pixel ID selected in Shopify is wrong, the whole ad optimization process does not work. Always compare the selected ID with the pixel ID shown in Meta Events Manager before confirming.

Auto Advanced Matching

1 min
  • Auto advanced matching lets Meta collect more customer data from the website, such as phone number and address. This makes remarketing more precise. Turn it on in the Meta ad account.
  • Shopify setup places the same setting in Events Manager > Settings, next to Automatic website matching. Use Events Manager, and keep website matching on.
  • A new Meta pixel knows nothing about who buys. It learns from view, cart, checkout and purchase events. So more events on the store mean faster and better audience learning.

Conversion Event for Optimization

1 min
  • For a new store, set the Meta ads conversion event to Purchase from the start, because the goal is sales. This comes from one expert's experience. Some advertisers start with Add to Cart.
  • Set up the new Facebook pixel site-wide (across the whole store). The optimization event options include Checkouts, Registrations, Leads, Key page views, Adds to cart, and other website conversions. Adds to Cart was reported as the strongest option.
  • Optimizing for Adds to Cart gave a better actual purchase conversion rate than optimizing for purchases. It only pays off if you also have a follow-up sequence (a series of messages) for people who added to cart. Even if you already run ads, switch the optimization event to Adds to Cart.
  • Choose between the two:
    • Purchase from the start (for a new store, based on one expert's experience), or
    • Adds to Cart (when you have a follow-up sequence for cart abandoners, meaning people who left without buying).

One Pixel per Product or per Niche

2 min

Sources differ on when to split pixels. A niche is a product market, such as one topic. The split points are given below, each with its own condition.

Situation Pixel rule Source
Two valid strategies (1) One pixel per product, which is stricter and gives clean data per product. (2) Several products under one pixel, with a new pixel after 3 to 5 failed tests. Both are accepted; the choice depends on how strict you want the test to be.
Testing 3 to 5 failed products of different niches Create a new pixel and start a new data set for the next products.
Same niche, all product tests Run all product tests on the same pixel.
Winner found (a product that sells well) and a new product in a different niche Use a different pixel.
Switching to a completely different niche Install a new pixel. The same ad account can usually stay.
Five products in one niche test Use one pixel for all five, so the pixel does not change each time a product is added.
Product takes off profitably at about 100 conversions Create a new pixel for that product. Below about 100 conversions, the pixel has too little data for a change to make a difference.
Fewer than about 5 sales per day Sharing one pixel between products is acceptable while testing.
About 10 to 15 total sales Sharing one pixel across different niches is acceptable. With more data, keep one pixel per niche.
Purchase volume about 100 or more Share one pixel until the store reaches about 100 or more purchases.
20 purchases Too little data to need a second pixel.
  • Keep one pixel per niche, so its data stays focused on that niche. Keep purchase data from one niche separate from another. Products within the same niche can share one pixel while testing.
  • Keep one pixel while testing. The pixel only starts to optimize well after roughly 10 sales for a product. Until then, Facebook's own targeting does most of the work. So the pixel matters less during early tests.
  • In the first test phase, the pixel mainly collects data and does not drive sales. Pixel data becomes important once a product has real sales.
  • In the early stage, with only a few sales, several products can share one ad account and one pixel. The pixel is still gathering data at this point rather than driving sales.
  • A pixel becomes tied to the niche it has been used for over months. When switching to a completely different niche, install a new pixel.
  • A new pixel gives Meta's algorithm (the system that picks who sees ads) a clean data record. So it learns faster than from a pixel with many failed tests attached. Creating a new pixel after failures restarts the learning process.
  • Keep the same pixel when testing products in the same niche. Consider a new pixel when switching to a different niche. Both approaches can work. A new pixel gives more separate data to compare.
  • Each new ad account needs its own new pixel.
  • Sharing a dataset with another ad account is possible through Share With an Ad Account.

Testing the Pixel: Test Events and Pixel Helper

1 min

Meta Pixel Helper

1 min

  • The pixel is a small piece of code that records what visitors do on your store. Meta Pixel Helper is a free Google Chrome extension (a small add-on for the Chrome browser) that checks it. Meta is the company behind Facebook and Instagram. (2025)

  • Pixel Helper shows which Meta pixel is installed on the current page. It also shows the pixel ID (the pixel's unique number), the events it fires (sends; events are recorded actions), and the page URL (web address). (2025)

  • Use it to debug pixel tracking (find and fix errors) before you rely on the data. (2025)

  • It shows whether the Meta Pixel is installed on a page. It also shows whether the pixel is firing correctly. (2025)

  • Purchase test with Pixel Helper:

    1. Install Meta Pixel Helper in Google Chrome.
    2. Create a temporary product priced at about $1 in your Shopify store (online store software), then buy it.
    3. On the order confirmation page (the page shown after payment), open the extension. Check that a Purchase event was triggered.
    4. If no Purchase event appears, the connection between Shopify and Meta is at fault. Check the Facebook & Instagram sales channel settings in Shopify. A sales channel is a link that shows your products on those apps.

Test events in Events Manager

2 min

  • Test events procedure:

    1. Open the dataset (the container that holds your pixel's data) in Events Manager (Meta's screen for checking pixel data). Go to Test events, enter the website URL and click Test events.
    2. Take actions on the site, such as View content, Add to cart, Initiate checkout (starting the checkout) or a simulated purchase.
    3. The events should appear in the test view, typically within a few seconds. A status of Active confirms the pixel works.
    4. Events can take up to 30 minutes to show in the normal overview.

  • Test events procedure with test_event_code (a unique code that marks events as tests):

    1. Open the pixel in Events Manager and go to Test events.
    2. Copy the unique test_event_code shown on the page.
    3. For server-side events (sent from your store's server, not from the visitor's browser), open the Graph API Explorer (a Meta tool for sending test requests). Make sure all parameters (settings in the request) match the payload (the data package) shown on the page. Submit the request, then return to the Test events page.
    4. For website events, enter your website URL in the field and click Test events.
    5. Keep the Test events page open in Events Manager during the whole test.
    6. Open your store and perform the actions you want to verify, such as viewing a product, adding to cart and starting checkout.
    7. Check the events list. Each action should appear as its event, for example Add to Cart or Initiate Checkout. Expect delays of up to 30 minutes before events show in the chart.

  • Do not treat the setup as finished until the test events appear in Events Manager. A connection that looks linked in Shopify can still send no usable events if the pixel or test steps were skipped.

  • Test events show how the site and server events are set up. Test behaviour can differ from live traffic (real visitors). Personal ad settings do not affect test data. So a passing test does not show that the ads are optimized (set up to find buyers well).

Product Catalog and Commerce Manager Feed

1 min

Making products sellable on Facebook and Instagram

1 min

  • Procedure:

    1. Set each product's status to active.
    2. Select the Facebook sales channel for each product.
    3. Publish the products.
    4. Wait until the catalog (your product list in Meta) shows Catalog in sync. This confirms the products were synced (copied over) to the catalog for ads and shops.

  • Procedure before the catalog sync:

    1. In Shopify, set the product status to active for the Facebook & Instagram sales channel.
    2. Publish the products to that channel.
    3. Sync products to your Meta catalog so they can be featured in ads and shops.
    4. Wait until the catalog shows as in sync before running ads.

  • The product catalog must contain the full catalog, since remarketing (showing ads to people who already visited) needs every product to be available. If products are rejected, shorten the description below the 5,000-character limit. A character is one letter, digit or space.

  • Facebook product descriptions must stay under 5,000 characters, or the product will not publish to Facebook.

Checking the catalog in Commerce Manager

1 min
  • Meta Commerce Manager (Meta's tool for checking products) is reached through a Meta Commerce account. That account is linked to the Business Manager (Meta's tool for managing business accounts). It holds the product catalog that allows dynamic remarketing with products. Data sources and items show whether the Shopify products arrived correctly.
  • For a store with its own brand, create a new product catalog during the sync step. Do not add it to a catalog that belongs to another business. Name it after the store domain (the store's web address).
  • Choose the Business Manager, Facebook page, Instagram profile and pixel that belong to the store. Several businesses or pixels may be listed. Picking the wrong one connects the store to the wrong account.
  • The Shopify product feed (the file or link that sends product data to Meta) in Commerce Manager should be named Shopify dynamic Facebook ads product feed. It should show an all good status with its latest update time.
  • Data sources (places where Meta gets product data) can still show an old manually uploaded feed. That feed may not have been updated for 365 days. Ignore that stale feed and check the newly updated Shopify feed instead.

Procedure for checking products in Commerce Manager

1 min
  1. Open Commerce Manager from the Business Manager.
  2. Click data sources and find the Shopify dynamic Facebook ads product feed. Check that it has its latest update time and an all good status.
  3. Click items to confirm all Shopify products are listed.
  4. Expand a product to see whether it is in stock or out of stock. You can also see its content details there.
  • Connecting the Shopify store to Meta, enabling data sharing (letting the pixel send data to Meta) and checking the Commerce Manager feed only prepares the account. It spends no ad budget. Confirm that the product feed and items are correct before building audiences or launching any ads.

Feed content and dynamic ads

1 min
  • Dynamic product ads (ads that show products from your feed automatically) require the account to be linked to the store's product feed. This may need more account activity first. Posting a few times a week on Instagram builds this activity.
  • Meta dynamic remarketing works when the store connects directly to Meta through Shopify, which shares the product catalog. A custom feed can be used instead for more control. It is submitted as a catalog URL (a web link to the product file) in Meta.
  • Meta ads can run before dynamic product ads are possible.
  • Facebook Marketplace (Facebook's buy-and-sell section) is a default placement (a spot where the ad shows automatically) for Meta ads run from a Shopify catalog. Separate Marketplace listings are not needed.
  • Running an ad to a product with no shop page is risky. A catalog-based ad with checkout inside Facebook is an alternative. It avoids a landing page (a single web page that an ad sends people to). But it requires setting up a catalog first.
  • Connect the store to the Facebook page and import the product catalog there. Products can then be viewed on Facebook, and visitors can return to the store. Post content on the Facebook page that matches what the successful reference store posts.

Catalog and Feed Errors

1 min
  • Conversion errors (a conversion is a tracked goal, such as a sale) with wrong conversion types or ID issues are often platform-level Facebook issues. They affect multiple users. Contact Facebook support by clicking the question mark (?) icon at the bottom right of the campaigns page.

Procedure when Meta reports a product feed error such as "add product description"

1 min
  1. Check how the product feed is submitted to Meta.
  2. If it is submitted through a Shopify app (an add-on tool), open the app's feed. Check that the product description column contains data.
  3. Fix the blank column so Meta reads the correct field.

Procedure when a Facebook catalog reports products without descriptions although they have text

1 min
  1. Check whether all products or only a subset (some of them) are affected.
  2. If all products are affected, check in the feed app (for example Simprosys, a tool that builds product files) that the correct Shopify section is linked to the product feed.
  3. If only a subset is affected, check whether those descriptions are too long for Facebook. Also check whether they contain HTML (the code used to format web pages) that Facebook does not accept.
  4. For the affected products, write custom descriptions inside the feed app. The feed sent to Facebook then carries them.

Procedure when Facebook rejects a product catalog without a clear reason

1 min
  1. Do not repeatedly request reviews from the rejection notice.
  2. Open the Facebook support page and click Get started.
  3. Use the live chat there to learn the reason and ask for the issue to be resolved.

Tracking Errors and Common Mistakes

1 min
  • Pixel ID mismatch: if the pixel ID (the pixel's unique number) selected in Shopify is wrong, optimization does not work. Compare it with the ID in Meta Events Manager before confirming.
  • Missing Purchase event: check the Shopify sales channel settings and data sharing, as in the Pixel Helper procedure.
  • Setup seems complete but sends no events: test events must show up in Events Manager before the setup counts as finished.
  • Refreshing the page while Finalizing channel setup is running can leave the channel incomplete.
  • Blocked parameters and events: data sharing category and domain controls in Events Manager can block parameters (pieces of data) and events. If no category is assigned, set the dataset category via Edit. The allow list or block list controls which domains can send events to Facebook.
  • Bot and non-buying traffic: newly launched ads, UTM parameters (tags added to web links that show where a visitor came from) or platform crawlers (automatic programs that scan websites) can inflate visitor counts. Bot traffic means visits from automatic programs, not people. Launch ads at least six to seven hours before the planned start. This lets the platform's bot traffic arrive before measurement begins. Exclude it from funnel analysis (checking how visitors move step by step to a purchase).
  • Stale feed: an old manually uploaded feed (not updated for 365 days) can be mistaken for the live feed. Check the newly updated Shopify feed.
  • Accuracy after iOS: maximum data sharing recovers only part of the tracking lost after iOS 14.5 (an Apple phone software update that limited tracking). Do not expect all lost conversions to return.

Further details

1 min

It enables advanced tracking options that help target new and existing customers, including retargeting (showing ads again to past visitors). The pixel tracks visitor behaviour on the store to support marketing.
