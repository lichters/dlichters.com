Ads manager columns, custom metrics and naming

Section 9.7 · 7 of 22 in this chapter · 14 min read

In short

  • Build all base columns first, then save them as a preset. Creating a custom metric before saving deletes your unsaved column work.
  • Name the preset main dash. It stays saved across logins and page refreshes.
  • Create custom metrics only after the preset is saved: CVR, ATC% and IC%.
  • Set the attribution setting to 7-Day Clicks for every campaign and ad set.
  • Pick one naming pattern and never change it midway. Changes make old ads hard to compare.

Column presets: build order and saving

3 min
  • Build all base columns first. Save them as a preset. Only then create custom metrics.
  • A column is one data field in the Ads Manager table (Ads Manager is Meta's tool for running ads on Facebook and Instagram).
  • A custom metric is a number you calculate yourself from other columns.
  • Creating a custom metric before the preset is saved deletes all unsaved column work. You must start over.
  • The correct order is: add columns, save preset, create custom metrics.
  • Save the column setup as a Column Preset, which is a saved column layout you can reload later.
  • Use a consistent name. The standard name is main dash.
  • The preset saves automatically. It persists across logins, account switches and page refreshes.
  • Reselect it from the Columns dropdown at any time. You do not need to rebuild it.

Base column procedure

  1. Log into Ads Manager.
  2. Click Columns > Customize Columns (at the bottom).
  3. Delete all columns except Delivery and Actions.
  4. Add columns in this exact order.
    • Bid Strategy (the rule Meta uses to spend your budget)
    • Budget
    • Amount Spent
    • Purchase: check the Value checkbox and uncheck the others
    • ROAS (return on ad spend, the money earned per money spent): uncheck other options
    • Average Purchase Conversion Value (AOV, average order value)
    • Cost per Purchase
    • Attribution Setting (the rule for which clicks or views count as a sale)
    • Reach (how many different people saw the ad)
    • Impressions (how many times the ad was shown)
    • Frequency (how often one person sees the ad on average)
    • Link Clicks
    • Cost per Link Click (CLC)
    • CTR (Link Click-Through Rate, the share of viewers who click the link)
    • CPM (cost per 1,000 impressions)
    • Add to Carts: select Total, uncheck in-app, offline and Meta versions, keep Website only
    • Cost per Add to Cart
    • Initiate Checkout: select Total and Cost
    • Cost per Initiate Checkout
    • Results: select Purchases
    • Cost per Purchase again
  5. Do not create custom metrics yet. Click Save as Column Preset and name it main dash (or any name you choose).
  6. The preset saves automatically. It stays available across logins and account switches.

Add to Carts selection

  • When adding the Add to Carts column, select Total. Then uncheck the individual options:
    • in-app add to carts (only for app downloads)
    • offline add to carts (only for stores that uploaded purchases to Facebook)
    • Meta add to carts (only for Meta Shop or Instagram Shop)
  • For standard e-commerce, choose Website add to carts.

Tool columns

  • Link Ad Settings: add this column to see the landing page (the page a click opens) for each ad. You do not need to edit each campaign.
  • Type link or ad in the search field to find it.
  • The column shows only at the ad level, not the campaign level.
  • It saves time. You no longer click into each ad to check its landing page.
  • Place the Link Ad Settings column right after Bid Strategy in the main dashboard preset.
  • This keeps setup information together at the top, so you can see landing page assignments quickly.
  • Last Significant Edit: add this column to see recent changes to campaigns, ad sets and ads.
  • Changes include bid caps, cost caps, minimum ROAS, or cost per goal settings. You can see them without checking account history.
  • It is visible at the ad set and ad level. It helps you find when a campaign's bidding strategy was last changed.

Common mistakes

  • Do not join a call with a Facebook mentor or account manager before these custom columns are set up.
  • Setting them up live wastes 5-7 minutes of the mentor's call time.

Custom metrics

2 min

Definitions at a glance

Metric Formula Source ids
Hook rate (attention) 3-second video plays ÷ total impressions × 100, shown as a percentage ,
Hold rate (engagement) Video plays at 50% ÷ 3-second video plays × 100, shown as a percentage ,
CVR (Source E version) Purchases ÷ Link Clicks, format Percentage
CVR (Source C version) Unique outbound clicks from the Facebook ad that resulted in a purchase, as a percentage
CBR (custom conversion rate) Purchases ÷ unique outbound clicks × 100, shown as a percentage
ATC% (Add to Cart Percentage) Add to Carts ÷ Link Clicks, format Percentage
IC% (Initiate Checkout Percentage) Initiate Checkout ÷ Link Clicks, format Percentage

Hook rate and hold rate

  • Hook rate is the percentage of people who watch the first 3 seconds of a video, out of total impressions.
  • To create it, go to Columns > Create custom metric.
  • Hook rate measures the share of impressions where viewers watched the first three seconds of the video ad.
  • Hold rate is the percentage of people who watch at least 50% of a video, out of those who watched the first 3 seconds.
  • Hold rate measures how many viewers who passed the three-second mark kept watching to the halfway point.
  • Hold rate is only meaningful with high traffic.
  • When spend is small, read differences between ads carefully.
  • Example: a CTR of 2.27% against 0.41% can be caused by too little data.

CVR and CBR: two denominators

  • A denominator is the number you divide by. Sources use different denominators for the conversion rate (the share of clicks that become sales). Both are kept here.
  • Do not compare a rate built on unique outbound clicks with a rate built on Link Clicks.
    • Source C method: purchases ÷ unique outbound clicks. Outbound clicks are clicks that leave Facebook for your store.
    • Use unique outbound clicks, not total clicks. Facebook's page-view tracking is unreliable.
    • Unique clicks count one person once, even if they click several times.
    • This version is called CBR.
    • Source E method: purchases ÷ Link Clicks. This is named CVR and placed next to AOV.
    • The same method builds ATC% and IC% on the same Link Clicks base.
  • Meta tracks outbound clicks more reliably than website sessions. This is the reason for the Source C denominator.

Creating the custom metrics

  • Do this only after the base preset is saved.
  1. Go to Columns > Customize Columns > Create custom metric.
  2. Create CVR: name it CVR, set format to Percentage, enter formula Purchases ÷ Link Clicks, press Create metric.
  3. Create ATC%: name it ATC%, set format to Percentage, enter formula Add to Carts ÷ Link Clicks, press Create metric.
  4. Create IC%: name it IC%, set format to Percentage, enter formula Initiate Checkout ÷ Link Clicks, press Create metric.
  5. Place CVR next to AOV. Place ATC% after the Add to Carts column. Place IC% after the Initiate Checkout column.
  6. Save the updated preset.

Funnel column order

2 min

A funnel is the path from seeing an ad to buying. Columns are arranged left to right in the order a buyer moves through it.

Source C: custom funnel view

  • To build a funnel column view in Meta Ads Manager:
    1. Open the campaign view.
    2. Click Customize columns.
    3. Add custom metrics first, then reorder the columns on the right-hand side.
    4. Keep the ad set name, budget per day, amount spent, results and cost per result.
    5. Remove bid strategy when you are not running advanced bidding.
    6. Save the final selection as a preset (for example mix funnel) and apply it.
  • The Source E base preset keeps Bid Strategy as its first column. This Source C view removes it when no advanced bidding runs. Both apply to different setups.
  • The Source C snapshot section includes:
    • ad set name
    • last significant edit
    • daily budget
    • total spend over the period
    • result (conversions)
    • cost per result
  • The funnel section includes:
    • impressions
    • CPM
    • 3-second video plays (hook rate)
    • hold rate
    • unique clicks
    • unique CTR %
    • cost per click
    • add-to-cart
    • purchases
    • custom conversion rate metric
    • ROAS

Video retention columns

1 min
  • Video retention means how long people keep watching a video.
  • To see these metrics, open Customize columns and add the video metrics. Examples: video plays at 25, 50 and 95 percent, through plays, and video average play time.
  • Facebook has renamed and added columns over time. The names you see may differ.
  • Add the Through plays column via Customize columns.
  • Through plays counts how often a video was played to completion or for at least 15 seconds.
  • Read Through plays together with video average play time.

Attribution setting columns

1 min
  • Attribution is the rule for how long after a click or view a sale still counts.
  • Use 7-Day Clicks as the attribution setting for all campaigns.
  • The setting must be the same across all campaigns and ad sets.
  • The Attribution Setting column (from the base procedure) shows this at a glance. You can spot different attribution windows right away.
  • The Columns menu also offers Compare attribution settings. Use it to check the effect of different windows.

Reporting presets and dashboard setup

1 min

Two presets

  • Set up two column presets in Meta Ads Manager:
    • a desktop preset for photo editing, UGC work (UGC means user-generated content, such as customer-made videos) and managing the ad account
    • a phone preset for checking lifetime data when you are away from the computer
  • Build them via Columns > Customise columns.
  • The menu also offers presets such as Performance and clicks and Engagement and Delivery.
  • It also offers View your column presets, Compare attribution settings, Conditional formatting (colors that flag numbers) and Reset column width.

Layout and reading

  • Place related metrics side by side: ROAS, purchases and AOV.
  • Do not scroll back and forth between them when you decide. This cuts decision time a lot.
  • Compare one ad across several ad sets by sorting the Ads Manager table by ad name. The same creative then appears side by side.
  • In Ads Manager you can:
    • read ad set and ad performance
    • check CTR and spend
    • add interests via the Suggestions function
    • create and duplicate ad sets
    • change budgets
  • The Facebook block in the daily record shows, for each day, alongside daily ad spend:
    • CPC (cost per click)
    • CTR (clicks ÷ impressions)
    • CPM (cost per 1,000 impressions)
    • ATC (add to cart)
    • IC (initiate checkout)
    • purchases

Reporting principles

  • A clean, consistent naming convention (a fixed rule for naming) is the base of any reliable creative report.
  • Reason: AI analysis is only as good as the data it reads.
  • Start the convention now, at any brand size. Then year-on-year comparisons are possible later.
  • Keep one convention stable. Renaming products or changing the naming system midway makes older ads hard to compare.
  • History beyond about 12 months became difficult to read after such changes.

Campaign naming

1 min

Core rules

  • Name each campaign so you can tell what is inside from the name alone.
  • Include: the product, the brand or account identifier, the budget type (for example CBO, campaign budget optimization, where Meta shares one budget across ad sets), the creative type (for example UGC) and the launch date.
  • This lets you read data later without guessing.
  • For sales that repeat every year, put the year in the campaign name.
  • Example: Black Friday Sale 2026 instead of Black Friday Sale.
  • Without the year, comparing the same sale across years becomes very hard.

Naming patterns in the sources

  • Source C: name campaigns and ad sets with these fields: product name, ABO or CBO (ABO means the budget is set per ad set), objective, date, interest name, country code and age group.
    • Date: add it only once a product has run for more than about two months.
    • Country codes: short codes such as T4 for the US, Canada, Australia and UK, or DE for Germany.
    • Age group: for example 20+.
  • Source D: name Meta campaigns by audience, purpose and budget type.
    • Examples: Broad - Scale - CBO or Testing ABO.
    • Test and scale campaigns are then easy to tell apart.
  • Source D: campaign name = [today's date] [product name] CBO.
    • Example: 2404 SleepMask CBO.
    • Here the date comes first. Source C adds the date only after about two months.
  • Source D: name a duplicated campaign that has a custom cover and custom UGC as CBO - [product code] / Custom.
    • This keeps the custom test separate from the original in the Ads Manager list.

Ad set naming

1 min
  • Name each ad set after the creative inside it. Example fields: the format, the number of ads, the launch date and the message type.
  • You can see the contents without opening the ad set.
  • Source D pattern: the ad set name is a broad targeting label, for example Top 5 Broad.
  • Source C pattern: the ad set name includes the interest name, along with the campaign fields above.

Ad naming

2 min

Principles

  • Put the product name first in every Meta ad name. Creative reports group by that field.
  • Keep the other fields (ad type, launch date, creator name) in the same fixed order for every ad. Then names can be read by a program.
  • Keep the product type in the ad-level name. The report groups creatives by product from this field.
  • For ads with several products, use a separate product type, such as mixed.
  • Start the naming now. Do not change it midway.
  • The launch date is recommended from the start. This avoids rebuilding names later.

Fields

  • A usable ad name carries:
    • The product name (examples: sleep, tea, bathrobe)
    • The ad type (video, UGC or sale ad)
    • The launch date
    • The creator name
  • License tags and other extra fields are not needed for a creative-count report.
  • The launch date is not strictly needed for a creative-count report. It is still recommended, because the report is pulled from the Meta API (the program that lets other tools read Meta's data).
  • Name each ad with its creative type and a unique counter. Example: UGC followed by a number, such as A123.
  • This lets you match an ad in Ads Manager to its source file and its results.
  • Source D pattern: ad name = [today's date] [product name] CBO > [ad set name] > [number] Ad.
    • Example: 2404 SleepMask CBO > Top 5 Broad > 1 Ad.

Pipe-separated example

  • A pipe-separated name uses the symbol | between fields.
  • It can contain fields such as:
    • product type (for example OODIE or BLANKET)
    • audience (ADULTS)
    • license status (LICENSED)
    • format (IMAGE or video)
    • production source (STUDIO)
    • launch type (NEW PRODUCT)
    • a category tag (for example F&B)
    • a design or character name
  • For a creative-count report, only product type, ad type, launch date and creator name are needed. The other fields can be left out.

Older advice

  • Older advice from 2021-22: name each Facebook ad so the name shows what differs from the other ads in the ad group.
  • Without this, split test results (tests that compare versions side by side) cannot be linked back to the creative that produced them.

Audience naming

1 min
  • Name custom audiences (groups of people you target) with: product name, funnel stage, event and window. This lets you tell them apart later.
  • Example: product, MOF, 25 plus video views, 30d. (MOF means middle of funnel. 30d means a 30-day window.)
  • Use the same pattern for engagement audiences, such as FP engagement with a 30-day window.
  • Use the same pattern for website visitor audiences.

UTM parameters and URL tracking

1 min

A UTM parameter is a short tag added to a link. It tells your analytics tool where a sale came from.

Where the URL goes

  • Enter the URL of the product page that belongs to that specific ad in the ad's Website URL field.
  • URL parameters are no longer typed there.
  • They are managed in the Tracking section, opened with Go to Tracking.

Method A: dynamic placeholders at ad level

  • A placeholder is a stand-in that Meta fills with the real name each time.
  • In the ad-level UTM parameters on Meta:
    • utm_source is fixed to Facebook
    • utm_medium is fixed to cpc
    • utm_campaign, utm_content and utm_term are filled with Meta's dynamic name placeholders for the campaign name, ad name and ad set name.
  • This lets you trace each sale back to the exact campaign, ad and ad set in analytics.

Method B: Build a URL parameter

  1. Go to Ad level > Tracking section > Build a URL parameter.
  2. Set Campaign source = facebook.
  3. Set campaign medium = campaign name.
  4. Set campaign name = ad set name.
  5. Set content = ad name.
  6. Optional extra parameters (for example utm_term) can be added with Add parameter.
  7. Click Apply so they are embedded in the destination link.

Conflict between the two methods

  • The two methods give different values for the same parameters:
    • utm_medium: cpc in Method A, campaign name in Method B
    • utm_source: Facebook in Method A, facebook in Method B
  • Both are kept here. The sources do not say when to use each.
  • Pick one method and use it for all ads. Then the trace in analytics stays comparable.
