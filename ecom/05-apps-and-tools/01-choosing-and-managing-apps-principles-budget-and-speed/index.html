Choosing and managing apps: principles, budget and speed

Section 5.1 · 1 of 22 in this chapter · 21 min read

In short

  • An app is a small add-on tool. Install only the one your store needs right now.
  • Start every app on its free plan. Pay only when the free plan is not enough.
  • Each app adds load time (how long pages take to open) and monthly cost, so fewer is better.
  • Test a paid app during its free trial and measure the extra sales before you keep paying.
  • Check the ratings and reviews before you install, and run a speed check after.
More key points
  • Delete every app you do not use. Apps are the most common reason a Shopify store loads slowly.
  • Uninstalling an app can leave its code on your site. Ask the app's developer where that code is.
  • Check whether your theme already does the job before you buy an app or hire someone.
  • For simple jobs, a freelancer or AI-written code can replace an app.

Principles for choosing apps

2 min
  • Use an app only for a feature that would be too hard to code yourself. Coding means writing the computer instructions yourself. Build simple features with on-site code, because fewer apps usually mean faster pages. **
  • Before you install an app, check whether it solves a real need at your current stage. Apps added because others use them, or because they look new, usually add cost and slow the store without helping. **
  • Install only the apps you need now. Add more as the business grows and your market asks for specific functions. **
  • Think of apps like phone apps: you add one app for one specific job.
  • Shopify apps are add-on programs built by outside developers. Shopify is the online store platform. The apps are listed in the Shopify App Store, a shop for apps. Each app adds one function when you need it, so you do not have to build that function yourself. **
  • For a store with a limited budget, an app is usually cheaper than custom development (having a developer build a feature for you). A live chat built from scratch can cost thousands of dollars and is often less polished than a finished app from a specialist company. **
  • Installing an app usually replaces custom development. Features that once needed a developer, paid thousands of dollars, can often be added with a few clicks and no coding.
  • Shopify's built-in features cover most of what a new store needs. So only a few apps are needed at the start. Installing extra apps before you need them adds cost and complexity.
  • Shopify is the only paid software that is a must-have at the start. Canva's free version is fine. Canva is a design tool. Stripe Atlas can help set up a US company if you run the business from abroad. Stripe Atlas is a company-setup service.
  • No apps are required at the start of the setup. To see your installed apps, go to Settings > Apps.
  • The Shopify App Store offers thousands of apps. They extend the store beyond the built-in features, for example with marketing and SEO tools. SEO (search engine optimization) means getting found on Google.
  • When you think about switching a tool, compare what the new tool does with what your current tool does for you. If the new tool covers everything at lower combined cost, switch. If the old tool does a job the new one cannot, keep it. **

Deciding which apps to install at each stage

5 min

Setup and foundation

  • When you set up a new Shopify store, do not install apps yet unless the current setup step needs them. Install each app when the stage that needs it arrives. This keeps the store lean and stops you paying for apps you do not use.
  • At the foundation stage, install only the apps the store needs for its current products and sales. Do not install all apps at once.
  • Fulfillment-agent apps, for example for a 3PL, are often not installed by hand. Fulfillment means packing and shipping orders. A 3PL (third-party logistics) is an outside company that stores and ships your products. The agent provides its own connection.
  • Channel apps for Google and Meta are added later, when the store starts advertising on those platforms. Channel apps connect your store to ad platforms. Do not add them during the first store build.
  • Review collection apps (apps that gather customer reviews) are also added at a later stage, once the store needs them.
  • Beginners do not need SMS marketing, SMS, email or retargeting apps when starting. SMS is text messaging. Retargeting means showing ads again to people who already visited. Focus first on getting views, sessions and sales. A session is one visit to the store. Add these apps later, once you have real customer interest (traction).
  • On a new store, install only the Ultimate Sales Boost app and one fulfillment app. Examples of fulfillment apps are DSers, CJ Dropshipping and an all-in-one fulfillment app. Dropshipping means a supplier ships each product directly to the customer.

Roles of the core tools

  • Klaviyo, SMS Pump and Tidio have different jobs. Klaviyo handles email retention and signup capture. SMS Pump handles SMS for abandoned checkout (customers who leave before paying) and for upsell and win-back. An upsell means offering a bigger or extra product. Win-back means messages that bring past customers back. Tidio handles live chat with visitors during checkout. It also runs chatbots for cart recovery (bringing back people who left items in the cart) and for order-status questions, such as "where is my order?"
  • Essential Shopify apps for dropshipping cover four jobs: fulfillment, currency conversion, product reviews, and email/SMS marketing. Optional apps add live chat, a sticky add-to-cart bar (a bar that stays on screen with the add-to-cart button), and AOV (average order value, how much each order spends on average) boosters. Boosters include bundle or quantity-break apps. Quantity breaks give a lower price for buying more.
  • Klaviyo has the deepest Shopify integration (the closest connection to Shopify). Every extra connector is another point where something can break. **

Currency converters

  • A currency converter is required whenever the store does not use Shopify Payments. It shows customers prices in their own currency. Shopify Payments is Shopify's built-in payment service.
  • Shopify Payments already converts currency automatically once a market, such as Germany, is enabled.
  • Bucks Currency Converter is recommended because it is free. Other currency converter apps do the same job.

Free plan first and budget

2 min

Rule order

  1. Start every new tool on its free plan and check whether it covers your need.
  2. Move to a paid plan only when volume or features force it. When you do, pick the lowest-priced tier that fits your current usage.
  3. Start every app on its free plan, confirm it delivers value, and only then upgrade. **
  4. Test a paid app during its free trial (a test period before billing starts) and measure the extra revenue before you pay. **

Price points and budget limits

  • Shopify apps recommended in one 2020 source cost less than about $20 per month each. Install them gradually as you reach each step, not all at the start. **
  • A 2021 source said that at about $10 per month, a useful upsell app usually costs little compared with the revenue it can add. **
  • Easy Tabs - Product Tabs by NexusMedia costs $5 per month with a 7-day free trial. **
  • Use both price points as examples only. Check current pricing, because some tools have been renamed (rebranded) and their prices changed (repriced).
  • Free or low-cost apps with many five-star reviews are an acceptable choice for page speed or image SEO. Image SEO means making images easy for Google to find and read.
  • In the App Store, each app is either free or paid. The listing page shows which. Apps developed by Shopify are free to add to a store.
  • For a basic automation stack, the free versions of Slack, Trello and Google Sheets are enough. Slack is a team chat tool, Trello is a task board, and Google Sheets is a spreadsheet. There is no need to pay for their team or upgraded plans. Consider a paid upgrade only when a specific limit is actually reached.
  • Starting ad research: a research tool budget of about $150 per month on ad testing usually gives more experience and data than the tool itself. A paid research tool is more useful once the business is already making money.
  • To begin testing a product, you only need a store, an Ad Library reference (Meta's public list of ads) and a product list. You do not need extra tools at the beginning.
  • Ahrefs (an SEO research tool) and SimilarWeb (a site traffic estimate tool) are paid and optional for a new dropshipping store. Their discounts, including on Black Friday, do not make them necessary.
  • AI tool costs add up. Each tool in a stack may cost about 10 dollars per month, so a stack of several tools can reach around 100 pounds per month. Justify each tool by the return it gives.

Cost traps

1 min
  • Apps that do not lead to sales should be cancelled. They add monthly cost with no return.
  • A free-gift app with a plan of about 20 USD ended up at almost 100 USD per month once usage fees were added. Check usage-based fees (charges that grow with how much you use the app) before you choose an app.
  • Remove costly bundle or gift apps once revenue is good enough to switch.
  • Some apps show a free trial or free plan badge in the listing. But billing starts after the trial. Check whether the trial or free tier ends in a paid plan. **
  • Bundle discounts from the Kaching app page grow with the number of apps installed: 10% off with 2 apps, 20% off with 3 apps, and 30% off with 4 or more apps. The discount applies to all installed apps. Check the exact terms and whether the discount applies to your plan before you count on it in a budget.
  • Shopify's app bundle discount, as shown in the admin in 2026: 2 apps installed gives 10% off, 3 apps gives 20% off, and 4 or more apps gives 30% off.
  • Use Bold Product Options and Bold Product Upsell on stores where you need that function. Do not use Bold Discounts. Use promo codes (discount codes) promoted on the store instead of storewide discounts. **
  • Do not pay for a tool before sales arrive. Several starter apps have free trials, so avoid paying before sales come in.
  • A currency converter app was switched off in a test with no visible change in conversion rate. Most ads targeted the US, and the store sold in USD. Such apps can conflict with other apps, which may be a reason to remove them.

Vetting an app before installing

2 min

Search and compare

  1. Open the Shopify App Store from the Shopify admin (the store's back office).
  2. Type the feature you need into the search bar, for example wishlist (a list of items to save for later).
  3. Compare the results. Check the developer, and remember that apps developed by Shopify are free.
  4. Open the app listing and review its demo video, screenshots, description, rating, number of reviews, and available pricing plans.
  5. Pick a plan and click Install to add the app to the store.
  • Search by the feature you need, such as wishlist, rather than by brand name.
  • The store front page has a search bar, a "Popular with stores like yours" section at the top, and lists of trending and spotlighted apps.
  • You can narrow search results with the checkbox See only compatible apps and with a pricing filter set to Free or Paid. The default sort order is Most relevant.
  • The Shopify App Store is organized into these categories: Store design, Orders and shipping, Sales and conversion, Marketing, Inventory management, Productivity, Reporting, Finances, Customer support, Finding products, Places to sell, and Trust and security. Customer support, for example, contains support ticket apps (tools that manage customer help requests).

Ratings and reviews

  • Before you choose a third-party app (one made by an outside company), check its ratings, the number of reviews, and whether the reviews are recent. In one 2021 source, Constant Contact's Shopify connector cost $5 per month and had 4.3 stars from 58 reviews. **
  • To pick a Shopify app, search the App Store for the task. Then sort by the number of reviews and star ratings. The app with the most five-star reviews is a good first option.
  • A wishlist app with a rating of 4.9 out of 5 stars from more than 1,900 reviews is an example of a well-reviewed app. Ratings and review counts together help you compare competing apps for the same feature.
  • Shopify app search results show each listing's star rating, review count and free trial length. This helps you compare apps in the same category. In 2021, the Easy Tabs - Product Tabs listing by NexusMedia showed 4.9 stars from 742 reviews, a 7-day free trial, and a price of $5 per month. Compare several listings before you install one. **
  • Poor apps usually show bad reviews in the Shopify App Store. **

Vetting procedure for a wholesale or sourcing app

A sourcing app helps you find suppliers. Wholesale means buying in bulk at a low price.

  1. Compare ratings of candidate apps in the Shopify App Store.
  2. Read the written reviews to see whether they look genuine.
  3. Look for video reviews on YouTube before you install.

**

Developer and integration

  • Choose tools with the deepest Shopify integration, such as Klaviyo.
  • Augmented reality (AR) room-preview apps, which show a product in your room through the phone camera, are not necessary for most niches. They need extra apps, coding skill and budget. The preview may also not match the product photos.

Installing an app

2 min

Procedure from Source B's material

  1. In the Shopify admin, open the Apps menu. If no apps are installed, click Visit Shopify app store, which opens in a new tab.
  2. If Shopify asks you to choose an account, select the store account again.
  3. Type the app name in the search bar and open the correct listing. In the example, the app was Easy Tabs, Easy Tabs - Product Tabs by NexusMedia.
  4. Click Add app.
  5. On the confirmation screen, read the list of access rights (what the app may see or change), then click Install app.
  6. Open the app. It loads its own admin interface (its own control panel), where you start the free trial if needed and complete the setup.

Procedure from Source C

  1. Open the Shopify search bar, go to Apps, then All recommended apps, and scroll down to the Shopify App Store.
  2. Search for the app by name and open the listing.
  3. Click Add app, then Install app.
  4. Log in to an existing account or sign up. This connects the app to your store.
  • To install a Shopify app, open Apps in the Shopify admin, click all recommended apps, scroll down and open the Shopify app store. Search the app name, click Add app, and then Install app.

Permissions and data

  • On the install confirmation screen, clicking Install app also accepts Shopify's Terms of Service (the legal rules you agree to). Read the list of access rights on that screen before you confirm.
  • The install confirmation lists what the app may access: view Shopify account data, view products, manage your Online Store, and view details. Removing the app starts a request to erase your customers' personal data after 48 hours. **
  • Some apps place features into the main Shopify areas. Most run through their own admin interface. After installation, open the app and manage its settings there. **
  • To remove an app, go to Shopify admin > Apps, open the app, and click Uninstall.

Working with app developers

1 min
  • For any change to how the app shows on your site, contact the developer named on the app's store listing. Do not edit code yourself if you are not a coder. For Easy Tabs, the developer's support address is support@nexusmedia-ua.com. **
  • Procedure for a placement change (moving where the app shows on the page):
    1. Find the developer's contact details on the app's store listing.
    2. Reply to the developer's welcome email. This keeps the earlier conversation in one thread.
    3. Ask the developer to install the app in a way that fits your theme and places it where it should appear on the product pages.
    4. Wait for the developer to finish. In the example, it took up to 12 hours.
  • In the example, the developer made the requested placement change within 12 hours and at no charge. **

Page speed and app weight

2 min

How apps slow a store

Page speed means how fast pages open. App weight means how much extra code an app adds. JavaScript is the code that makes pages interactive. It must load with the page.

  • Apps that place content on the storefront (the part of the store customers see) add extra code and JavaScript. This code must load with every page. A large number of such apps slows page load. Slow pages can lower conversion rates and hurt organic search rankings, which means your position in Google results without ads. **
  • Each installed app adds JavaScript that runs on every page load. Keep the number of apps low. Remove unused apps along with their code.
  • Some apps use lazy loading to defer their scripts (load their code later), so they do not slow the first view. Every installed app still adds JavaScript. So check the impact on load time before you install.
  • Many stores run around 30 apps, while only 2 or 3 are fundamental. Remove apps that are not essential to the business. Each app adds code and load time, especially on the cart and checkout pages.
  • Each app added can slow the store, so use as few as possible.
  • Apps can slow page load and add monthly cost.
  • The number of Shopify apps does not decide slowdown. One poorly coded app can damage performance and user experience. Many lightweight, well-coded apps may have almost no effect. **
  • Use lightweight apps that add little code and do not change how the site operates. Apps that alter the site structure can drastically increase load times.
  • Within one app category, page-speed impact differs. When features are similar, choose the lighter app. **
  • Apps with similar functions differ hugely in speed, so test alternatives before you choose. Talk To is a light chat app with minimal page speed impact. TDO Chat was described as the slowest chat app on Shopify. Pop-up apps that load asynchronously (separately, without holding up the page) have less impact than those that block loading. **
  • Chat apps on Shopify differ greatly in page speed impact, even when they offer the same function. For a budget-limited early-stage store, a light and cheaper option such as Talk To is a reasonable choice. Replacing a slow chat app is usually the single biggest quick speed fix. **

Speed check after installing

  1. Install the app.
  2. Run a speed check on the store. A speed check measures how long pages take to load.
  3. Test the load on a 3G connection, a slow mobile connection. This shows the worst case.
  4. Confirm the site is still easy to use.
  5. If it slows the store, remove the app.

App audit

1 min
  • Apps are almost always the biggest cause of slow page speed on Shopify. Page speed means how fast your pages load for visitors. An app is a small add-on program you install in your store. Remove apps that are not used. Also remove the leftover code of uninstalled apps from the theme. The theme is the design template that controls how your store looks. Uninstalling an app does not remove its script from the site. A script is a piece of code that makes something work on the page. **
  • Removing an app from Shopify does not always remove its injected code. Injected code is code the app adds to your site. Contact the app developer and ask where the code must be deleted. A developer is a person who writes code.

Audit procedure

1 min
  1. List every app that adds front-end code. Front-end code runs in the visitor's browser, so visitors can see its effect. Examples are chat widgets (live chat boxes), upsell widgets (boxes that offer an extra product), option apps (apps that let customers choose things like size), filters, header bars (bars at the top of the page), pop-ups, and JavaScript-based tools. Back-end apps, such as accounting connectors, work behind the scenes and do not affect page speed.
  2. For each app, ask whether it is still used regularly. If not, delete it.
  3. If the app is needed, check for a faster alternative with similar function and cost, and replace it.
  4. Check the theme code after deletion to confirm no script of the removed app remains.
  5. Replace simple app functions with code written into the theme, such as banners or simple elements. This is more efficient. Keep apps only for complex functions such as live chat.

**

  • Hire a Shopify developer who has page speed experience to audit the store once and fix the technical issues: apps, code, lazy loading, and theme. Lazy loading means loading images only when a visitor is about to see them. This is a worthwhile one-time investment, not something you must learn yourself. **

Uninstalling an app

1 min
  • When uninstalling an app that slowed the store, message the app developer through the Shopify App Store first. The App Store is Shopify's marketplace for apps. The developer can confirm whether extra code was added that must be removed to restore load speed.
  • Removing an app does not always remove its injected code, so ask the developer where code must be deleted.
  • Remove apps that are not essential to the business.
  • Remove an app that conflicts with other apps. A conflict means two apps interfere with each other.
  • Remove costly bundle or gift apps once revenue is good enough to switch. A bundle app sells several products together as one deal. A gift app adds free gifts to orders.
  • Cancel apps that do not lead to sales.

Finding apps that competitors use

1 min

Browser inspection procedure

1 min
  1. Open the competitor's store in Chrome. Chrome is a web browser.
  2. Right-click and choose Inspect. Inspect is Chrome's built-in tool that shows a page's code.
  3. Use the select-element tool and click the bundle block on the page. The select-element tool lets you click any part of a page to see its code. An element is one part of a page, such as a button or block.
  4. Read the element's code and search for the app name, such as 'bundle' or the app's name in the script.
  5. Note the app name and check its listing on the Shopify App Store.

Tools that show competitor apps

1 min
  • Ali Hunter (a Chrome extension, which is a small add-on for the Chrome browser), PPSpy, and Koala Inspector show which apps competitor stores use. Koala Inspector may require an upgrade for full app data.

Theme features, custom code or a freelancer

1 min

Use the theme first

1 min
  • Use the built-in theme features before paying for a separate app or a custom developer job for the same function. A review collection tool, which gathers customer reviews, still needs a separate app, because the theme does not provide it.
  • Some features built into a theme can replace functions that would otherwise need separate paid Shopify apps. Check a theme's native features before buying apps. This can reduce monthly app costs. Native means built in.
  • Simple site elements such as banners or small on-page features can often be coded directly into the theme by an inexpensive developer. This is usually more efficient than a script-heavy app. Complex functions such as live chat still normally require an app. **

Custom code for simple features

1 min
  • For a simple custom feature, ask an LLM for custom Shopify section code instead of installing an app or hiring a developer. An LLM (large language model) is an AI chat tool such as ChatGPT. Section code is a reusable block of code in the theme.
  • Use apps only for features that would be too hard to code yourself. Build simple features with on-site code. **

Hiring a freelancer

1 min
  • Get a custom feature built when paid apps are too expensive. A freelancer is a self-employed worker you hire for one job.
    1. Post a job for a Shopify developer on Upwork. Upwork is a website for finding freelancers.
    2. Describe the function you need and link to the apps you want to copy.
    3. Hire a developer to build it into your store for a one-time cost.

**

  • Platforms for hiring Shopify developers for custom code, such as custom buttons and external service integration, include Fiverr.com and StoreTasker.com. Integration means connecting your store to another service.
  • Stack Overflow is a technical question-and-answer site, useful for finding fixes to specific coding problems. Reddit, an online discussion forum, can also be used to ask for developer recommendations, though answers can be harsh for beginners.
