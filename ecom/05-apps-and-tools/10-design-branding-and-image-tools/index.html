Design, branding and image tools

Section 5.10 · 10 of 22 in this chapter · 60 min read

In short

  • Canva is the easiest tool for simple images. Photoshop and Illustrator can do more, but take longer to learn.
  • Keep your Gemini API key secret. Anyone who has it can run jobs on your key and your billing account.
  • Check your brand colours, fonts and social links before you save the brand file.
  • Use only images you are allowed to use for your business, and check the licence first.
  • Use Canva (an easy online design tool) for simple graphics. Use Photoshop (a full photo editing program) for photos that need fine control.
More key points
  • Shrink images before you upload them, so your store pages load fast.
  • Build packaging at its exact print size. A 10 x 13 inch mailer is 3000 x 3900 px.
  • Keep your Gemini API key (a private code that lets the tool use Google's AI) secret. If you see 429 errors, lower the concurrency (how many jobs run at once) or add a pause.
  • For a new logo or banner, hire a designer at $20 or more, not a $5 job.
  • A free Canva account (an online design tool) is enough for a basic store's logo, icons and images.
  • Make logos with a transparent background (no background color), so they work on both dark and light sites.
  • Turn the final logo into a vector file (a file that stays sharp at any size).
  • Check every product cutout at zoom (close up) before you publish it.
  • Shrink images before you upload them. Smaller files make the store load faster.
  • Free online tools like Canva, Pixlr and Snappa can make simple images, logos and ad pictures.
  • AI image tools can make pictures from written instructions. Check every picture before you use it.
  • Put the words "authorized retailer" under a supplier's logo on any badge you make.

Choosing the design tool

2 min
  • Canva is the fastest option for simple social posts, product graphics and quick exports.
  • Canva is an online design app. It has ready-made templates (layouts you fill in), animated icons, graphics, and stock photos and videos (ready-made media you can use). Beginners can build without outside files.
  • Canva is weak at layering and blending. Layering means stacking objects on top of each other. Blending means mixing one object into another.
  • Shadows and gradients (smooth colour changes) come in Canva only as presets (fixed options).
  • You have little control over how one object blends into another.
  • Plan designs that do not need deep blending when you work in Canva.
  • Canva has no pen tool (a tool that draws exact lines by clicking points) and no real brush.
  • Canva's draw tool does not auto-correct, so straight lines and custom hand-drawn shapes are hard to make.
  • Build custom shapes in Illustrator or Photoshop.
  • Photoshop works mainly with pixels (tiny dots that make up a picture).
  • Photoshop is built for image manipulation (changing photos). Examples are cutouts (removing a background), colour grading (adjusting the colour mood) and photo compositing (combining several photos).
  • Photoshop can also create vector shapes (shapes drawn with maths-based lines that stay sharp at any size). That is why many designers choose it when they can learn only one of the two programs.
  • Illustrator creates scalable vector graphics (graphics that stay sharp when resized), built from mathematical paths (lines defined by maths).
  • Enlarging a logo or shape in Illustrator does not pixelate it (make it blocky).
  • Illustrator is the right tool for logos, icons and custom drawn shapes.
  • Choose the tool by the job:
    • Canva for speed and ready-made elements.
    • Photoshop for image manipulation and advanced compositing (complex layering of images).
    • Illustrator for custom graphics and shape building.
    • One designer can use all three and move files between them.
  • Photoshop and Illustrator have a steep learning curve (they are hard at first).
  • Do not try to learn every tool first. Learn the basic controls, then look up the specific technique you need for the current problem.
  • Older advice: professional software has unnecessary complexity for basic ecommerce tasks such as resizing and cropping. Simpler online tools are more practical for non-designers.
  • PicMonkey is an online editor. It resizes, crops and adds text to images.
  • PicMonkey needs no software installation or design experience. A free trial is available. The basic plan costs $7 per month.
  • Snappa is a simple online tool for custom article images.
  • Snappa has a free version and a paid version with extra features. It is much simpler than Photoshop and includes a curated set (hand-picked selection) of stock photos.
  • Canva is browser-based (it runs in a web browser, with no install). Its free plan is enough for basic store assets such as logos, favicons (the small icon in a browser tab), banners and icons.
  • Beginners without design training can use Canva. Experienced designers can use Photoshop or another editor.

Gemini API key setup

2 min

Terms:

  • Gemini is Google's AI.
  • An API key is a secret code that lets a tool use your Google AI account.
  • Google AI Studio is Google's website for managing those keys.

Set up the key in Google AI Studio:

  1. Open Get API key, then API Keys.
  2. Click Create API key.
  3. Choose the Gemini API Key option.
  4. Select an existing project or create a new one (a project is a folder that groups your settings).
  5. Click Create key.
  6. Copy the key from the API keys list when a tool needs it.
  • Treat the Gemini API key like a password. Never share it.
  • Paste the key only into tools you control.
  • Keep tool files private, because the key is stored inside them.
  • If a key leaks, revoke it (cancel it) in Google AI Studio and create a new one before running anything else.
  • Downloading course HTML tool files from Google Drive (Google's online file storage): click the three-dot menu on each file and choose Download. HTML files are web pages that run in a browser.
  • Do not open the raw code.
  • Download every file of the set before first use, then open the HTML file locally in a browser.
  • Gemini image generation (Nano Banana, the nickname of Google's image model) runs in the browser tools on the model gemini-3.1-flash-image-preview.
  • Model names change. If a request returns a 404 error (a "not found" message), check the Gemini API models documentation and update the model field in the tool.

Adding the key through a skill file (source procedure). A skill file is a folder of instructions that Claude can load:

  1. In Claude, open Settings > Customize skills, click Add, and add the image skill folder.
  2. Open https://aistudio.google.com/apikey and sign in with a Google account.
  3. Click Create API key.
  4. Copy the key, which starts with AIza.
  5. Open the SKILL.md file and find the API Config section.
  6. Replace the placeholder line API KEY = 'YOUR GEMINI API KEY HERE' with your key, then save the file.
  • Conflict: the skill-file procedure above places the key inside a file. A key placed in a skill file travels with that file.
  • Anyone you share the skill with can run jobs on your key and your billing account (the account that gets charged).
  • Use the file method only for a private skill that is never shared or uploaded.
  • Otherwise, enter the key in the tool's key field at run time.
  • Never place the key inside a file you share or upload.

Fonts

Brandfetch MCP (brand data extraction)

Terms:

  • JSON is a plain text format for data.

  • ICP means ideal customer profile, your perfect buyer.

  • Brand Fetch MCP is a data extraction tool (a tool that pulls data from websites). It has two main functions.

  • get_brand returns the visual identity as JSON: logos, colours, fonts, social handles (account names) and company metadata (basic company facts).

  • get_brand_context returns the voice (how the brand talks), ICP, positioning (where the brand stands against others), product catalogue, tagline, mission and target audiences.

  • Brandfetch MCP is a Model Context Protocol connector for Claude.

  • It extracts brand identity from any website: logo, hex colour codes, fonts, social media links and brand summary.

  • It generates two files, brandkit.json and voice.md.

  • Processing takes 5 to 7 minutes before the brand kit and voice files are returned.

  • Naming difference: names the two functions get_brand and get_brand_context.

  • lists six tools: Search Brands, Build Logo URLs, Identify Merchant from Transaction, Fetch Asset as Base64, Get Brand Details and Get Brand Context.

  • Base64 is a way of writing a file as text. A merchant is the shop that received a payment.

  • The read-only tools (tools that only read data and change nothing) extract logos, hex colours, fonts, social links and merchant data when you run the brand kit prompt.

  • Competitor research: use Brand Fetch MCP to study competitor brands' positioning, colours and voice.

  • Do not copy their visual identity or tone.

  • Use it as competitive intelligence (information about rivals) to understand market positioning.

Photoshop

2 min
  • Generative Fill can add or change parts of an image using AI. It can be used alongside AI background tools.
  • Generative Fill creates or replaces content from a selected area and a text prompt (the written instruction you type). At the time of writing it was at an early stage with uneven results. Expect several tries before you accept one.
  • Adding realistic light falloff (the gradual darkening of light across a surface) to a cut-out subject:
    1. Create an Exposure adjustment layer above the subject. An adjustment layer changes how the image looks without changing its pixels (the tiny dots that make up the picture). Lower the exposure so the subject matches the darker background.
    2. Clip the exposure layer to the subject, so it affects only that subject.
    3. Press Cmd+I or Ctrl+I to invert its mask. A mask is a black-and-white layer that shows or hides an effect. Inverting fills the mask black, which hides the effect.
    4. Set a soft brush with low opacity (how see-through the paint is). Paint white over the areas that should be darker, such as parts not lit by the background light.
    5. Add a solid colour or Hue/Saturation layer clipped to the subject, to match the colour of the background light.
    6. Set the layer to a blending mode (a rule for how two layers mix) such as Overlay or Color Burn. Then use the Blend If sliders to blend the colour into the subject. Hold Alt or Option to split the sliders for a smoother blend.
  • Blend If sliders (in Blending Options) blend a layer based on the brightness of the layer below. Holding Alt or Option while dragging splits the slider for a smooth transition instead of a hard edge.
  • Clipping mask: hold Alt or Option and click the line between two layers. This applies an adjustment layer only to the layer beneath it. Without clipping, an adjustment layer affects the whole artboard (the working area of the design).
  • Adjustment layers change colour, brightness, contrast, levels, curves, exposure, hue and saturation, photo filters and colour balance. They do not change the underlying pixels. Each adjustment can be turned off or edited later, so it counts as a non-destructive edit (one you can undo at any time).
  • Scaling a rasterised pixel image (one made of fixed dots) makes it pixelated (blocky). A smart object (a protected container that keeps the original quality) keeps its quality when resized. Convert the layer to a smart object before scaling. A smart object cannot be painted on directly.
  • Right-click a layer and choose Convert to Smart Object. To edit its contents, click the smart object icon at the bottom right of the layer thumbnail. Change the content and save. The change updates everywhere the smart object is used.

  • Keep the brush small and use a little feather so the repaired spot blends with its surroundings.
  • Using Spot Healing with a large brush or on high-contrast edges changes the texture around it too much.
  • Keep the brush small and check each click in areas with strong contrast.
  • Clone Stamp copies pixels from one area to another.
  • Hold Alt to set the source point, release Alt, then paint over the target area.
  • The copied area keeps its lighting. It can look too bright or too dark when moved.
  • Watch the light direction.
  • The Clone Stamp source moves with the cursor. So a long stroke copies the sampled spot repeatedly and creates visible duplicates.
  • Sample a new source area with Alt-click often.
  • Avoid dragging across the same sampled spot for a long distance.
  • Sample from different points. Drag the source from the side where the light falls on the same surface.

Photoshop: Adjustments

1 min
  • Adjustment layers (the circle icon at the bottom of the Layers panel) apply changes above the photo.
  • These changes include exposure, hue/saturation, black and white, or whites and blacks.
  • They do this without altering the photo's pixels.
  • Dragging the adjustment layer to the trash removes the change and restores the original image.
  • In Hue/Saturation, hue sets the color itself.
  • Saturation sets how strong that color is.
  • To reduce a color cast (an unwanted tint) on a garment against a white background, lower saturation.
  • Lowering saturation moves the color toward grey or black instead of changing the hue.
  • Lowering Saturation on a tinted area, such as a blue cast on a white T-shirt, neutralizes it.
  • Used as an adjustment layer, the original photo stays unchanged.
