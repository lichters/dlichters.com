Conversion testing, site speed and monitoring

Section 5.18 · 18 of 22 in this chapter · 15 min read

In short

  • Watch recordings of real visits to find where shoppers get stuck. Fix the most frequent problems first.
  • Trust GTmetrix and Google PageSpeed Insights for speed checks. Shopify's own speed score is less useful.
  • Remove apps you do not need. Each app adds code that slows the store.
  • Wait with expensive testing tools until you have enough visitors and basic fixes in place.
  • Google Optimize was shut down in September 2023. Check a current tool before you set up a test.

Conversion Testing: Prerequisites

1 min
  • Testing tools named in the sources include Optimizely, VWO, Convert and Google Optimize.
  • Tools for finding conversion problems (where visitors fail to buy) include Google Analytics with Shopify Analytics, Usertesting.com for user tests, and session recording tools such as Hotjar, Smartlook and FullStory.
  • VWO and Google Optimize-style platforms are for running controlled tests. They are only worth the investment once traffic (visitors coming to the store) and basic best-practice fixes are in place.
  • Track conversion rate tests and planned future tests in a Trello board (a board of task cards) or a spreadsheet, Google Sheet, Asana or similar project management tool. A downloadable Trello template can be used as a starting point.

Conversion Testing: Tools

2 min

Visually (Shopify A/B testing)

  • Visually is a Shopify A/B testing platform available risk-free through Source E. It has no charges until reaching 1.5x to 3x return on investment (money earned back for each dollar spent), which creates zero upfront app cost.
  • Its recommendation engine (the part that suggests products) uses Shopify purchase data, customer order history and on-site browsing behavior.
  • Most tests are set up in 3-4 clicks, with toggles for magnifying glass, reviews and design elements. Custom options are available through the Visually team.
  • Visually runs no-code A/B tests and on-site experiences: promotion bars, social proof, product recommendations, product upsells, custom HTML, CSS and JS components (HTML sets page structure, CSS sets page look, JS, or JavaScript, adds page behavior), redirects, Fake Click, and global CSS or JavaScript files.
  • Results are sent to Google Analytics (Google's visitor tracking tool) when the event box is ticked.
  • The Redirect feature sends visitors to a different URL (web address). This lets you compare two pages, such as two landing pages (the first page a visitor sees), and optimize conversions without code. It sits alongside Fake Click, Global CSS and Global JavaScript in the element list.

Lively

  • Lively is an app for A/B split testing (showing two versions to split visitors) on a Shopify store. After major website changes, run the new version against the old one in a controlled test, so each version gets enough visitors to show a clear result.

Lomio

  • Lomio is used for price and image testing, and for description testing, rather than full page tests. It is a quick way to shift prices and visuals on one product.

Neat

  • The Neat A/B testing tool is an option for Shopify stores to run conversion tests. It can be used alongside another testing tool to compare results.
  • Neat AB Testing is a split-testing app from the Shopify App Store (Shopify's shop of add-on apps). It pulls conversion data from the Shopify checkout (the payment step) and links it to each page version, so results are collected inside the app.

Google Optimize (discontinued, meaning shut down)

  • Google discontinued Google Optimize in September 2023. It can no longer be used, and current alternatives must be checked before setup.
  • Older sources (2021-22) describe Google Optimize as a free split-testing tool linked to Google Analytics for on-page tests (tests on one page). That method no longer works as described, so a current alternative is needed.
  • For landing page split tests in 2026, use a current A/B testing app that works with Shopify instead.

Session Recording: Lucky Orange

1 min
  • Lucky Orange records your visitors' mouse movements and clicks on store pages in real time (as they happen). It creates heatmaps showing where visitors interact.
  • You can watch individual visitor sessions to see scrolling patterns, cursor movements and interaction points.
  • Lucky Orange records visitor sessions and shows country and location. It can be used to measure average time on site.
  • Lucky Orange offers a 7-day free trial. If you continue after the trial ends, the subscription costs $10 per month.
  • Use Lucky Orange to show why people bounce (leave a page at once). A free trial or free account is enough to start.
  • Use it to spot frustrating elements, such as things visitors try to click that are not clickable, which increase bounce rate (the share of visitors who leave at once). (Advice from 2023.)
  • It shows where visitors click, where they stop and whether something on the site looks broken.
  • A free trial is available for testing.
  • Lucky Orange shows how visitors behave on a store, so you can make optimizations (improvements) based on what they actually do.
  • Microsoft Clarity is a free alternative that offers similar behavior tracking.
  • It shows how long a visitor has looked at a product before leaving. You can use that information to personalize abandoned cart messages (messages to people who left items in their cart).

Bot traffic and IP addresses (Lucky Orange)

  • Lucky Orange shows visitor IP addresses (the number that identifies each internet connection). This lets you block bot traffic (automatic visits by programs, not people) that inflates visitor counts.
  • A seven-day free trial is enough to collect this data. You can cancel afterwards.
  • Repeated visits from one IP address with no purchases are most likely a bot.
  • To check, search the IP address on Google. Others often identify it as a Google, Microsoft or Meta bot.

Session Recording: Other Tools

1 min
  • Hotjar offers heatmaps, scroll maps (how far people scroll), user recordings and exit-intent feedback polls (questions shown as someone tries to leave).
  • Smartlook is a similar session recording tool.
  • FullStory is the most expensive option of this group.

Daily recording review routine (Hotjar, Smartlook or similar)

  1. Install the tool on the store.
  2. Once a day, spend 10 to 15 minutes watching about 5 recordings.
  3. Prioritize visitors who added products to cart but did not complete the purchase.
  4. Look for buttons that are hard to find, checkout buttons hidden by scrolling, elements visitors click that are not clickable, and rage clicking (clicking the same spot again and again out of frustration).
  5. Record each flaw and fix the most frequent ones first.

User Testing

1 min
  • User testing services let you buy recorded sessions with real users matching a chosen audience, such as age range or interests.
  • Assign them a task, such as buying a specific product. You receive recordings with spoken thoughts and notes on why tasks were easy or hard.
  • Usertesting.com is named as the tool for user tests when looking for conversion problems.

Speed Measurement: Which Numbers to Trust

1 min
  • Shopify's built-in speed test is not a reliable measure. Use Google PageSpeed Insights (Google's free speed checker) and GTmetrix for speed checks.
  • A Shopify speed score is less useful than the GTmetrix breakdown for finding the cause. (Advice from 2023.)
  • GTmetrics and Shopify can show different load times because the tests run from different locations.
  • The slowest item in the GTmetrics waterfall (a list of every page file with its load time) is usually the same slow element that shows up in Shopify.

Speed Measurement: GTmetrix

2 min
  • GTmetrix is a free speed test. It reports page load performance and a waterfall of every page element with its load time. Use it to find the element slowing a product page.
  • GTmetrix reports a performance score and a waterfall chart. The waterfall shows how each element of the page loads, from fastest to slowest.
  • It shows the scores, the elements slowing the page, and the code loaded on the site. (Advice from 2023.)
  • A free account with no credit card is enough for these tests.
  • The free GT Metrics account needs no credit card and allows about 3 speed tests per day. Enter the product or store URL (web address) and run the test to get a starting score.
  • The free version also shows which installed apps or tracking scripts (small code pieces that track visitors) slow the page.

Reading the waterfall

  • The GT Metrics Waterfall view lists every loaded resource (each file the page loads) from fastest to slowest.
  • Scroll down to the lines that stretch furthest to the right on the timeline. These are the slowest items.
  • Optimize or remove the apps or resources that cause them.
  • Check the waterfall to find slow images or app code, then remove or reduce them.

Speed check procedure (GTmetrix)

  1. Run the store URL through GTmetrics.
  2. Open the waterfall view.
  3. Find the item loading slowest, such as a large image or an app script.
  4. Fix it, or send the code to the developer for identification.

Finding a slow app (GTmetrix)

  1. Create a free GTmetrics account.
  2. Enter your store URL and run the test.
  3. Open the waterfall view.
  4. Scroll to the bottom of the waterfall to see the slowest-loading items.
  5. Note any app or developer names you do not need.
  6. Remove the unneeded app from the store.
  7. Retest the store speed.
  8. Contact the app developer to ask them to remove any leftover code.

Speed Measurement: PageSpeed Insights

1 min
  • Google PageSpeed Insights often returns generic speed recommendations that are impractical for a Shopify store.
  • Filter its results against your actual app list and image sizes. Start with the heaviest elements, such as apps and unoptimized images (images not yet compressed).
  • The "Remove unused JavaScript" entry lists each script with its host domain (the website that serves it), such as a chat widget, pop-up, analytics or finance vendor.
  • Use those domains to match each slow script to the installed app that injects it (adds it to the page) before deciding to remove or replace it.
  • Use Google PageSpeed Insights, GTmetrix and Pingdom to test page speed regularly. They list suggested fixes, though many of those fixes are technical.

WebPageTest waterfall

  • In a WebPageTest waterfall, one slow third-party request (a call to an outside service), such as a chat widget that stalls on connection, can hold back every request that follows it. This can push the Largest Contentful Paint out by tens of seconds.
  • Locate the stalled item by its position in the waterfall. Removing that one script can change the result more than any other fix.

Apps, Scripts and What You Control

1 min
  • Installed apps add code that slows a store. The impact depends on how each app is built, not only on how many are installed.
  • Remove apps that are not needed, so their code is removed as well.
  • Shopify's hosting, CDN (a network of servers that delivers files fast) and base platform scripts cannot be changed. Focus optimization effort on images, apps, custom code, CSS, HTML and JavaScript that the store controls.
  • The standard Shopify plan at about 29 dollars per month serves assets (images and files) from cdn.shopify.com. The store does not need a separate CDN for normal speed.
  • Check hosting-level items in PageSpeed Insights, including Google Tag Manager (one place to manage tracking codes) and tracking tools. Hotjar, Privy, Zotabox, Klaviyo, Facebook and Google Analytics scripts add JavaScript cost. Check whether each is still needed, and move tags to Google Tag Manager where possible.
  • Financing widgets such as Bread load their scripts on every page, including the homepage. Shoppers only need them on product or checkout pages. For high-ticket stores (stores selling expensive items), check whether the financing app's scripts can be limited to those pages.

Image Optimization and Alt Text

2 min
  • Add image alt text (a short written description of a picture, read by search engines and screen readers) either manually or with a free Shopify app from the Shopify App Store. Compress product images as well, since large images slow the store down.
  • Minifier adds metatags (alt text) to product photos automatically. It resets once per month.
  • If only some photos get tagged when you expect all to be tagged, contact Minifier's support for a reset, then run it again.
  • Crush Picks is an alternative app if Minifier issues persist.

Smart SEO: optimize images by collection

  1. Open the Collections tab.
  2. Select all collections.
  3. Deselect those without images. Only collections that actually have images need this step.
  4. Click Optimize collection images.

Path: Smart SEO app > Configure > Image optimization.

Smart SEO: optimize product images

  1. Open the Shopify admin and open the Smart SEO app.
  2. Find the Image optimization section and click Configure.
  3. Open the Products tab. The app pulls in all store products and shows whether each image is optimized.
  4. Tick the products to optimize, for example all of them.
  5. Click Optimize product images and wait for the job to finish.
  6. Check the savings shown afterwards for the combined image size before and after.

Expected results

  • In one test with 10 products, the combined image size dropped from 60.2 MB to 18.1 MB, which saved about 42 MB.
  • A store with hundreds or thousands of products may need around 30 minutes or longer. The job can run while you work on other tasks.

Smart SEO: add alt text to product images

  1. Open Smart SEO, go to the Alt tags section, and click Configure.
  2. Select all products with the checkbox at the top and click Edit products.
  3. Set the alt text to the product title as a dynamic value pulled from the store, then click Save.
  4. Open each product image and rewrite its alt text to describe what the image shows, such as the view angle (for example, front view, front view with model, back view with model).
  5. Save each change.

Broken Links: Check My Links

3 min
  • Check My Links is a free Chrome extension (a small add-on for the Chrome browser) offered by pagemodified.com. It checks every link on the page you are viewing and marks broken ones.
  • It finds 404 links (links to pages that do not exist) on other sites without clicking each link manually, which is too slow on pages with dozens of outgoing links.
  • Use Check My Links for broken link building (finding dead links on other sites and offering your link as a replacement). Searching the Chrome Web Store for "check my links" returns similar extensions, such as Link Redirect Trace from linkresearchtools.com and Redirect Link Checker. Use the extension offered by pagemodified.com.
  • Page Modified also offers a crawl (an automatic scan) of an entire website instead of only the open page. Use the full-site crawl when you need to audit every page of a site for broken links.

Installation

  1. Install Check My Links from the Chrome Web Store.
  2. Chrome asks to add it with the permission to read and change all data on the websites you visit. Accept this to add the extension.
  3. The default options can be left unchanged.

Options

Option Setting Units
Method of Request Keep GET as the default (GET asks for the full page; HEAD asks only for the page header). HEAD is faster but can misreport the true HTTP status (the page's result code) of a page. Switch to GET if results look odd. GET is also required to parse hashtag targets by element ID (read the part of a link after #, which points to a spot on the page).
Autocheck When enabled, the extension checks links automatically whenever the URL of the current tab changes and the page has loaded. If you enable it, also enable Valid Link Caching.
Warnings Warnings appear in the browser console (F12 opens the developer tools, then choose the Console tab) and are highlighted yellow. Optional checks: Parse DOM after hashtag (flags a hashtag link whose target element does not exist; DOM is the page's structure), Trailing # (flags links ending in #), Empty Link (flags empty href, the empty link address), and Anchor tag without href.
Valid Link Caching Enable it so the extension stops re-checking good links that return HTTP 200 (the code meaning the page works). It only checks new links or links that were previously broken. This greatly reduces the time needed to recheck a page. The Clear Cache button resets it (wipes the saved results).
Nofollow Links By default the extension skips links with the nofollow attribute (a tag telling search engines to ignore the link), so only dofollow links are checked. Leave the option Check Links with rel=nofollow unchecked, because dofollow links are the ones worth pursuing for backlinks (links from other sites to yours).
Exclude links from these domains Enter one domain or URL part per line to skip it. The default list already excludes ad network domains such as googleadservices and doubleclick, and appliedsemantics.com, because these are not sites you would contact about a link.
  • On the options page, change the settings you need, then click the "Save my preferences" button at the bottom so the changes are stored.

Uptime Monitoring: Pingdom

1 min
  • Pingdom monitors the website every minute and sends SMS or email alerts on downtime (when the site is offline).
  • The base plan costs about $10 per month or $100 per year and covers up to five sites.
  • A common alert threshold (the amount of downtime before you get an alert) is 10 or 20 minutes, to avoid noise from brief hiccups (short glitches).
