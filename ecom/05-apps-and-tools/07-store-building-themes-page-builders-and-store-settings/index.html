Store building: themes, page builders and store settings

Section 5.7 · 7 of 22 in this chapter · 17 min read

In short

  • Shopify is the software that runs your shop. Start with the basic plan.
  • Check the theme first. A paid theme can replace several paid apps.
  • Test page builders in this order: PageFly first, then Source F Team.
  • Prices and deals change. Check them yourself before you buy.
This section has 13 parts. Tap one to open it.

Shopify plan and admin basics

2 min
  • Shopify is the software that runs your online shop.
  • Under Settings > Plan you see your current Shopify plan. You can upgrade or downgrade it there.
  • Paid app subscriptions are managed in the subscriptions section of the same area.
  • For a new store, the Shopify basic plan is the recommended starting plan.
  • You can change the plan later when your needs grow.
  • Shopify Plus is only for high-volume stores (stores with many orders) that need complex functionality. (2023)
  • Shopify Plus is expensive. It is not needed for the stores built in this handbook. (2023)
  • Shopify hosts the store (it keeps the shop online) and offers a 14-day free trial.
  • The Shopify back end (the admin area behind the shop) shows visitor and session data (each visit is a session). Use it to analyse traffic (how many people arrive) and conversion (how many of them buy).
  • A Shopify partner offer from November 2024 gave three days free. Then it gave three months at 1 USD per month for a new account, a total of 3 USD. (2025)
  • Check the current Shopify terms before you rely on this offer. Promotional deals change. (2025)
  • Shopify includes SSL. SSL is a security lock that encrypts the connection between visitor and shop. It shows up as HTTPS, the "s" in the web address. (2023)
  • A separate SSL check or certificate purchase is not needed. Check the website's HTTPS status in Shopify. (2023)
  • Shopify also covers email marketing (sending emails to customers), order tracking, live chat and visitor analytics (visitor statistics).
  • These functions are inside the same platform. Separate tools are not required for them.
  • Under Sales channels, only Online Store should be shown by default. A sales channel is a place where you sell.
  • If Point of Sale (the in-person cash register app) appears, and the store does not sell in person, remove it. Use the three-dot menu and choose Uninstall.
  • Installed apps appear automatically under Settings > Apps and sales channels, as sales channels.
  • The list grows over time. On a new online-only store, only Online Store should be shown.
  • The store is created first as a demo (a test version that customers cannot use).
  • The store goes public when you remove its password.
  • A password-protected store cannot run as a live store. A live store is one open to real customers.
  • The storefront password step only matters for demo or development stores.
  • A live store should not sit behind a password once Smart SEO is set up. SEO is the setup that helps Google find your pages.

Admin workflow: files and preview

1 min
  • Content > Files holds all uploaded images in one place.
  • The file picker (the window that lets you choose a file) in each section draws from this list. So upload first to save time.
  • The theme customizer is the editor where you change how the shop looks.
  • It has a live desktop preview and a separate phone preview.
  • Use the phone preview after each edit. This helps you catch layout problems early. Layout means how things are arranged on the page.

Shrine theme setup (step sequence)

1 min

  1. Create the account on the register page. You need an email address, a password and a password confirmation. Then click Create Account. Users who already have an account choose Sign in on the same page instead.

  2. License keys unlock the paid theme. They follow the pattern SHRINE-PRO- followed by two five-character groups, for example SHRINE-PRO-4AP05-2X84Z.

  3. The keys arrive by email. The email comes from a noreply sender (an address that cannot receive replies). The subject is Your Shrine License Keys.

  4. Enter the keys under Add key in the Shrine dashboard (the control panel). This activates the license.

  5. Whitelist your URLs (add them to an approved list) under Keys > Accounts > Whitelist your URLs. The form has three fields:

    • Main URL, for example https://yourstore.com
    • Secondary URL (Optional), for example https://yourstore.co.uk
    • Shopify URL, for example https://store.myshopify.com

  6. Every URL entered in the whitelist must start with https://.

  7. Entering it without this prefix can cause the whitelisting to fail.

  8. Find the Shopify myshopify.com URL. This is the free address Shopify gives your store.

  9. Find it under Settings > Domains in the Shopify admin (the back office), in the domain list at the top.

  10. The custom domain of the store (your own web address) appears in the same list.

  11. Whitelist both the Shopify myshopify.com URL and the custom domain of the store in Shrine.

  12. This is required to manage the Shrine account and its keys.

  13. Click Save and generate token. A token is a long access code.

  14. The token is required for the theme download. Save it somewhere safe. Losing it means the access steps have to be repeated.

Theme code editing

1 min

Procedure for finding and editing code in the theme. Code is the instructions behind the design.

  1. In Shopify, go to Online Store > Themes. Click the three dots next to Customize, and choose Edit code.
  2. Use Filter files to search the theme folders.
  3. Note that it may not find text inside files.
  4. Open each file one at a time. Press Cmd+F on Mac or Ctrl+F on PC to find the text.
  5. Before editing or deleting anything in the code editor, copy the entire original code into a document.
  6. This lets you restore it.
  • Custom Liquid is a block (a box you add to a page) for inserting custom code into the product page. Liquid is Shopify's own code language.
  • It is an advanced feature. It is not needed at the start.

Page builders: choice and testing

2 min

  • A page builder is a tool for designing pages.

  • Test page builders in this order:

    1. Start with PageFly.
    2. If no results appear, switch to Source F Team.

  • Use only PageFly and Source F Team for page building.

  • Ecomposer has not been tested operationally. This means it has not been tested in real use.

  • Ecomposer charges a monthly subscription.

  • PageFly's free tier (its free version) eliminates this cost.

  • PageFly offers a free version covering one store.

  • It includes tutorials for all core functions.

  • PageFly is a page builder for creating product and landing pages.

  • It is used for split tests against the standard store page. A split test shows two versions to different visitors and compares sales.

  • Prestige and Refresh were the page builders the source recommended most.

  • PageFly is a free landing page builder.

  • It is used to create product pages for split-testing against a Shopify theme.

  • PageFly is free and makes sense for single-product tests.

  • For a general store selling several items, a landing page may not be necessary.

  • This is especially true with a multi-buy offer. A multi-buy offer is a deal such as buy two, save more.

  • PageFly suits single-product storytelling pages. These fit emotional or niche products (small, specific markets).

  • It is recommended over a standard collection page setup. A collection page lists many products.

  • PageFly and Replo build landing pages without code.

  • They work for prototypes (test versions).

  • They usually cannot handle complex features such as bundle builders.

  • PageFly and Jam Page can rebuild a product page.

  • Any builder works as long as the required sections are present on the page.

  • Page 5 (PageFly) was used as the landing page builder.

  • It was used instead of GemPages, because it was described as better and cheaper.

  • Gem Pages or PageFly are product page builder options.

  • Loox reviews (a product review app) offers a two-week free trial for product reviews.

  • Learning PageFly's basic workflow takes about one hour.

  • Plan a separate block of time for it when building a store.

  • Gem Pages and PageFly are store design apps.

  • The owner should learn how to use them before delegating store design (handing it to someone else).

  • PageFly has ready-made product page templates. These are ready-to-use layouts.

  • Use one to assemble a landing page with the sections a product page needs. These sections are: headline, lifestyle images (photos of the product in daily life), trust badges (small logos that show safety), star ratings and short bullet copy (short text points).

  • Use PageFly's manual layout editing when a theme or template does not show a banner or section correctly. A banner is a wide image strip at the top.

  • PageFly includes live chat support, even on the free plan.

  • Support is reliable for troubleshooting page build issues, styling problems and design questions.

  • Contact them through the PageFly app dashboard when you are stuck.

  • Do not use workarounds (quick fixes that avoid the real solution).

PageFly layout and styling

1 min

  • In PageFly, click Plus, then Layout. This inserts pre-built rows with 1, 2, 3 or more columns.

  • Each row stacks on top of the previous one. Its columns sit side by side on desktop.

  • Select a row by clicking its name in the breadcrumb (the path shown at the top of the editor).

  • Set mobile columns per line on the row.

  • Set the desktop column count in the row's General tab.

  • To make identical elements match in one step:

    1. Copy the style from one element (right-click or the style menu).
    2. Paste the style to all other identical elements.

    This updates colors, sizing and formatting across the page at once.

  • It is faster than editing each element individually.

  • A hex color is a six-character code with a leading hash that encodes red, green and blue values.

  • A Chrome color picker (a color tool in the Chrome browser) can read any on-screen color.

  • It can copy that color's hex code for PageFly color fields.

  • To set transparency with custom CSS (style code), open the Advanced section at the bottom of the element settings.

  • Add this line. Here 0 is fully transparent and 1 is fully opaque (solid):

opacity: 0.5;
  • PageFly's slideshow arrow colors may not be editable in the editor.
  • Ask PageFly support for a custom code snippet (a short piece of code) to recolor the arrows.
  • Joy Pixel is a browser extension (an add-on for your web browser).
  • It inserts emoji and icon symbols into PageFly text fields and buttons. You do not leave the editor.
  • Use it for call-to-action icons (buttons that tell people what to do), benefit bullets or section headers.
  • Use it instead of searching external icon libraries.

AI page builders and visuals

1 min
  • Instant AI Page Builder builds listicle pages. A listicle is an article written as a numbered list.
  • Listicle pages work as pre-landers. A pre-lander is a page that warms up customers before the product page.
  • Shopify Sidekick is Shopify's built-in AI helper.
  • Sidekick theme generator template sections can build the comparison chart or other AI-generated visuals.
  • They build these directly into the theme.
  • This is better than making them ad hoc (one-off, by hand).
  • When an AI tool turns a page section into a visual, it can pick up fonts, colours and style from the live store.
  • So a basic request can already give on-brand output. On-brand means it looks like your brand.
  • A more specific request gives better results. Name the colours, fonts and the look you want.
  • Download the finished visual and upload it to the site. Or have the theme build it as a section.

Product page elements

2 min

Tabs:

  • EasyTabs creates tabbed sections on product pages. Tabs are clickable labels that show different text.
  • Content such as product description, shipping policy, warranty information and return policy sits in separate clickable tabs.
  • Older advice from 2020.
  • Product page tabs are built with the EasyTabs app in the theme.
  • Set up and check the tabs for product description, specifications, shipping details and Why Buy From Us.
  • Older advice from 2021 to 2022.
  • Easy Tabs by NexusMedia adds tabs to product pages in three ways.
  • The three ways are: standard tabs built from the product description.
  • Static tabs are shown on all products or selected collections (groups of products).
  • Integration with third-party review apps (apps made by other companies).
  • It also includes a Layout section. This controls padding (inner space), colors, borders, typography (font style and size), responsive behavior (how it adapts to screen size) and custom CSS.
  • Older advice from 2021 to 2022.

Sticky add-to-cart:

  • Sticky Add to Cart is a Shopify app. Find it in the Shopify App Store.
  • It keeps the add-to-cart button visible on mobile. It stays visible while the visitor scrolls.
  • The source reports about a 25 percent increase in add-to-cart rate after adding it.

Video and third-party embeds:

  • For product page videos, embed from YouTube rather than uploading directly. To embed means to show a video from YouTube inside your page.
  • Suppliers often provide YouTube links. Use the embed code (the code that shows the video) in the Shopify product description.
  • Older advice from 2022.
  • For app integrations such as scarcity timers and product reviews, place the app's HTML code manually. HTML is the code that builds web pages.
  • Scarcity timers are countdown clocks that show limited time or stock. Examples are VitaLabs and Countdown Timer.
  • Product review examples include LAI product reviews.
  • Do not rely on automatic plugin integration. Automatic integrations often display elements in undesired locations or break page layouts.
  • Copy the HTML the app provides. Paste it into the page builder (PageFly, Shopify) to control exact placement.
  • If integration issues persist and consume time, contact app support. Do not build workarounds.

Complementary products:

  • The complementary products block is a box that shows items that go well with the one being viewed.
  • It recommends items such as paddles, leashes or cases.
  • It needs the Search & Discovery app to link the products you want to show.
  • It is not needed until the store sells products with accessories.

Filters and price tags:

  • Shopify apps for product filtering are available for most requirements. A filter lets visitors narrow products down.
  • If the theme does not include a filter, install an app. Do not build a custom feature.
  • Older advice from 2020.
  • To find a filter app for an All products page, search the Shopify App Store for filter. Then compare the options. (2024)
  • No single app is clearly the standard. (2024)
  • Some stores skip a filter app. They rely on tags (labels attached to products) instead. (2024)
  • A savings percent tag next to a sale price depends on the theme. The method differs per theme.
  • On the Source A theme, it is an option in settings.
  • On other themes, check the theme creator's documentation (the maker's instruction manual) or search for code.
  • Older advice from 2020.

  • This applies unless you offer carrier-based shipping rates. These are prices calculated by the delivery company.
  • Free shipping is typically included in the price.

  • They can do this for specific products without a third-party app.
  • Use them to offer free standard delivery.
  • Use them to offer upgrades such as white glove delivery. This is delivery with setup inside the home.
  • Older advice from 2021.

  • This is because it may not be a built-in function.
  • Contact Shopify support to confirm available options before you plan a launch in multiple countries.
  • Older advice from 2020.
  • To restrict collections (limit who can see them), search the Shopify App Store for password protected collection access or wholesale password apps.
  • These apps lock collections or products until a password is entered.
  • Older advice from 2021.

Translation and new markets

1 min

Procedure for activating a new market (a new country or language group to sell to) with the Shopify Translate app (an app that translates your store):

  1. Use the Shopify Translate app instead of building a new store.
  2. Activate a new market, for example the UK, Australia or another market.
  3. Translate the store.
  4. Run English ads to that market with a budget of about 100 euros to see if performance improves.
  • Shopify Translate & Adapt is a free app in the Shopify App Store. It is rated 4.6.
  • It translates the store and adapts content to international audiences.
  • It is listed as an option when adding store languages.
  • Adding translations improves cross-border conversion (sales to buyers in other countries).
  • The average improvement is 13 percent.
  • This is according to the source.
