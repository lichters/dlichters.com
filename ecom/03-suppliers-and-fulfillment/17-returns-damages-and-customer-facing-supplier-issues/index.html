Playbook › 3. Suppliers and fulfillment

Returns, damages and customer-Facing supplier issues

Section 3.17 · 17 of 22 in this chapter · 12 min read

In short

  • Your return rules should follow your suppliers' return rules, because the supplier decides what can come back and who pays.
  • Check each supplier's return policy and damage rules before you offer refunds or sell its products.
  • Follow up on every return request until the supplier actually handles it.
  • Check samples and order accuracy before you spend more on ads.
  • If a supplier keeps sending damaged or wrong items, change suppliers.
This section has 11 parts. Tap one to open it.

Setting the Return Policy from Supplier Policies

2 min
  • Your customer return policy (the rules you give buyers for sending items back) should match the average of your suppliers' return policies. A supplier is the company that makes or ships your products. If most suppliers charge return shipping, the customer pays return shipping.
  • Choose suppliers by their return rules. Set your return policy for each supplier or each brand.
  • If a supplier accepts no returns, state clearly on those product pages that the item cannot be returned.
  • Each supplier's return policy is written into its agreement (the contract you accept with that supplier). It states how long returns are accepted and for which reasons.
  • Check it for each supplier before you offer refunds.
  • Returns are handled supplier by supplier, not by Shopify (the online store software you use).
  • Most suppliers offer a 30-day return policy. You can see it when you sign the supplier agreement.
    • The supplier issues a return authorization label (a shipping label that approves the return).
    • The item ships back to the supplier's warehouse (the place where the supplier stores its stock).
    • The supplier credits the sale (gives you credit for the order).
  • Before you commit to a supplier with a higher return rate (the share of sold items sent back) or with heavy items, ask about its return policy and its fulfillment options (how it packs and ships orders).
  • Check whether it accepts returns at all. A supplier that does not accept returns affects your own return policy.
  • Many suppliers in China offer poor return policies. Returns often require the store to pay return shipping.
  • Agree on return and size-change handling with the supplier before launch (before your store goes live).
  • Returns can go back to a supplier abroad (in another country), but the store pays the return shipping.
  • A store with its own warehouse in the country where it sells can receive returns locally. The goods must still be flipped again (made ready to sell again).
  • Ask each supplier in advance whether it pays for a free replacement when an item is damaged in transit (while it is being shipped).
  • Some suppliers cover the cost. Others only file a claim (a formal request for payment) with the shipping company. This changes how you handle damage claims (requests for compensation).

Return Rate Benchmarks

1 min

Two sources from 2021 give different rules. Use the table to see when each applies. A benchmark is a target number you compare your results against.

Rule Value When it applies Source
Fixed target 1% or lower Benchmark for every product. If returns consistently exceed it because of supplier packaging or quality, discontinue the supplier (stop working with it) regardless of other factors.
Situation-dependent check No fixed percentage Assess the product case by case, using the four factors below.

Situation-dependent check, four factors:

  1. How many units of that product have sold.
  2. The root cause (the real reason) of returns: packaging damage, quality control, or customer expectation.
  3. If returns are a problem from day one because of supplier quality, discontinue the supplier immediately.
  4. If returns come from customer misunderstanding, fix the product page with clearer information.
  • Incorrect sizes raise the return rate, so a wrong size chart (the table of sizes shown to buyers) costs money through refunds and returns.
  • Verify every size against centimeter measurements before you sell.

Free Returns and Restocking

1 min
  • Offer free returns only when the item is defective (faulty) or damaged, because then the supplier covers the cost.
  • For other returns, match the usual restocking fees in your niche (your product group). A restocking fee is a charge the customer pays to send back an item.
  • Avoid testing free returns before you have a cash reserve (money saved up for emergencies).
  • If a supplier has no return policy, state on the product page that the item is not eligible for returns, except for damaged or defective items.

Product Pages and Policy Pages

1 min
  • In Shopify, product pages have tabs (clickable sections, such as "Shipping"). The Shipping tab can show the specific supplier's return policy for that product, so make the supplier return policy unique on each affected product page.
  • On the main Shipping and Returns page, state that the store's return policy excludes named suppliers.
  • Then add each excluded supplier's own shipping and returns policy below that statement.
  • Products from a supplier that does not accept returns can be marked on the product page as not eligible for return.
  • The shipping and return policy can say that some exclusions apply and list them.
  • The store's general shipping and return policy should combine its suppliers' policies.
  • If a supplier does not accept returns, the product page says the item is not eligible for returns. The policy page lists that exception below the general policy.
  • Dropshipping means selling products that a supplier ships straight to the customer, so you never hold the stock yourself.
  • When returns go to a third-party warehouse (a warehouse run by another company, not your business address), the refund policy should state that the exact return address is given only after the return is authorized.
  • Without this statement, Google may flag the site (mark it as a problem) for hiding a dropshipping model.

Pre-Purchase Return Option (Checkout Plus)

1 min
  • Checkout Plus is the name of this pre-purchase return option, which the customer can add at checkout (the payment step).
  • Checkout Plus is an unfulfillable product on the order. Unfulfillable means it is never picked or shipped. It stays on the order as a line (one item row) that is not sent out.
  • The main operational step (the daily work step) is to make sure the 3PL (a company that stores and ships your orders for you) or warehouse understands this.
  • No return label is included at purchase because of Checkout Plus.
  • Steps:
    1. Create the pre-purchase return option in Shopify as a product so it appears on the order.
    2. Tell the 3PL or warehouse that this line is unfulfillable and must not be picked or shipped.
    3. Confirm that the line is visible on the order for customer service staff.
    4. Set a separate price per Shopify Market (a country or region you sell in) if the offer runs in several markets.
    5. Do not include a return label at purchase because of the option. The label is issued only when the return is submitted.

Damaged Deliveries and Claims

1 min
  • Before you sell a product, check whether its type is prone to (likely to have) shipping damage.
    1. Search Google for the brand names of your future competitors (other stores selling the same kind of product).
    2. Read their reviews and look for complaints that items arrived damaged.
    3. If many competitors have such complaints, assume the problem affects most suppliers in that industry.
  • Shipping damage depends more on the supplier and its packaging than on the niche itself.
  • Industry-wide damage patterns can still show up in competitor reviews.
  • Claim routing (who handles a damage claim) for damaged deliveries.
  • The shipment must be insured in both cases. Insurance covers the value of the goods if they are lost or damaged.
Who ships from its account Who files the claim What the seller still does
Supplier Supplier, which processes the replacement or exchange Handles the customer and the claim
Seller, with insurance Seller, with the shipping carrier Handles the customer and the claim
  • If a supplier repeatedly sends damaged goods, especially for fragile products, change suppliers rather than accepting the losses.
  • For a cheap product, the cost of goods (what you pay for the product) plus shipping to the US can be about 7 to 8 USD per unit (for each single item).
  • Use this figure to decide whether a replacement or a partial refund (giving back only part of the money) costs less than a return.

Freight Deliveries and Refusals

1 min
  • For damaged large items delivered by freight (large shipments moved by truck or cargo company).
    1. The customer photographs the damage on arrival.
    2. The customer notes the damage on the delivery receipt (the paper signed at delivery).
    3. The customer reports the damage to the carrier (the shipping company).
    • Carrier reporting applies to freight or LTL (less-than-truckload, a freight shipment that shares a truck) shipments.
    • It does not apply to parcel carriers such as UPS, FedEx or USPS, which ship small packages.
    • Large freight items require a signature on delivery.
    • The shipping company calls the customer to set a delivery time.
  • Freight deliveries require the buyer to be present to inspect the package and sign the receipt.
  • If the outer packaging is clearly damaged, tell the customer to refuse the delivery.
  • A refused shipment can be replaced by the supplier without repacking or return shipping.
  • For a freight shipment from a supplier, follow the freight carrier's guidance for damage claims and refusals.
  • A damaged item that is accepted and then opened creates a much bigger return hassle than one refused at delivery.

Supplier Errors and Substitutions

3 min
  • Dropshipping means you have no warehouse of your own, so supplier mistakes land on you as refunds, complaints and reputational damage (harm to your brand's reputation).
  • Chinese suppliers may promise much and later deny the promise, so verify quality before you scale (grow your sales and ad spending).
  • If a supplier ships a different product than the one you specified, the supplier is responsible for the mismatch.
  • Before shipping, the supplier should send a photo or video of the product from the factory.
  • Supplier quality varies by agent (a go-between who works with factories for you), so judge each agent on its own record.
  • A supplier that sends wrong materials, such as silver instead of gold, leads to negative reviews and can force a store to close.
  • Confirm supplier quality before you scale.
  • Wrong or low-quality items from a supplier can create enough complaints and disputes that the brand's Facebook account and its ads are lost.
  • Check samples (test products) and order accuracy before you increase ad spend (money spent on ads) on a new supplier.
  • Ask dropship suppliers to contact you before sending any replacement or substitute item when the original is out of stock (no longer available).
  • Suppliers may send a similar item or another brand's product to protect their own profit, which can damage your brand.
  • Make this explicit in the agreement and in regular communication.
  • A dropship supplier substituting a different colour, variant (a different version of the same product) or branded item for the ordered product can trigger chargebacks (the customer's bank takes money back from you after a complaint) and customer complaints.
  • In one case, around 300 units went out with another brand's label, which nearly crippled the business (almost destroyed it).
  • When a supplier is backlogged (behind on orders), ask it to ship the existing orders instead of issuing refunds, since refunds often create more problems.
  • Resume ads only after the backlog is cleared or a new supplier is confirmed.
  • For an AliExpress order (AliExpress is an online marketplace where you buy from suppliers) that needs a refund, the seller can ask AliExpress to refund the supplier payment.
  • In the reported case the money came back almost immediately.
  • Handle the buyer's refund separately, since the item may never need to return to the supplier.
  • Whether to cancel an order and request a refund depends on the relationship with the supplier.
  • If the supplier appears to be stalling (delaying on purpose) or lying, request the money back immediately.
  • Long shipping times are less of a problem early on.
  • Reply quickly to customer emails and apologize.
  • Give a reason, such as customs delays (checks at the border) or Covid delays.
  • Offer a discount code (a code that lowers the price) for the next purchase to prevent chargebacks.
  • Case: A seller started a store with necklaces that had strong click-through rates (the share of people who see an ad and click it).
    • A buy one get one free offer produced around 60,000 within two months.
    • The seller then switched to a random new supplier. It shipped the wrong product: gold necklaces arrived in silver.
    • Some orders for African countries went to the wrong country: Egypt orders received Ethiopia products.
    • About 200 orders were affected.
    • Some customers kept the product, others requested refunds, and the seller shut the store and restarted.

Supplier Packaging and Invoices

1 min
  • Expect supplier boxes and product manuals to show the brand name and supplier information.
  • This signals authenticity (that the product is genuine).
  • Suppliers never include invoices or receipts that show your wholesale cost (the price you pay for the product), because they do not sell directly to consumers.
  • Authorized brands (brands that give official permission to sell) that do not sell direct to the public typically include only packing slips (lists of the items in the box) in shipments.
  • They do not include invoices or receipts.
  • This is normal for authorized retailers and has not caused problems in almost 15 years.
  • Default supplier packaging shows the supplier's name, which is normal for dropshipping.
  • Only worry if a packing slip or invoice contains the supplier's name.
  • Shein's logo on a package is a branding problem when reselling Shein products, the same as with normal dropshipping.
  • Branded dropshipping (shipping with your own brand name on the package) or a packaging solution (a way to change the packaging) is needed so the competitor's name does not reach the customer.

Return Procedures

1 min
  • Supplier return handling:
    1. The customer contacts you by email or phone to request a return.
    2. Email the supplier rep (the supplier's contact person) with the order number and ask for a return authorization number (a code that approves the return).
    3. The supplier usually sends a shipping label directly to the customer.
    4. When the item arrives back, refund the customer.
    5. Ask the supplier to refund you. Return policies differ by supplier.
  • Return procedure for damaged or unwanted items:
    1. The customer reports the damaged or unwanted item by email.
    2. The store emails the supplier about that order and asks for a return shipping label.
    3. The supplier sends the return shipping label to the store.
    4. The store sends that label to the customer.
    5. The customer ships the product, and it goes directly back to the supplier's warehouse.
    6. Check each supplier's exact return process and policy during the approval process (when the supplier approves you).
  • Handling a supplier return request:
    1. Send the supplier the order number and the return request. Ask for a prepaid return shipping label (a label already paid for) or the instructions the customer needs.
    2. Set a reminder in your email tool to check for a reply after two or three days.
    3. If there is no reply, follow up politely and ask the supplier to confirm that the return was handled.
    4. Repeat the follow-up until the return is actually processed, because suppliers often delay returns.
  • Suppliers dislike processing returns even more than the store does.
  • A return request should never be assumed to be done just because it was sent.
  • The store is responsible for following up until the supplier acts.

Samples

1 min
  • When customers ask for product samples, such as fabric swatches (small pieces of cloth to show colour and texture), ask the brand whether it will ship samples to your customers for you.
  • Competitors may already do this, and the brand may ask you to pay the shipping.
