Image SEO, visual search and compression

Section 14.12 · 12 of 20 in this chapter · 8 min read

In short

  • Give every image a clear name made of product words, never "image123" or a random code.
  • Give every image its own alt text (a short written description that screen readers read aloud).
  • Shrink every image under 100 KB with an offline tool before you upload it.
  • Use your own photos when you can. Do not use compression apps inside Shopify.
  • Keep product images at 800x800 pixels. Never go below 600x600.
This section has 6 parts. Tap one to open it.

File names and image metadata

2 min

Metadata means hidden information stored inside an image file. The file name is the first piece of metadata Google sees. Name files well.

Filename rules

  • Every image on a website must have a unique filename with relevant keywords (words people type into Google) and a descriptive phrase. Never use generic defaults like "screenshot" or "image123".
  • Every image on a page should have a descriptive file name. At least one image file name on the page should include the focus keyword (the main search phrase for that page). Google reads file names as one of several signals for what the page is about.
  • Every image on the site needs a short, descriptive file name, for example "black dog running" for a photo of a black dog running. Random strings of letters and numbers as file names are not allowed.
  • Image filenames help Google understand both what the image shows and what the page is about. This improves both image search and normal search rankings (where a page appears in results).
  • Image file names should describe the product, such as the brand, model, product type and colour. Do not use generic supplier names like "image 5467". A detail such as "side view" can be added for close-up shots.

Filename patterns by page type

  • Product pages: Name the first image with just the product name. Name later images by combining the product name with what each image shows. Example: "widget-blue-packaging" for the packaging detail, "widget-lifestyle-use" for the in-use shot.
  • Products with several angles: Use variations of the product name. Use synonyms (other words with the same meaning) across the different images.
  • Target keyword: Put the page's main target keyword in at least one image filename. Put related synonyms and variations in the filenames of the other images.
  • Blog post images: The filename should simply describe what the image shows: what it demonstrates, depicts or contains. Do not force keywords in.
  • **** This guidance was written as current practice for Google Images in 2021-2022. Treat these filename patterns as older advice. Check them against current guidance before you rely on them.

Images already published

  1. Update the filename and alt tag of the existing image file.
  2. Re-upload the changed image file to the site. Re-uploading applies the changes.

Images in the product description

  • Images placed in the product description area need unique file names and alt tags, just like the main product images. This step is often skipped.

Alt text

2 min

Alt text (also called alt tag) is a short written description of an image. It is stored in the page code. Screen readers (software that reads the screen aloud for blind or visually impaired people) use it.

Rules

  • Write descriptive alt text for every product image on the product page. This improves SEO (search engine optimization, making a page easier to find in search), supports accessibility (making the site usable for everyone), and gives context if an image fails to load.
  • Each image on a page must have a unique alt tag that describes that specific image. Using the same alt text for several images wastes the optimization chance and gives no extra ranking benefit.
  • Each image's alt tag must be unique. It should include target keywords and synonyms related to that specific image, like filenames do. This helps both normal search and visual search rankings (ranking when people search with a photo).
  • Each product image needs a unique alt tag: a short phrase describing what the image shows. Alt tags serve screen readers, display when an image fails to load, and help search engines, including Google Images, rank the page.
  • Give every product image its own alt text. It should name the product, its key feature and the view shown. Keep it short.
  • Add alt image tags to all images.

What alt text does

  • Alt text describes what an image shows. It helps screen reader users who are visually impaired. It gives Google more context. Accurate alt text can also help product images rank in Google image search.
  • Alt text displays when an image cannot load. It helps screen reader users. It should describe the image and can include the focus keyword.
  • Google reads image file names and alt text to understand the topic of the page.

Entering alt text in the editor

  1. Click the image in the media section (the area where all uploaded files are kept).
  2. Enter the alt text.
  3. Click out to save.

Image size and dimensions

1 min
  • Product images should be 800x800 pixels (800 pixels wide and 800 pixels high). Never go below 600x600 pixels.
  • Cropping example: take a 3000x4000 supplier image and crop it to 800x800. Crop means cutting out part of the picture. Focus on a product detail.

File size and compression

2 min

Compression means shrinking a file so it loads faster. Keep the picture looking good while you do it.

Targets

  • Compress images to reduce file size while keeping quality.
  • Aim for images under 100 KB each (KB means kilobytes, a small unit of file size). Images must never reach hundreds of megabytes.
  • Multi-megabyte product images make product pages load slower. This hurts page speed (how fast a page opens) and organic rankings (ranking in normal search results without ads). Compress them. Good compression keeps the visible quality unchanged.
  • Keep images small enough to load quickly.

Compression principles

  • Compress all images as far as possible without visibly degrading quality. Balance page speed against how good the image looks. A good-looking image helps sales (conversion, when a visitor buys).
  • The optimal point is when image quality begins to noticeably degrade. Most compression tools have settings that show this point.
  • Optimized images look the same to a visitor on a desktop computer, but their file sizes are smaller, so pages load faster. In one blog post, image optimization reduced the image file size by 64%.

Formats and delivery

  1. Compress images to reduce file size.
  2. Use web-friendly formats: JPG, PNG, WebP (file types that work well on websites).
  3. Keep images under 100 KB each.
  4. Use image CDNs (servers that deliver images fast from places near the visitor) or lazy loading (images load only when a visitor scrolls to them) to improve page speed.

Tools

  • Image Optim: A free desktop app for offline bulk image compression (shrinking many images at once on your computer, not on the website). Drag and drop images into it. Adjust compression settings until quality is acceptable.
  • Smart SEO (Shopify app): Use it for bulk optimization (fixing many items at once) of store files and blog posts. The steps are below.

What not to use

  • Do not use Shopify or other on-site image compression apps. Some inject JavaScript (small program code added to the page) that harms SEO. Compress images offline before uploading.

Smart SEO procedure for pages and blog posts

  1. Open the Smart SEO app.
  2. Click Image optimization, then click Configure.
  3. Open the Files section. It holds the images used on the store, on pages and in other parts of the site.
  4. Select all images and click Optimize file images. Let it run in the background (working without you watching).
  5. Open the Articles section. It lists blog posts. Unoptimized posts are shown as not optimized.
  6. Click optimize on each blog post. Posts added later appear in the Articles section and are optimized the same way.

Originality and image sourcing

1 min

Why unique images matter

  • Use unique, original images rather than stock images (generic photos sold to everyone) when possible. Google's algorithm (the set of rules a search engine uses to rank pages) gives preferential ranking treatment to unique images.
  • For resellers and dropshippers (sellers who sell products they do not stock themselves) selling products that competitors also offer, the first person to publish an image is usually treated as the original owner of that version. Unique variations count more than duplicated stock images.
  • Original product photos taken with a smartphone produce high-definition (HD, sharp) images. They work better for search rankings than stock images already used by competitors.
  • Unique images are not a major ranking factor. Put domain authority (how trusted your whole website is) and quality content first. Then add unique images where practical. Do not treat them as a critical step.

Creating unique images from supplier files

  • Crop specific sections from high-resolution supplier images to highlight particular features or angles. Example: take a 3000x4000 image from a supplier and crop it to 800x800, focusing on a product detail. This avoids the generic images all competitors use.

Permitted sources (company rule)

  • Images for content come only from the company's shared image library or its Adobe Stock account (a paid library of photos). Do not use images from other sources.

Google Images and visual search

1 min

Visual search means searching with a picture instead of words. Google Lens and Pinterest Lens are apps that do this.

Scale and adoption (figures as of 2020, from older 2021-2022 guidance)

Metric Value Ids
Google Lens uses Over 1 billion times as of 2020
Pinterest Lens visual searches Over 600 million per month
US consumers who had used visual search at least once, as of 2020 36%
Objects Google Lens can recognize Over 1 billion

How visual search affects product discovery

  • Visual search through Google Lens and Pinterest Lens is now a main search method, alongside text search. Image optimization is essential for product discovery (customers finding your products).
  • Customers can use Google Lens to scan physical products around them and immediately find where to buy them. This works through shopping ads and normal search results. The customer does not need to know the product name or the retailer.

Ranking signals for Google Images

  • Google uses a separate ranking algorithm for image search. It works independently from text search. So image optimization helps rankings separately from standard on-page SEO (work done on the page itself).
  • Search engines use information from images to decide which search terms a whole page should rank for in normal results.
  • Domain authority is a more important ranking signal in Google Images results. Building site authority through quality content, backlinks (links from other websites to yours) and technical SEO (behind-the-scenes site setup) improves image search rankings automatically.
  • Google Images prioritizes fresher content. Recently updated pages rank higher for image searches than unchanged older pages.
  • Position images centrally on the page and place them higher up. Google Images prioritizes product pages where images are central to the content, over category pages (pages that list several products).
