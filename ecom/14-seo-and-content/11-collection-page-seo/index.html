Collection Page SEO

Section 14.11 · 11 of 20 in this chapter · 15 min read

In short

  • Collection pages (pages that list all products in one category) are your most important SEO pages. SEO means making your pages easy to find on Google.
  • Give every collection the same full setup: images, description, URL, title and search listing. Do this in the same order each time.
  • Write at least 300 unique words for each collection description. Unique means not copied from anywhere else.
  • Check and edit all AI-written text before you publish it.
This section has 13 parts. Tap one to open it.

Order of Work for Collection Pages

1 min

  • Collection pages list the products of one category. They are the most important pages for SEO (SEO means making your pages easy to find on Google).

  • Treat them as money pages, meaning pages that bring in sales.

  • More category pages rank in Google than single product pages.

  • Category pages also usually turn visitors into buyers better than single product pages.

  • Collection pages can rank in Google for free. This is called organic ranking (ranking without paying for ads).

  • So they deserve the same SEO work as product pages.

  • Set up their images, descriptions, URLs and meta tags early. Collections are usually fewer than products, so the work is quick.

  • Shopify (the online store software used here) collections have no description by default.

  • Adding one gives shoppers and search engines extra information from the start.

  • This is a fast gain for stores with only a few collections.

  • Collection pages can rank for specific phrases, such as "custom concrete countertops."

  • Adding a custom section or category can bring in buyers who already want to spend more.

  • Each collection must go through the same sequence.

  • Doing it for only some collections leaves the rest without the benefit.

  1. Image optimization: make image files smaller so the page loads faster.
  2. Descriptions with keywords: keywords are the search words people type into Google.
  3. Template layout: the page design (a template is the layout file that builds the page).
  4. URL and handle: the web address. In Shopify, the handle is the part of the address that names the page.
  5. SEO title and meta description: the title and short text that show in Google search results.
  6. JSON-LD: code that tells Google what the page is about.

Indexing and Site Structure

1 min

  • Build one collection page per category.

  • Make it the full version, with content and SEO.

  • Do not build a second version with and without content. One strong page gathers all the ranking signals (the SEO points Google uses to rank a page).

  • Before you publish, decide two things. Should Google list it? This is called indexing (Google storing and showing the page in search). Where does it fit in the site menu and structure?

  • If it does not fit the site structure, set it to noindex (tell Google not to show the page in search).

  • Collection pages built only for paid ads are often orphan pages. An orphan page has no internal links (links from other pages on your own site).

  • Such a page is not meant to rank in Google anyway. Setting it to noindex protects the SEO value of the rest of the site.

  • If a collection should rank in Google, link it into the site structure (menus and links from other pages).

  • It also needs the same on-page SEO as any other indexed page.

  • Use these collection page rules for new pages.

  • Do not rewrite collection pages that already rank well.

Collection Names and Search Intent

1 min

  • Collection pages target searches for a product type, not one specific product.

  • This is called middle-of-funnel search intent. "Funnel" is the path from first search to sale. "Search intent" is what the searcher wants. Middle-of-funnel means the searcher is comparing options but has not chosen one yet.

  • Choose a focus keyword (the main search phrase for the page) that matches this intent.

  • Build category collections with buying-intent names. Buying intent means the name shows the searcher is ready to buy.

  • For example, use one collection for the general product type and one "for sale" collection.

  • Turn each collection into a landing page (the page a visitor arrives on from a search) so it ranks.

  • Place your product at the top as the recommended choice.

Keyword Research for Collections

1 min

To set the collection name and keyword, follow this procedure.

  1. Decide the collection name from the exact product type, e.g. 'Bamboo Standup Desks'.
  2. Go to Google and type your collection keyword.
  3. Review the top organic results (the first unpaid results) to see what content people expect.
  4. Scroll to the bottom of the Google results and check 'Related searches' (extra searches Google suggests). These give long-tail keyword variations, which are longer, more specific phrases.
  5. Add these related keywords to your collection description and metadata (hidden page information for search engines).

  • The keyword list comes from earlier keyword research.

  • The main keyword matches the collection name. Related keywords are added to it.

  • To find related keywords, search your main keyword with words such as 'best' and 'for beginners'.

  • Example: 'best hybrid surfboards' and 'hybrid surfboards for beginners'.

  • Note the variants (versions) that come up.

  • Use these variants in the collection description and meta tags, next to the main keyword.

Images and Media

1 min

  • Reduce image file size and dimensions on collection pages. Smaller images load faster.

  • Faster pages help both Google rankings and user experience (how pleasant the page is to use).

  • In a demo store (a test store used as an example), optimizing four collection images cut the total from 3.6 MB to just over 1000 KB. That saves about 2.6 MB.

  • Image compression is worth doing for collection pages.

  • But a fast theme (the store's design template) and few apps matter more for page speed (how fast the page loads).

  • Compress every other image on the collection page as far as possible.

  • Give each one a unique file name and unique alt text (a short written description of the image, read by screen readers and Google).

  • Give every image in the description area a unique file name and unique alt text.

  • Videos in the description area should use a thin load (a light file that loads fast).

  • This keeps the page load time low.

Descriptions and Content Length

2 min

  • Add descriptive text to collection pages. It is an SEO element.

  • Collection descriptions should contain at least 300 unique words.

  • Each H3 section (a third-level sub-heading) should carry about 100 words of copy.

  • A page built on the full wireframe (the planned page layout) needs several hundred words of unique text. A few lines are not enough.

  • AI-written section copy often comes out at about 30 words, roughly a third of the target.

  • Expand each section to about 100 words.

  • Shorter copy does not carry enough relevance to rank.

  • Collection pages often have little real content. Google can classify them as thin content (pages with too little text).

  • On a large site with many such pages, thin content can:

    • weaken your overall SEO efforts,
    • stop pages from being indexed,
    • or leave indexed pages performing poorly.

  • A thin page with only a title, a product grid and a few lines of text rarely ranks.

  • Only very large, well-known brands can rank such pages on brand name alone.

  • Smaller stores must add relevant on-page copy (text on the page itself).

  • Add some content so pages are not seen as thin content or duplicate content (the same text on many pages).

  • Make only a small number of collection pages cornerstone pages (your most important pages). If every page is treated as important, none stands out.

  • The fear that adding content makes products harder to find has no evidence behind it.

  • This holds as long as the content is genuinely valuable to the user.

  • Valuable collection content helps the buyer decide which product in the category fits them.

  • It can:

    • compare brands,
    • explain price ranges and configurations (the setup options),
    • show which option suits the buyer's usage conditions and experience level.

  • Example: a collection page for one equipment category could explain which brands suit beginners and which suit advanced users.

  • It could outline the price tiers.

  • It could describe which configuration works best for a given terrain or style of use.

  • This lets visitors reach the right product faster. It also gives search engines clear context about the page.

  • Helpful content gives search engines a clear signal of what the page is about.

  • If competitors (other shops selling the same thing) do not offer similar content, your page may be able to outrank them.

Keyword Placement and Count

1 min

  • Use the focus keyword 3 to 5 times in the collection description.

  • Use the focus keyword 5 times on the whole page.

  • Headings, body text, image file names, image alt text and links to products on the page all count.

  • Product titles listed on the page can contain the keyword, so pages often reach the count easily.

  • The focus keyword must appear at least once in the first 100 words of plain text on the page.

  • Plain text means text without images or code. Plain text is recommended.

Layout and Copy

1 min

Use this layout from top to bottom.

  1. H1 (the main page heading) = the exact target keyword, with no variation.
  2. Short description directly under the H1: one to two sentences about what the products do. Place it above the product grid.
  3. Product grid (the rows of product pictures).
  4. Descriptive copy below the grid. Open with an H2 (a second-level heading) that contains the target keyword in some form. An inverse phrasing is acceptable, such as 'Running Shorts for Men' for 'Men's Running Shorts'.
  5. Three H3 headings, each covering one unique selling point (a reason to buy).
  6. About 100 words of copy under each H3.
  7. 3 to 5 internal links in total, acting as a mini navigation (links to other pages on your site).

  • Collection titles should be tagged as H1 and serve as the page title.

  • Place the focus keyword at the front of the title where possible.

  • Headings in the description area should be H2 tags.

  • They must not carry a link.

  • Collection pages must show visible breadcrumb navigation (a small trail of links that shows where the page sits on the site).

  • The collection title must be visible above the fold on mobile. "Above the fold" means the part of the page you see without scrolling.

  • The title is the main signal that tells visitors they have reached a page that matches their search.

  • Collection page content should use 18pt font (a font size of 18 points), short sentences and short paragraphs.

URLs and Handles

1 min

  • Collection URLs (the handle in Shopify's search engine listing) should match the collection name, with dashes between words.

  • Example: /hybrid-surfboards, not run together.

  • If an existing handle does not match the collection name, change it to match.

  • The page URL should contain the focus keyword and be short.

  • Descriptive URLs that include the target keyword improve click-through rate (how often people click your result, called CTR) from search results.

Meta Title and Meta Description

2 min

  • To set the SEO title, meta description and URL in Shopify, use this setting.

  • In Shopify admin (the store's back office), open the collection.

  • Scroll to Search engine listing (the box that controls how the page looks in Google) and click Edit.

  • The fields are SEO title, SEO description and Handle (the URL).

  • Use these fields to set the title, meta description and URL.

  • SEO title formula for collections: main keyword + sale phrase + shipping benefit.

  • Example pattern: [Main keyword] for Sale | Free and Fast Shipping

  • Adding these qualifiers turns the title into an ad-like snippet (a short, ad-style text), which gets more clicks.

  • Same pattern, another example: Standing Desks for Sale | Free Delivery in 3 Days

  • Same pattern, another example: Ergonomic Office Chairs for Sale | Free Returns and Fast Shipping

  • The page meta title should be unique, include the focus keyword, and be short.

  • The page meta description should be unique and include the focus keyword.

  • Create custom meta descriptions for each collection page instead of using defaults.

  • This maximizes click-through rate from search results.

  • Rich snippets (extra details shown under a search result, such as product information) increase click-through rate.

  • To improve click-through rates from search results, do three things:

    • optimize page URLs,
    • write persuasive meta descriptions,
    • implement rich snippets.

  • A generic meta description or title gives Google no reason to rank the page or show it to searchers.

  • Adding the category, shipping and trust signals (proof you are reliable) makes the listing more attractive.

  • That raises click-through rate, which is the main reason to improve listings.

  • The page title and meta description are what Google displays in search results for the keywords on your site.

  • They can be left empty during the initial setup and filled in during the SEO phase.

  • AI-generated meta tags are a starting point only. Review and edit them before publishing.

  • A generic listing is worse than no listing at all.

  • Filling in unique meta descriptions for all collections as a box-checking task will not bring visitors this week.

  • Duplicate meta descriptions do not penalize pages.

  • So this work should wait behind changes that affect clicks and rankings.

  • Reusing the homepage social share description (the OG description, the text shown when a link is shared on social media) across collections creates duplicate metadata.

  • Give key collections their own descriptions as part of the targeted rewrite work, not as a blanket task.

Prompts and Templates for Collection Copy

3 min

Use this prompt to draft a collection description.

Create a product collection description optimized for search engines. The copy should target [COLLECTION NAME] and strategically incorporate these search terms: [KEYWORD 1, KEYWORD 2, KEYWORD 3].

Use this prompt to draft the description from your keyword research.

Act as an SEO specialist and draft an e-commerce collection description for [collection name], working in these keywords: [keyword 1], [keyword 2], [keyword 3], [keyword 4]. Take the primary keyword as the collection's name and swap the keyword placeholders for the related keyword list from your research. Review the result, keep the parts that work, and reword whatever feels stiff so it reads naturally and reflects what the collection really contains instead of using it as-is.

Use this template for the opening line of a collection description.

Acquire [Collection Name] from [Brand] without delay. Complimentary shipping and protection apply to your entire [Products] order. Purchase immediately to unlock a complimentary [bonus] offer.

Use this template for a meta description draft.

Buy [collection name] now from [brand] and enjoy free shipping plus insurance on every one of our [related keywords]. Place your order today to get a free bonus. (Optional: delete the bonus line if no bonus applies.) Fill the placeholders with the collection name, brand name and related keywords from your research, and use the result as a draft to revise rather than publishing it word for word.

Use this prompt to write the full collection page copy in the wireframe layout.

You are an ecommerce SEO copywriter. Write search-optimized collection page copy for the brand [BRAND NAME], based only on the product catalog and brand facts below: [PASTE PRODUCT CATALOG AND BRAND FACTS]. Target keyword: [TARGET KEYWORD].

Follow this exact structure:
- H1: the target keyword, unchanged.
- Short description under the H1, 1 to 2 sentences, placed above the product grid.
- [PRODUCT GRID] placeholder.
- H2 that contains the target keyword or a natural inverse of it.
- Three H3 headings, each naming one unique selling point.
- About 100 words of copy under each H3.
- 3 to 5 internal links to these URLs: [LIST OF COLLECTION AND BLOG URLS].

Before writing, search Google US for the target keyword with the Firecrawl MCP, analyze the top 10 results, and list the entities they cover (related terms, features, use cases, activities). Work the relevant entities into the copy where they fit naturally.

Style rules: write in active voice, do not use em dashes, remove unnecessary fluff, and avoid these words: [BLACKLIST OF AI-TYPICAL WORDS].

Facts: use only facts from the catalog above. If a size, material, claim or certification is missing, write [PLACEHOLDER: missing fact] instead of inventing it.

Output: the copy in the order above, each section labeled with its heading level and word count, followed by a list of the internal links used and any section under 90 words.

  • To have AI write a collection page in your exact layout, attach a screenshot of the wireframe to the prompt. The wireframe shows the H1, product grid, H2 and three H3s with copy.

  • Tell the model to base the page on it. Showing the image gives the model the structure directly. This works better than describing the layout in words.

  • Before you run a collection copy prompt, state what each H3 section must cover.

  • Examples of real product features: inseam lengths, liner type, fabric, pockets.

  • Also state the roughly 100-word length per section.

  • Without these details, the model fills the sections with generic claims that need heavy rewriting.

On-Page Checklist

1 min

Run the full checklist for every new collection page, in this order.

  1. Decide whether the page should be indexed and where it fits in the site structure. If it does not fit, set it to noindex.
  2. Choose a focus keyword and its relevant synonyms.
  3. Show visible breadcrumb navigation on the page.
  4. Tag the collection title as H1. It is also the page title. Place the focus keyword at the front of the title where possible.
  5. Make sure the collection title is visible above the fold on mobile.
  6. Compress any additional images as far as possible.
  7. Make headings in the description area H2 and do not attach a link to them.
  8. Use the focus keyword at least once in the first 100 words of plain text.
  9. Use the focus keyword 5 times on the page in total.
  10. Format collection page content in 18pt font, with short sentences and short paragraphs.
  11. Write at least 300 unique words for the collection description.
  12. Give every image in the description area a unique file name and unique alt text.
  13. Give videos in the description area a thin load.
  14. Make the page URL contain the focus keyword and keep it short.
  15. Make the meta title unique and include the focus keyword.
  16. Make the meta description unique and include the focus keyword.

Apply the checklist to every collection page as follows.

  1. Run through the full checklist every time a new collection page is created.
  2. Tick off each item before the page goes live.
  3. If someone else creates collection pages for you, give them the checklist and check that every item is ticked on each page.
  4. If a page skips checklist items, ask why and have it corrected.

Where Sources Differ

1 min

  • Keyword count: the description should carry 3 to 5 uses of the focus keyword. The whole page should carry 5 uses.

  • Both apply, because they measure different things: the description and the full page.

  • H1 wording: the H1 must be the exact target keyword with no variation. The focus keyword should sit at the front of the title where possible.

  • Both fit when the title equals the keyword itself.

  • Meta descriptions: write unique ones for each collection.

  • Waiting is advised for filling them in across all collections as a box-checking task.

  • Apply the unique-description rule to new pages and to key collections in the targeted rewrite.

  • The search engine listing fields can stay empty during initial setup and be filled in during the SEO phase.

  • Image compression: compress images as a priority.

  • A fast theme and few apps matter more for page speed than compression alone.

  • Word count: at least 300 unique words for the description fits with about 100 words per H3 across three H3s, which gives several hundred words.
