Typography

Section 8.10 · 10 of 24 in this chapter · 6 min read

In short

  • Keep text easy to read. Normal text should be at least 18 px (pixels, the small units that measure size on a screen).
  • Match fonts to your niche (your small, specific market) and to your logo's style.
  • Use only fonts you have the licence (legal permission) to use for business.
  • Use one or two fonts for the whole store. Many fonts make it look messy.

Serif and sans-serif basics

  • A serif is a small decorative line or flourish (a tiny extra stroke) at the end of a letter stroke. Times New Roman has serifs.
  • A sans-serif font has no serifs ("sans" means "without"). It looks modern and clean.
  • A serif font has small flicks at the ends of its letters. A sans-serif font does not.
  • Sans-serif fonts create a clean, modern look. Serif fonts suggest tradition and formality.
  • Font classes (groups of fonts with a similar style) differ in feel:
    • Monospaced fonts give every letter the same width.
    • Script fonts imitate handwriting.
    • Display fonts are decorative designs made to stand out. They are meant for headlines (big titles) rather than long text.
    • Choose the class based on the mood and where the text will be read.

Choosing headline and body fonts against the logo

  1. Identify whether the logo uses a serif or a sans-serif font.
  2. Select the opposite style from the logo:
    • If the logo uses sans-serif, choose serif fonts for headings (section titles) and body text (the main reading text).
    • If the logo uses serif, choose sans-serif for headings.
    • This contrast creates a modern, professional, and visually pleasing result.

Font pairing

  • Pair a serif font for headings with a sans-serif font for body text, or the reverse, whichever fits the brand best. Replace the template's fonts (the ready-made design of the store) on all headings and all body text in one batch.
  • Use one heading font and one body font, with one or two weights each (thick or thin versions of a font, such as regular or bold).
  • Use one high-quality font consistently across the whole store. Consistent colour and font together build brand value (how much people trust and remember your brand).
  • Pick one typeface family (a group of related fonts that share one design) and use it consistently across the brand.
  • Use default fonts (the ones the store already comes with) for a store unless a designer is working on it. Mixing many fonts quickly makes a store look messy.
  • Use one heading font across the site. A second font for headings is allowed only if it is still readable and not fancy. A bold, chunky font was chosen for the example store to suit its target market (the buyers you aim at).
  • Conflict in the sources: some parts say to use one family throughout the brand. Others say to use a serif and sans-serif contrast between headings and body. The sources do not state when to use one family and when to use a contrasting pair. Both approaches are given here as the sources state them.

Worked examples of the pattern:

  • A modern tech brand uses a clean sans-serif heading font with a simple body font.
  • A sports brand uses a bold display font for headlines with a plain sans-serif for body text.

Steps to find font pairs for a niche:

  1. Search the niche name together with "font pairing" or "luxury font".
  2. Look at real projects on design platforms such as Dribbble and Behance (websites where designers show their work).
  3. Use those projects to see how fonts behave together in a finished design.

Font weights and emphasis

  • Some serif families have no bold weight. A title that needs heavy emphasis (a strong, thick look) should be set in a second typeface with a bold weight.
  • Check the available weights of a family before committing to it for headlines.
  • Body font setup in the example store:
    • Use Helvetica as the body font at 18 px, because it is common and easy to read.
    • Set the alternate bold font (the font used when text is bold) to Helvetica Bold.
    • Adjust letter spacing (the gap between letters) or heading fonts to taste.

Readability and body size

  • Set the base font size (the normal text size) to at least 18 px for all body copy (the main text of the page). Smaller text is hard to read, and search engines (such as Google) do not favour it.
  • The font size scale (one setting that makes all text bigger or smaller) is the simplest way to adjust readability across the store.
  • Choose simple, standard, readable fonts. Avoid decorative, cursive, very thin, or unusual fonts such as Lobster (a loopy, decorative font), because they are harder to read.
  • Text must be clean, easy to read and balanced in structure.
  • Readability limits decorative fonts:
    • Calligraphic (fancy, brush-style) or runic (old rune-like) fonts that are hard to read should be used only for accents or images, not for body text.
    • Choose a readable serif (classic, with small flicks) for headings and for text where needed.
    • Avoid hard-to-read decorative fonts for body text.
  • Mistake: do not use Comic Sans (a casual, cartoon-like font) for website branding. It looks unprofessional, and poor-looking typefaces reduce trust in the store.

Niche fit

  • Typefaces should fit the niche (the small market the store serves):
    • Luxury products use luxury fonts.
    • Friendly or playful brands use playful fonts.
    • Corporate or nature brands use clean fonts.
  • Fonts must match the niche's brand. Playful fonts suit baby or pet products. Elegant serif or thin luxury fonts suit jewellery. A font that changes between niches changes the brand feel drastically.
  • Luxury typography (the design of text) has moved away from calligraphic scripts toward high-contrast serifs. These combine very thin and very thick strokes with sharp terminals (the sharp line ends). The style reads as premium in most niches that target affluent buyers (wealthy customers).

Licensing and Google Fonts

  • Use commercially licensed fonts. Check the licence of fonts from Font Space (a font website) before commercial use (selling or business use). Some fonts, for example ones copied from famous brands, cannot be used commercially.
  • Prefer Google Fonts for web pages. They are widely available in browsers (internet programs such as Chrome) and render reliably (they show correctly).
  • If a non-Google font is not installed on a visitor's device, the browser falls back (switches to a backup font).
  • Use decorative fonts only in images, where the text is printed into the picture.
  • Conflict in the sources: the body font example uses Helvetica. The web rule prefers Google Fonts. The sources do not reconcile these. Check the licence and whether the font is a Google Font before using it on web pages.

Setting fonts in the theme and page builder

Shopify theme (the store's design package; Typography settings are its font controls):

  1. Go to Theme settings > Typography > Change.
  2. Pick a heading font from Shopify's font library (its built-in list of fonts) and click Select.
  3. The change shows in the homepage preview immediately.
  4. Set the body font under Typography > Body font. The example used Montserrat, with the weight changed from regular to medium for thicker text.
  5. Set the font scale to 110% to make all text larger.

PageFly (a page builder, a tool for designing store pages) global styles (settings that apply across the whole site):

  • Set headings, body fonts and colours once under global styles. Changes then push across the whole PageFly site.
  • Upload brand fonts there, then set headings to the uploaded font.
  • Colour scheme used in the example:
    • Dark for primary (the main colour).
    • Light and muted for secondary (the supporting colour).
    • Light and slightly more vibrant for tertiary (the extra accent colour).
    • Plus charcoal, white and grey neutrals (plain background and text colours).
